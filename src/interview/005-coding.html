The coding round, run like a design review

The DSA patterns tab teaches the thirty structures. This section covers the forty-five minutes around them: what gets scored, where the time goes, and the Java slips that cost points even when the algorithm is right.

What the rubric scores

Most rubrics score four things, roughly equally. Problem solving: did you find a sound approach and know its cost? Code: is it correct, readable and idiomatic? Communication: could the interviewer follow your reasoning while you worked? Verification: did you test it before they did?

Verification is the cheapest of the four to earn, and the one candidates skip most often.

When you are stuck

  • Say what you have: "brute force works, it's O(n²), and the repeated work is re-scanning the prefix."
  • Ask what would make it easy: sorted input, a prefix sum, a map from value to index.
  • Shrink it. Solve n = 2 and n = 3 by hand and look for the step you keep repeating.
  • Take the hint and use it well. Interviewers expect to give hints, and using one well counts for more than refusing it.
MinutesDoSay out loud
0–5Restate the problem. Ask about sizes, value ranges, duplicates, empty input, and what to return when there is no answer. Work one example by hand."So n can be 10⁵ and values can be negative. Can the array be empty?"
5–10Brute force first, with its cost. Then the pattern and its invariant. Get agreement before you type."Brute force is O(n²). The constraints want O(n log n) or better, so I'll use a sliding window. The invariant is that the window never contains a repeat."
10–30Code the agreed approach. Name helpers for what they mean. No premature cleverness.Narrate intent, not keystrokes: "now I shrink from the left until the window is valid again."
30–38Trace the example through the code line by line, with real values. Then the edge cases: empty, one element, all equal, negatives, maximum values."Let me run [2, 1, 2] through it before I call it done."
38–45State time and space with their qualifiers: amortised, average case, excluding the output. Take the follow-up."O(n) time amortised, because each index enters and leaves the window once, and O(k) space for the map."

Java slips that cost points with a correct algorithm

SlipWhy it bitesWrite instead
Integer compared with ==Works for −128 to 127 because those values are cached, then fails on real data.a.equals(b), or unbox to int first
Comparator (a, b) -> a - bOverflows for large or mixed-sign values and silently mis-sorts.Integer.compare(a, b) or Comparator.comparingInt(...)
(lo + hi) / 2Overflows when both are near Integer.MAX_VALUE.lo + (hi - lo) / 2
int sums and productsOverflow at about 2.1 × 10⁹, well inside typical constraints.A long accumulator. Say why out loud.
Math.abs(Integer.MIN_VALUE)Returns a negative number.Work in long, or Math.absExact, which throws
list.remove(3) on a List<Integer>Calls remove(int index). It removes the fourth element, not the value 3.list.remove(Integer.valueOf(3))
Arrays.fill(grid, new int[m])Every row is the same array. A write to one row appears in all of them.new int[n][m], or a loop that allocates each row
Arrays.asList(intArray)Returns a one-element List<int[]>. Any Arrays.asList result is also fixed-size.A loop, or new ArrayList<>(...) over a boxed array
Removing inside a for-eachUsually throws ConcurrentModificationException.iterator.remove() or removeIf
s += c in a loopCopies the whole string every time, so O(n²) overall.StringBuilder
Deep recursion on a path-shaped inputA 10⁵-node chain overflows the default thread stack.An explicit ArrayDeque stack, and mention the limit
Relying on HashMap orderThe order is unspecified. Output that passed locally is not guaranteed.Sort, or use LinkedHashMap or TreeMap on purpose
Test your code, not your intentionWhen you trace, read what the code says, not what you meant it to say. Point at each line and say the variables' values. Most bugs found this way are off-by-ones at a boundary. Finding one yourself, calmly, counts in your favour, because it is exactly the habit the verification score measures.
