A three-week plan

If the interview is booked, this order gets the most out of the atlas per hour. It assumes about ninety minutes on weekdays and a longer session at the weekend. Start from the rounds in your loop and drop the lines for rounds you will not face: an AI line for a role with no LLM work, the low-level design lines for a loop without machine coding. With less time, shorten each week but keep the order: mechanisms first, then systems, then rehearsal.

Week 1 · Mechanisms

  • Core Java tab: Collections, Concurrency foundations and The JVM. Every Spring answer eventually lands on one of them.
  • Spring Boot tab: Lifecycle, JPA and Internals. The proxy, the persistence context and transaction boundaries answer a third of any Spring deep-dive.
  • Java streams tab: How a stream runs, then Collectors. Laziness and ordering come up in both the deep-dive and the coding round.
  • This page: Spring & Java and Security, answered out loud before you read the answers.
  • SQL & NoSQL tab: SQL essentials and Indexes and plans, writing each query before reading it. A live SQL round tests exactly this.
  • DSA: the orientation and complexity slides, then patterns 01–10, about two a day. Code the two "if you only drill two" problems for each.

Week 2 · Systems and design

  • System design tab: Fundamentals, Estimation, Data and Caching, then two worked designs (URL shortener and news feed) drawn from memory before you read them.
  • Reference deck: Modular monolith, Backend, Middleware and Data. Event-driven tab: Guarantees and Kafka internals.
  • Low-level design tab: SOLID, then the parking lot and the elevator coded against a 45-minute timer.
  • This page: Architecture, Data and Integration. Rehearse W1 and W2 out loud against a 45-minute timer.
  • SQL & NoSQL tab: Transactions and locking, then Choosing and case studies; do the SQL and MongoDB drills from the question alone.
  • DSA patterns 11–20.

Week 3 · Operating it, then rehearsal

  • Spring Boot tab: Production. Reference deck: Cross-cutting. System design tab: Reliability and Operate & secure.

  • This page: Production & ops, scripts W3–W5, and the numbers.
  • Two mock interviews, one design and one coding, with someone who will interrupt you. Write your five stories and time each at ninety seconds.
  • DSA patterns 21–30.
