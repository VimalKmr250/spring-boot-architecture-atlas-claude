How to read it

  • Arrow keys or the buttons move through slides; C opens contents.
  • Copper marks the path or hop under discussion; teal always means an asynchronous channel.
  • Code is real Spring Boot 4 / Framework 7 on Java 21, trimmed to the line that matters.
  • Versions differ by tab, on purpose. This deck is written against Boot 4.1; the Spring Boot tab targets 3.4/3.5 because that is what most enterprise codebases run today, with Boot 4 boxes marking the delta; the Event-driven tab is Boot 3.5 code with Boot 4 notes; the Java streams tab documents the JDK 25 API and tags everything added after Java 8 with its release. Build snippets are Gradle unless the slide says Maven.
  • The System design tab is a separate, interview-focused deck on high-level design: fundamentals, building blocks, architecture and cloud patterns, then twelve worked designs, with a diagram on nearly every slide.
  • The Low-level design tab prepares you for object-oriented design and machine-coding rounds: principles, the 23 patterns and seven classic problems, solved in Java 21 code that compiles and runs.
  • The Core Java tab covers what every Spring Boot service stands on: the language, collections, concurrency and the JVM, with every claim shown by a program and the output it printed on JDK 25.
  • The Interview prep tab is a separate page: the same material rearranged as questions, scripts and numbers, with every answer linking back to the slides that go deeper.
