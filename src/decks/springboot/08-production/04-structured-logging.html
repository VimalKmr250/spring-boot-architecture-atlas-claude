Logs a machine can query

A line of prose is readable by one person on one server. A JSON object with a trace id is queryable across four hundred pods — which is the only mode that works once you are past one instance.

Boot 3.4+ ships structured logging — no Logback XML needed
logging:
  structured.format.console: ecs        # or gelf, logstash
  level:
    root: INFO
    com.retailco.shop: DEBUG
    org.hibernate.SQL: DEBUG            # local only
  pattern.correlation: "[%X{traceId:-},%X{spanId:-}] "
MDC — context that attaches to every line automatically
@Component
class MdcFilter extends OncePerRequestFilter {
    protected void doFilterInternal(HttpServletRequest req, HttpServletResponse res,
                                    FilterChain chain) throws IOException, ServletException {
        MDC.put("tenantId", TenantContext.current());
        MDC.put("channel", req.getHeader("X-Channel"));
        try {
            chain.doFilter(req, res);
        } finally {
            MDC.clear();            // ALWAYS — pooled threads carry it to the next request
        }
    }
}

// Per-statement structured fields, without string concatenation:
log.atInfo()
   .setMessage("order placed")
   .addKeyValue("orderId", order.id())
   .addKeyValue("totalMinor", order.totalMinor())
   .addKeyValue("lines", order.lines().size())
   .log();
Forgetting MDC.clear()Thread pools reuse threads. A tenant id left in the MDC attaches to the next customer's log lines — which is both a debugging nightmare and, in a regulated environment, a reportable data-handling incident. Always clear in a finally.
MDC does not cross threads@Async, CompletableFuture, Kafka listeners and scheduled jobs all start with an empty MDC. Propagate explicitly — a TaskDecorator on your executor that copies the map is the standard fix, and it is about ten lines.
Runtime log levelsPOST /actuator/loggers/com.retailco.shop.payment {"configuredLevel":"DEBUG"} turns on debug for one package on one pod, with no restart and no deploy. Then turn it off. This is the single most useful production debugging capability Boot gives you, and most teams never enable the endpoint.
