Binding: converters, formatters and the enterprise date problem

Request parameters arrive as strings. How they become a LocalDate, an OrderId or an enum is a small, well-defined extension point that saves a great deal of parsing code.

Per-field formatting
@GetMapping("/report")
Report report(@RequestParam @DateTimeFormat(iso = ISO.DATE) LocalDate from,
              @RequestParam @DateTimeFormat(pattern = "dd/MM/yyyy") LocalDate to,
              @RequestParam @NumberFormat(style = CURRENCY) BigDecimal threshold) { ... }
Application-wide: a Converter for your own value types
@Component
class StringToOrderIdConverter implements Converter<String, OrderId> {
    public OrderId convert(String source) { return OrderId.of(UUID.fromString(source)); }
}

// Now this works, with no parsing in the controller and a typed signature:
@GetMapping("/{id}")
OrderView get(@PathVariable OrderId id) { ... }

// Register a Formatter (parse + print) the same way:
@Configuration
class WebConfig implements WebMvcConfigurer {
    @Override public void addFormatters(FormatterRegistry registry) {
        registry.addConverter(new StringToOrderIdConverter());
        registry.addFormatter(new MoneyFormatter());
    }
}

The date and time rules that avoid incidents

  • Store and transmit instants in UTC. Instant or timestamptz, never a naive local timestamp.
  • Convert to a zone only for display, and carry the user's zone explicitly rather than relying on the server's default.
  • LocalDate for business dates — an invoice due date is a date, not an instant, and forcing it to one shifts it by a day for half your users.
  • Never Date or Calendar in new code; both are mutable and carry a hidden zone.
  • Set the JVM zone explicitly (-Duser.timezone=UTC) so behaviour does not change between your laptop and the cluster.
The enum parameter trapAn unknown enum value in a request parameter produces a 400 whose message names your Java class and its constants — an internal detail leaking to the client. Register a converter that maps unknown values to a domain exception and returns a ProblemDetail listing the accepted values instead.
