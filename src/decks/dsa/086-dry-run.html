Why the child gains are clamped at zeroEach recursive result is wrapped in Math.max(0, …). A branch contributing a negative total should simply not be used — the path can stop at this node instead. Without the clamp, a tree of all-negative values propagates ever more negative sums and the answer is wrong. With it, the root above records 34 rather than being dragged down, and a single negative node correctly returns itself.
