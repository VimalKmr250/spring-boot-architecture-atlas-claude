You cannot go back, so send a scout ahead

A linked list gives you no indices, no length and no way to step backwards. Two pointers moving at different speeds, or the same speed with a fixed gap, recover all three — in one pass and O(1) space.

The invariant — two speeds

Move slow one node and fast two per step. Two consequences follow, and both are used constantly:

  • When fast reaches the end, slow is at the middle — the length was never needed.
  • If there is a cycle, fast must eventually lap slow. Inside the cycle the gap closes by exactly one node per step, so they cannot jump past each other: a meeting is guaranteed.

That "closes by exactly one" is the whole reason the algorithm terminates, and it is what interviewers ask you to justify.

The invariant — fixed gap

Move fast ahead by n nodes first, then advance both at the same speed. The gap is preserved, so when fast hits the end, slow sits exactly n from the end.

This is how "nth node from the end" becomes one pass instead of two: you never learn the length, you just carry the offset.

Both forms are O(n) time and O(1) space, which is almost always the stated constraint. If a problem says "using only constant extra space" about a list, it is naming this pattern.

Applies when

Singly linked lists, and any structure where "next" is a function you can only follow forwards — including an array read as i → nums[i], which turns index-chasing into exactly this cycle problem.

Does not apply when

You need to move backwards, or need the k-th node from the start (that is a plain loop). If the list is doubly linked, the problem is usually easier and this pattern is overkill.

Complexity

O(n) time — phase 1 is at most L + C steps, phase 2 exactly L. O(1) space, which is the constraint these problems exist to enforce. A HashSet of visited nodes also solves 141/142 in O(n) space; say so, then give this.

Recognition cues — the literal words in the statement"determine if the linked list has a cycle" · "return the node where the cycle begins" · "the middle node" · "the n-th node from the end" · "in one pass" · "using O(1) memory" · "the lists intersect". The pairing of linked list with O(1) space or one pass is effectively the problem naming this pattern for you.
