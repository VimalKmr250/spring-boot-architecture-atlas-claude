Build the difference array with a collect; only the sweep carries state

Each update touches two cells of a difference array. Accumulating those is a textbook mutable reduction: a supplier makes the array, an accumulator applies one update, and a combiner adds two partial arrays, so it is even safe in parallel. The sweep that turns differences back into values is a scan, and it is the one stateful line in each solution.

LC 370 · Range Addition · stateful
class Solution {
    public int[] getModifiedArray(int length, int[][] updates) {
        // The difference array is a mutable reduction with a
        // real combiner: +inc at start, -inc just past the end.
        int[] diff = Arrays.stream(updates).collect(
                () -> new int[length + 1],
                (d, u) -> {
                    d[u[0]] += u[2];
                    d[u[1] + 1] -= u[2];
                },
                (a, b) -> Arrays.setAll(a, i -> a[i] + b[i]));
        // Sweeping back to values is a scan: the stateful line.
        int[] run = {0};
        return Arrays.stream(diff, 0, length)
                .map(d -> run[0] += d)
                .toArray();
    }
}
LC 1109 · Corporate Flight Bookings · stateful
class Solution {
    public int[] corpFlightBookings(int[][] bookings, int n) {
        // 370 with 1-indexed flights: +seats at first - 1,
        // -seats at last (just past the range, 0-indexed).
        int[] diff = Arrays.stream(bookings).collect(
                () -> new int[n + 1],
                (d, bk) -> {
                    d[bk[0] - 1] += bk[2];
                    d[bk[1]] -= bk[2];
                },
                (a, b) -> Arrays.setAll(a, i -> a[i] + b[i]));
        int[] run = {0};
        return Arrays.stream(diff, 0, n)
                .map(d -> run[0] += d)
                .toArray();
    }
}
LC 1094 · Car Pooling · stateful
class Solution {
    public boolean carPooling(int[][] trips, int capacity) {
        // Pick-ups add at "from", drop-offs subtract at "to":
        // a passenger is out of the car at the stop they leave.
        int[] diff = Arrays.stream(trips).collect(
                () -> new int[1001],
                (d, t) -> { d[t[1]] += t[0]; d[t[2]] -= t[0]; },
                (a, b) -> Arrays.setAll(a, i -> a[i] + b[i]));
        // Sweep the load and stop at the first overload.
        int[] load = {0};
        return Arrays.stream(diff)
                .allMatch(d -> (load[0] += d) <= capacity);
    }
}
LC 1893 · Check if All the Integers in a Range Are Covered · clean
class Solution {
    public boolean isCovered(int[][] ranges, int left,
                             int right) {
        // At most 50 points × 50 ranges: brute force is clean,
        // instant, and needs no difference array at all.
        return IntStream.rangeClosed(left, right)
                .allMatch(x -> Arrays.stream(ranges)
                        .anyMatch(r -> r[0] <= x && x <= r[1]));
    }
}
LC 1943 · Describe the Painting · stateful
class Solution {
    public List<List<Long>> splitPainting(int[][] segments) {
        // position -> net colour change. Keep every key, even a
        // zero: a mix can change while its sum stays the same.
        TreeMap<Integer, Long> delta = Arrays.stream(segments)
                .flatMap(s -> Stream.of(
                        new long[]{ s[0], s[2] },
                        new long[]{ s[1], -s[2] }))
                .collect(Collectors.groupingBy(e -> (int) e[0],
                        TreeMap::new,
                        Collectors.summingLong(e -> e[1])));
        List<Integer> at = new ArrayList<>(delta.keySet());
        // mix[i] = colour sum on [at[i], at[i+1]): the scan
        long[] run = {0};
        long[] mix = delta.values().stream()
                .mapToLong(d -> run[0] += d).toArray();
        return IntStream.range(0, at.size() - 1)
                .filter(i -> mix[i] > 0)
                .mapToObj(i -> List.of((long) at.get(i),
                        (long) at.get(i + 1), mix[i]))
                .toList();
    }
}
LC 2381 · Shifting Letters II · stateful
class Solution {
    public String shiftingLetters(String s, int[][] shifts) {
        int n = s.length();
        // +1 forward, -1 backward, over [start, end]
        int[] diff = Arrays.stream(shifts).collect(
                () -> new int[n + 1],
                (d, t) -> {
                    int v = t[2] == 1 ? 1 : -1;
                    d[t[0]] += v;
                    d[t[1] + 1] -= v;
                },
                (a, b) -> Arrays.setAll(a, i -> a[i] + b[i]));
        // The sweep to each letter's net shift is the scan.
        int[] run = {0};
        int[] shift = Arrays.stream(diff, 0, n)
                .map(d -> run[0] += d).toArray();
        return IntStream.range(0, n)
                .map(i -> s.charAt(i) - 'a' + shift[i])
                .map(x -> 'a' + Math.floorMod(x, 26))
                .collect(StringBuilder::new,
                         StringBuilder::appendCodePoint,
                         StringBuilder::append)
                .toString();
    }
}
A collect with a real combiner is cleanArrays.setAll(a, i -> a[i] + b[i]) merges two partial difference arrays correctly, so the accumulation is safe in parallel. That is exactly what the three-argument collect is for. The contrast is the sweep after it: in Java 17 it has no correct combiner, because each output needs everything before it. So the one stateful line is always the sweep, never the build.
1943's trap is the same in a streamDrop the zero-change keys, or sum into a HashMap and rebuild the order some other way, and you merge two different colour mixes that happen to have the same sum. The TreeMap collector keeps every event point, so each output segment really is a single mix.
