Sort once; after that, a merge is a collect and a greedy is a fold

Every interval problem starts with a sort, and sorted() handles that. What follows is one of two things. A merge (56) either appends or extends, which is a mutable reduction, and its combiner is the same rule, so it is even safe in parallel. A greedy walk (253, 435, 452) carries one end point, which Stream.iterate folds over the sorted array. 57 needs no sort at all: three filters split the list around the new interval.

LC 56 · Merge Intervals · clean
class Solution {
    public int[][] merge(int[][] intervals) {
        // Sort by start, then collect: each interval extends
        // the last one or starts a new one. The combiner is the
        // same rule applied to a whole list: parallel-safe.
        return Arrays.stream(intervals)
                .sorted(Comparator.comparingInt(iv -> iv[0]))
                .collect(ArrayList<int[]>::new, Solution::add,
                         (a, b) -> b.forEach(iv -> add(a, iv)))
                .toArray(int[][]::new);
    }

    static void add(List<int[]> out, int[] iv) {
        int[] last = out.isEmpty() ? null
                                   : out.get(out.size() - 1);
        if (last != null && iv[0] <= last[1])
            last[1] = Math.max(last[1], iv[1]);
        else
            out.add(new int[]{ iv[0], iv[1] });   // a copy
    }
}
LC 57 · Insert Interval · clean
class Solution {
    public int[][] insert(int[][] intervals,
                          int[] newInterval) {
        int s = newInterval[0], e = newInterval[1];
        // No sort: the list is already sorted. Everything that
        // touches [s, e] collapses into one interval.
        IntSummaryStatistics lo = Arrays.stream(intervals)
                .filter(iv -> iv[1] >= s && iv[0] <= e)
                .mapToInt(iv -> iv[0]).summaryStatistics();
        IntSummaryStatistics hi = Arrays.stream(intervals)
                .filter(iv -> iv[1] >= s && iv[0] <= e)
                .mapToInt(iv -> iv[1]).summaryStatistics();
        int[] merged = { Math.min(s, lo.getMin()),
                         Math.max(e, hi.getMax()) };
        // Entirely left, the merged one, entirely right.
        return Stream.of(
                    Arrays.stream(intervals)
                            .filter(iv -> iv[1] < s),
                    Stream.of(merged),
                    Arrays.stream(intervals)
                            .filter(iv -> iv[0] > e))
                .flatMap(part -> part)
                .toArray(int[][]::new);
    }
}
LC 252 · Meeting Rooms · clean
class Solution {
    public boolean canAttendMeetings(int[][] intervals) {
        int[][] s = Arrays.stream(intervals)
                .sorted(Comparator.comparingInt(iv -> iv[0]))
                .toArray(int[][]::new);
        // Sorted by start, only neighbours can clash.
        return IntStream.range(1, s.length)
                .allMatch(i -> s[i - 1][1] <= s[i][0]);
    }
}
LC 253 · Meeting Rooms II · clean
class Solution {
    // starts and ends consumed so far; the most rooms in use
    record Sweep(int i, int j, int rooms) {}

    public int minMeetingRooms(int[][] intervals) {
        int n = intervals.length;
        int[] start = Arrays.stream(intervals)
                .mapToInt(iv -> iv[0]).sorted().toArray();
        int[] end = Arrays.stream(intervals)
                .mapToInt(iv -> iv[1]).sorted().toArray();
        // Walk both lists in time order. An end at or before
        // the next start frees its room, so it goes first.
        return Stream.iterate(new Sweep(0, 0, 0), s ->
                        s.j() < n && end[s.j()] <= start[s.i()]
                        ? new Sweep(s.i(), s.j() + 1, s.rooms())
                        : new Sweep(s.i() + 1, s.j(), Math.max(
                                s.rooms(), s.i() + 1 - s.j())))
                .filter(s -> s.i() == n)
                .findFirst().get().rooms();
    }
}
LC 435 · Non-overlapping Intervals · clean
class Solution {
    // the greedy's whole state: index, last kept end, kept
    record Keep(int i, int end, int kept) {
        Keep next(int[] iv) {
            return iv[0] >= end
                    ? new Keep(i + 1, iv[1], kept + 1)
                    : new Keep(i + 1, end, kept);
        }
    }

    public int eraseOverlapIntervals(int[][] intervals) {
        // Earliest end first leaves the most room for the rest.
        int[][] byEnd = Arrays.stream(intervals)
                .sorted(Comparator.comparingInt(iv -> iv[1]))
                .toArray(int[][]::new);
        Keep seed = new Keep(0, Integer.MIN_VALUE, 0);
        int kept = Stream.iterate(seed,
                                  k -> k.next(byEnd[k.i()]))
                .skip(byEnd.length)          // exactly n steps
                .findFirst().get().kept();
        return intervals.length - kept;
    }
}
LC 452 · Minimum Number of Arrows to Burst Balloons · clean
class Solution {
    // index, where the last arrow went, arrows so far
    record Shot(int i, long at, int arrows) {
        Shot next(int[] b) {
            return b[0] > at              // touching still pops
                    ? new Shot(i + 1, b[1], arrows + 1)
                    : new Shot(i + 1, at, arrows);
        }
    }

    public int findMinArrowShots(int[][] points) {
        // Shoot at each balloon's end, in order of end. The
        // seed is long: a balloon may start at -2^31 itself.
        int[][] byEnd = Arrays.stream(points)
                .sorted(Comparator.comparingInt(p -> p[1]))
                .toArray(int[][]::new);
        return Stream.iterate(new Shot(0, Long.MIN_VALUE, 0),
                              s -> s.next(byEnd[s.i()]))
                .skip(byEnd.length)
                .findFirst().get().arrows();
    }
}
A merge has a real combinerThe rule that folds one interval into a merged list also folds a whole merged list into another: add each of b's intervals to a in turn. That makes 56's collect a genuine mutable reduction, correct even in parallel, and the harness checks it with .parallel(). It is the rare case where the stream version is strictly more general than the loop.
Sorting a copy costs O(n) spaceArrays.stream(intervals).sorted(…) sorts a copy. That is why the space column says O(n) where the loop says O(1): the loop sorts the input in place. Say so if space comes up, or call Arrays.sort in place first and stream the array that is already sorted.
