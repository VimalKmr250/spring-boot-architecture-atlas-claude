Two traversals, one direction array

The DIRS constant and the bounds check are shared. Everything else is the choice between a stack of recursive calls and an explicit queue with level counting.

DFS — connectivity, counting, sizing (LC 200, 695, 733, 1254)
private static final int[][] DIRS = {{1,0},{-1,0},{0,1},{0,-1}};

// Count components: one DFS per unvisited start.
int numIslands(char[][] g) {
    int count = 0;
    for (int r = 0; r < g.length; r++)
        for (int c = 0; c < g[0].length; c++)
            if (g[r][c] == '1') { count++; sink(g, r, c); }
    return count;
}

/** Marks the whole component. Returns its size, which LC 695 needs. */
private int sink(char[][] g, int r, int c) {
    // One guard covers bounds AND "not part of this component".
    if (r < 0 || r >= g.length || c < 0 || c >= g[0].length) return 0;
    if (g[r][c] != '1') return 0;

    g[r][c] = '0';           // mark visited — NEVER undone, unlike backtracking

    int size = 1;
    for (int[] d : DIRS) size += sink(g, r + d[0], c + d[1]);
    return size;
}
BFS — distance and elapsed time (LC 994, 1091)
// Multi-source: seed EVERY start before the loop, then one pass
// reaches each cell from its nearest source automatically.
int spread(int[][] g) {
    Queue<int[]> q = new ArrayDeque<>();
    int fresh = 0;

    for (int r = 0; r < g.length; r++)
        for (int c = 0; c < g[0].length; c++) {
            if (g[r][c] == 2) q.offer(new int[]{r, c});   // every source
            else if (g[r][c] == 1) fresh++;
        }

    int minutes = 0;
    while (!q.isEmpty() && fresh > 0) {
        int size = q.size();              // SNAPSHOT — one level = one minute

        for (int i = 0; i < size; i++) {
            int[] cur = q.poll();
            for (int[] d : DIRS) {
                int nr = cur[0] + d[0], nc = cur[1] + d[1];
                if (nr < 0 || nr >= g.length || nc < 0 || nc >= g[0].length) continue;
                if (g[nr][nc] != 1) continue;

                g[nr][nc] = 2;            // mark on ENQUEUE, not on dequeue
                fresh--;
                q.offer(new int[]{nr, nc});
            }
        }
        minutes++;      // guarded by fresh > 0, so a drain level never counts
    }
    return fresh == 0 ? minutes : -1;     // unreachable fresh cells
}
The border trick — for "surrounded" questions (LC 1254)
// "Closed" means not touching the edge. Rather than tracking that
// during each traversal, ELIMINATE the open ones first: flood every
// component that touches a border, then count what remains.
int closedIslands(int[][] g) {
    int rows = g.length, cols = g[0].length;

    // Sink everything reachable from the border.
    for (int r = 0; r < rows; r++) { sink(g, r, 0); sink(g, r, cols - 1); }
    for (int c = 0; c < cols; c++) { sink(g, 0, c); sink(g, rows - 1, c); }

    // Whatever land is left cannot touch an edge.
    int count = 0;
    for (int r = 0; r < rows; r++)
        for (int c = 0; c < cols; c++)
            if (g[r][c] == 0) { count++; sink(g, r, c); }   // 0 is LAND here
    return count;
}

The knobs

Traversal
DFS for connectivity, BFS for distance. Forced by the question, not chosen.
Marking
Mutate the grid when allowed — no extra array, and the guard doubles as the visited test. Otherwise a boolean[][].
When to mark
On enqueue in BFS. Marking on dequeue lets the same cell enter the queue many times.
Level counting
The size snapshot, exactly as in a level-order tree traversal. Guard the increment so a level that changes nothing does not count.
Diagonals
Eight directions instead of four when the problem says "8-directionally", as LC 1091 does. Read for that word.
Recursion depth
A 10⁶-cell grid overflows the stack. Say so and switch to an explicit stack if the constraints are large.
The three bugs that actually happenMarking on dequeue — cells are enqueued repeatedly before their first visit, and the queue grows far beyond the grid. Using DFS for a shortest path — it terminates and returns a number, just not the minimum one. Incrementing the level counter unconditionally — the final drain level adds a phantom step, which is exactly the off-by-one in LC 994.
