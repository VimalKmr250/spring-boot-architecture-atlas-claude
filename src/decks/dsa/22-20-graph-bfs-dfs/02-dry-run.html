LC 994 traced on a 3×3 grid of oranges

The grid is 2 1 1 / 1 1 0 / 0 1 1, where 2 is rotten, 1 is fresh and 0 is empty. Rot spreads to orthogonal neighbours each minute. The answer is 4 — and the count comes from the number of BFS levels, not from any per-cell arithmetic.

Two details that decide correctnessCount the fresh oranges up front and decrement as they rot. At the end, a non-zero count means some orange was unreachable — return −1. Checking "are any 1s left?" by rescanning the grid also works but is an extra pass. Only increment the minute counter when a level actually rotted something, or the final drain level inflates the answer by one.
