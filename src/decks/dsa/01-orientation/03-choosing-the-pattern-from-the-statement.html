The trap hiding in row twoA sliding window needs the window property to be monotone: growing the window must only ever help, or only ever hurt. With negative numbers, extending a subarray can lower or raise the sum, so there is no valid shrink rule — which is why "subarray sums to K" with negatives is not a window problem at all, and belongs to a different pattern in the list.
