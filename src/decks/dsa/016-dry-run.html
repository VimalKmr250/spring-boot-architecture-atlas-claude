Longest substring without repeating characters. The window state is a character count; the window is invalid exactly when the character we just admitted appears twice. Watch l: it moves seven times in total across the whole run, never backwards — the amortisation argument made concrete.

The window never re-reads a settled prefix: the count map already remembers everything the rescan would have recomputed. On a string of 10⁵ characters that is the difference between 10⁵ and 10¹⁰ operations.
