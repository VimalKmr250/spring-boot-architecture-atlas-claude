Why the bounds must be Long, not intSeeding with Integer.MIN_VALUE and Integer.MAX_VALUE breaks when the tree legitimately contains those values — a single node holding Integer.MIN_VALUE is a valid BST, but the check val > MIN_VALUE rejects it. Use Long bounds with null meaning unbounded, or pass Long.MIN_VALUE and Long.MAX_VALUE. LeetCode tests this exact case.
