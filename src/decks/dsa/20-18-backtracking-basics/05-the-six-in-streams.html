Backtracking is flatMap, and the call stack does the undo

A backtracking loop adds a choice, recurses, then removes the choice again. A stream version never removes anything. Each recursive call returns a stream of finished answers for the choices still left, and flatMap puts the current choice on the front of each one. No list is shared between branches, so there is nothing to undo. The depth here is at most 20, so recursing through a pipeline is safe. Subsets and combinations need no recursion at all, because they are just bitmasks.

LC 78 · Subsets · clean
class Solution {
    public List<List<Integer>> subsets(int[] nums) {
        int n = nums.length;
        // Every mask 0 .. 2^n - 1 is one subset: bit i says
        // whether nums[i] is in it. No recursion at all.
        return IntStream.range(0, 1 << n)
                .mapToObj(m -> IntStream.range(0, n)
                        .filter(i -> (m >> i & 1) == 1)
                        .mapToObj(i -> nums[i])
                        .toList())
                .toList();
    }
}
LC 77 · Combinations · clean
class Solution {
    public List<List<Integer>> combine(int n, int k) {
        // A combination is a mask with exactly k bits set. Up
        // to 2^20 masks, filtered by bitCount: no recursion.
        return IntStream.range(0, 1 << n)
                .filter(m -> Integer.bitCount(m) == k)
                .mapToObj(m -> IntStream.rangeClosed(1, n)
                        .filter(i -> (m >> (i - 1) & 1) == 1)
                        .boxed()
                        .toList())
                .toList();
    }
}
LC 39 · Combination Sum · clean
class Solution {
    public List<List<Integer>> combinationSum(int[] candidates,
                                              int target) {
        return sums(candidates, 0, target).toList();
    }

    // Recurse from the SAME index: a number may be reused, but
    // never an earlier one, so every combination appears once.
    static Stream<List<Integer>> sums(int[] c, int from,
                                      int left) {
        if (left == 0) return Stream.of(List.of());
        return IntStream.range(from, c.length)
                .filter(i -> c[i] <= left)   // prune overshoot
                .boxed()
                .flatMap(i -> sums(c, i, left - c[i])
                        .map(rest -> prepend(c[i], rest)));
    }

    static List<Integer> prepend(int x, List<Integer> rest) {
        return Stream.concat(Stream.of(x), rest.stream())
                .toList();
    }
}
LC 46 · Permutations · clean
class Solution {
    public List<List<Integer>> permute(int[] nums) {
        return perms(Arrays.stream(nums).boxed().toList())
                .toList();
    }

    // Each remaining value in turn goes first; the rest are
    // permuted recursively. equals(), not ==, on Integers.
    static Stream<List<Integer>> perms(List<Integer> left) {
        if (left.isEmpty()) return Stream.of(List.of());
        return left.stream().flatMap(x -> perms(left.stream()
                        .filter(y -> !y.equals(x)).toList())
                .map(rest -> prepend(x, rest)));
    }

    static List<Integer> prepend(int x, List<Integer> rest) {
        return Stream.concat(Stream.of(x), rest.stream())
                .toList();
    }
}
LC 90 · Subsets II · clean
class Solution {
    public List<List<Integer>> subsetsWithDup(int[] nums) {
        int[] a = nums.clone();
        Arrays.sort(a);   // equal subsets become equal lists
        int n = a.length;
        // Every mask, as in 78; distinct() drops the repeats.
        return IntStream.range(0, 1 << n)
                .mapToObj(m -> IntStream.range(0, n)
                        .filter(i -> (m >> i & 1) == 1)
                        .mapToObj(i -> a[i])
                        .toList())
                .distinct()
                .toList();
    }
}
LC 47 · Permutations II · clean
class Solution {
    public List<List<Integer>> permuteUnique(int[] nums) {
        return perms(Arrays.stream(nums).boxed().toList())
                .toList();
    }

    // Branch on each DISTINCT remaining value, never on each
    // element: equal values then never start two branches.
    static Stream<List<Integer>> perms(List<Integer> left) {
        if (left.isEmpty()) return Stream.of(List.of());
        return left.stream().distinct()
                .flatMap(x -> perms(removeOne(left, x))
                        .map(rest -> prepend(x, rest)));
    }

    static List<Integer> removeOne(List<Integer> l, int x) {
        int i = l.indexOf(x);
        return Stream.concat(l.subList(0, i).stream(),
                        l.subList(i + 1, l.size()).stream())
                .toList();
    }

    static List<Integer> prepend(int x, List<Integer> rest) {
        return Stream.concat(Stream.of(x), rest.stream())
                .toList();
    }
}
Why nothing is undoneThe loop's path.add, recurse, path.remove exists because one mutable list is shared by every branch. Here each call builds its answers from the bottom up and hands them back, so there is no shared list and no undo step to forget. The price is copying: an answer is rebuilt once per level, which multiplies the loop's cost by the depth. The Streams column shows that factor wherever it applies.
Where duplicates go90 and 47 show the two stream answers to duplicate input. For subsets, generate everything from sorted input and let distinct() remove the equal lists. For permutations, branch on left.stream().distinct(), so equal values never start two branches. That is the loop's "skip if equal to the previous unused element" rule, without the index bookkeeping. Note too that 46 compares with equals: == on boxed values past 127 compares references.
