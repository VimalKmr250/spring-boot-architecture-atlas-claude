Why stopping at n − 1 edges is safeA spanning tree on n nodes has exactly n − 1 edges, so once that many have been accepted every node is connected and any further edge would close a cycle. Breaking there saves scanning the tail of the sorted list — with n = 1000 points that is roughly 500,000 edges, of which only 999 are ever taken.
