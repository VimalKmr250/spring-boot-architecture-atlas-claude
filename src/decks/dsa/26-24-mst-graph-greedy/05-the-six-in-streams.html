Kruskal is a filter; Prim is a pure step per point

Kruskal's algorithm reads naturally as a pipeline: sort the edges, keep the ones whose union joins two components, sum what is left. The union-find behind that filter is state, so 1135, 1168, 1489, 778 and 1102 are stateful, and 778 and 1102 simply open grid cells in value order instead of taking edges. 1584 goes the other way. On a complete graph, Prim's step is a pure function of the tree so far, which makes it both clean and faster than sorting all n²/2 edges.

LC 1584 · Min Cost to Connect All Points · clean
class Solution {
    // the tree so far: which points are in, each outside
    // point's cheapest link into it, and the cost paid
    record Prim(boolean[] in, int[] link, int cost) {
        Prim grow(int[][] p) {
            int n = link.length;
            IntBinaryOperator nearer = (a, b) ->
                    link[a] <= link[b] ? a : b;
            int u = IntStream.range(0, n).filter(v -> !in[v])
                    .reduce(nearer).getAsInt();
            boolean[] in2 = in.clone();
            in2[u] = true;
            int[] link2 = IntStream.range(0, n)
                    .map(v -> in2[v] ? link[v]
                            : Math.min(link[v], dist(p, u, v)))
                    .toArray();
            return new Prim(in2, link2, cost + link[u]);
        }
    }

    public int minCostConnectPoints(int[][] points) {
        int n = points.length;
        int[] link = IntStream.range(0, n)
                .map(v -> v == 0 ? 0 : Integer.MAX_VALUE)
                .toArray();
        // Prim on the complete graph, one pure step per point:
        // O(n²), where sorting all n²/2 edges is O(n² log n).
        return Stream.iterate(new Prim(new boolean[n], link, 0),
                              s -> s.grow(points))
                .skip(n).findFirst().get().cost();
    }

    static int dist(int[][] p, int a, int b) {
        return Math.abs(p[a][0] - p[b][0])
             + Math.abs(p[a][1] - p[b][1]);
    }
}
LC 1135 · Connecting Cities With Minimum Cost · stateful
class Solution {
    public int minimumCost(int n, int[][] connections) {
        DSU dsu = new DSU(n + 1);
        // Kruskal is a filter: cheapest first, keep an edge
        // only if it joins two components. The union is state.
        List<int[]> taken = Arrays.stream(connections)
                .sorted(Comparator.comparingInt(c -> c[2]))
                .filter(c -> dsu.union(c[0], c[1]))
                .toList();
        return taken.size() < n - 1 ? -1   // still disconnected
                : taken.stream().mapToInt(c -> c[2]).sum();
    }

    // ---- the union-find from the union-find slides ----
    record DSU(int[] parent, int[] size) {
        DSU(int n) {
            this(IntStream.range(0, n).toArray(),
                 IntStream.range(0, n).map(i -> 1).toArray());
        }

        int find(int x) {
            return IntStream.iterate(x, y -> parent[y])
                    .filter(y -> parent[y] == y)
                    .findFirst().getAsInt();
        }

        boolean union(int a, int b) {
            int ra = find(a), rb = find(b);
            if (ra == rb) return false;
            int big = size[ra] >= size[rb] ? ra : rb;
            int small = big == ra ? rb : ra;
            parent[small] = big;
            size[big] += size[small];
            return true;
        }
    }
}
LC 1168 · Optimize Water Distribution in a Village · stateful
class Solution {
    public int minCostToSupplyWater(int n, int[] wells,
                                    int[][] pipes) {
        DSU dsu = new DSU(n + 1);
        // A well at house i is a pipe from a virtual house 0.
        // After that, it is plain Kruskal.
        Stream<int[]> wellPipes = IntStream.rangeClosed(1, n)
                .mapToObj(i -> new int[]{ 0, i, wells[i - 1] });
        return Stream.concat(wellPipes, Arrays.stream(pipes))
                .sorted(Comparator.comparingInt(e -> e[2]))
                .filter(e -> dsu.union(e[0], e[1]))
                .mapToInt(e -> e[2])
                .sum();
    }

    // ---- the union-find from the union-find slides ----
    record DSU(int[] parent, int[] size) {
        DSU(int n) {

                 IntStream.range(0, n).map(i -> 1).toArray());

        int find(int x) {

LC 1489 · Find Critical and Pseudo-Critical Edges in MST · stateful
class Solution {
    public List<List<Integer>>
            findCriticalAndPseudoCriticalEdges(int n,
                                               int[][] edges) {
        int m = edges.length;
        Comparator<Integer> light = Comparator
                .comparingInt(i -> edges[i][2]);
        List<Integer> order = IntStream.range(0, m).boxed()
                .sorted(light).toList();
        IntBinaryOperator cost = (skip, force) ->
                mst(n, edges, order, skip, force);
        int base = cost.applyAsInt(-1, -1);
        // Critical: the MST gets dearer (or breaks) without it.
        List<Integer> critical = IntStream.range(0, m)
                .filter(i -> cost.applyAsInt(i, -1) > base)
                .boxed().toList();
        // Pseudo-critical: not critical, yet some MST uses it.
        List<Integer> pseudo = IntStream.range(0, m)
                .filter(i -> !critical.contains(i))
                .filter(i -> cost.applyAsInt(-1, i) == base)
                .boxed().toList();
        return List.of(critical, pseudo);
    }

    // Kruskal without edge skip, taking edge force first. Each
    // call owns a fresh DSU, so the state stays inside it.
    static int mst(int n, int[][] e, List<Integer> byWeight,
                   int skip, int force) {
        DSU dsu = new DSU(n);
        IntStream first = force < 0 ? IntStream.empty()
                                    : IntStream.of(force);
        int[] taken = IntStream.concat(first, byWeight.stream()
                        .mapToInt(Integer::intValue)
                        .filter(i -> i != skip))
                .filter(i -> dsu.union(e[i][0], e[i][1]))
                .toArray();
        return taken.length < n - 1 ? Integer.MAX_VALUE
                : Arrays.stream(taken).map(i -> e[i][2]).sum();
    }

    // ---- the union-find from the union-find slides ----
    record DSU(int[] parent, int[] size) {
        DSU(int n) {
            this(IntStream.range(0, n).toArray(),
                 IntStream.range(0, n).map(i -> 1).toArray());
        }

        int find(int x) {
            return IntStream.iterate(x, y -> parent[y])
                    .filter(y -> parent[y] == y)
                    .findFirst().getAsInt();
        }

        boolean union(int a, int b) {
            int ra = find(a), rb = find(b);
            if (ra == rb) return false;
            int big = size[ra] >= size[rb] ? ra : rb;
            int small = big == ra ? rb : ra;
            parent[small] = big;
            size[big] += size[small];
            return true;
        }
    }
}
LC 778 · Swim in Rising Water · stateful
class Solution {
    public int swimInWater(int[][] grid) {
        int n = grid.length, last = n * n - 1;
        // at[t] = the cell of height t (heights are 0 .. n*n-1)
        int[] at = new int[n * n];
        IntStream.range(0, n * n)
                .forEach(x -> at[grid[x / n][x % n]] = x);
        boolean[] open = new boolean[n * n];
        DSU dsu = new DSU(n * n);
        // Raise the water one height at a time. Each height
        // opens one cell and joins it to its open neighbours;
        // the answer is the first height joining the corners.
        return IntStream.range(0, n * n).filter(t -> {
            int x = at[t];
            open[x] = true;
            around(x, n, n).filter(y -> open[y])
                    .forEach(y -> dsu.union(x, y));
            return dsu.find(0) == dsu.find(last);
        }).findFirst().getAsInt();
    }

    // the 4 neighbours of cell x = r * n + c, inside the grid
    static IntStream around(int x, int m, int n) {
        int c = x % n;
        int left = c > 0 ? x - 1 : -1;
        int right = c < n - 1 ? x + 1 : -1;
        return IntStream.of(x - n, x + n, left, right)
                .filter(y -> y >= 0 && y < m * n);
    }

    // ---- the union-find from the union-find slides ----
    record DSU(int[] parent, int[] size) {
        DSU(int n) {
            this(IntStream.range(0, n).toArray(),
                 IntStream.range(0, n).map(i -> 1).toArray());
        }

        int find(int x) {
            return IntStream.iterate(x, y -> parent[y])
                    .filter(y -> parent[y] == y)
                    .findFirst().getAsInt();
        }

        boolean union(int a, int b) {
            int ra = find(a), rb = find(b);
            if (ra == rb) return false;
            int big = size[ra] >= size[rb] ? ra : rb;
            int small = big == ra ? rb : ra;
            parent[small] = big;
            size[big] += size[small];
            return true;
        }
    }
}
LC 1102 · Path With Maximum Minimum Value · stateful
class Solution {
    public int maximumMinimumPath(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int last = m * n - 1;
        boolean[] open = new boolean[m * n];
        DSU dsu = new DSU(m * n);
        Comparator<Integer> highFirst = Comparator
                .comparingInt((Integer x) -> grid[x / n][x % n])
                .reversed();
        // Open cells from the highest value down. The cell
        // whose opening first joins the corners is the weakest
        // step of the best path, so its value is the answer.
        return IntStream.range(0, m * n).boxed()
                .sorted(highFirst)
                .filter(x -> {
                    open[x] = true;
                    around(x, m, n).filter(y -> open[y])
                            .forEach(y -> dsu.union(x, y));
                    return dsu.find(0) == dsu.find(last);
                })
                .findFirst()
                .map(x -> grid[x / n][x % n]).get();
    }

    // the 4 neighbours of cell x = r * n + c, inside the grid
    static IntStream around(int x, int m, int n) {
        int c = x % n;
        int left = c > 0 ? x - 1 : -1;
        int right = c < n - 1 ? x + 1 : -1;
        return IntStream.of(x - n, x + n, left, right)
                .filter(y -> y >= 0 && y < m * n);
    }

    // ---- the union-find from the union-find slides ----
    record DSU(int[] parent, int[] size) {
        DSU(int n) {
            this(IntStream.range(0, n).toArray(),
                 IntStream.range(0, n).map(i -> 1).toArray());
        }

        int find(int x) {
            return IntStream.iterate(x, y -> parent[y])
                    .filter(y -> parent[y] == y)
                    .findFirst().getAsInt();
        }

        boolean union(int a, int b) {
            int ra = find(a), rb = find(b);
            if (ra == rb) return false;
            int big = size[ra] >= size[rb] ? ra : rb;
            int small = big == ra ? rb : ra;
            parent[small] = big;
            size[big] += size[small];
            return true;
        }
    }
}
Kruskal reads like its definitionsorted(byWeight).filter(e -> dsu.union(e[0], e[1])) says exactly what Kruskal's algorithm is: the cheapest edges first, keeping each one that connects something new. The loop version says the same thing with more ceremony. The stateful part is confined to union, and 1489 shows how to keep it contained: each call to mst builds its own DSU, so the outer pipeline over edges shares nothing.
Pick the algorithm that fits the streamOn 1584's complete graph, Kruskal would materialise and sort about 500,000 edges. Prim needs only two arrays of n values, and each step is a pure function from one pair of arrays to the next. So the cleaner pipeline is also the asymptotically better algorithm: O(n²) instead of O(n² log n), which ran in 13 ms at n = 1000.
