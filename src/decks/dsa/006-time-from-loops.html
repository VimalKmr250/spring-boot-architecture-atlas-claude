Count executions of the innermost line, not loop keywords

For iterative code, the time complexity is the number of times the innermost statement runs, multiplied by what that statement costs. The loop bounds decide that number — so read each bound and ask what it depends on: n, the outer index, a second input, or a constant.

Shapes 1–5 · the everyday ones
// 1 · One pass — O(n)
for (int i = 0; i < n; i++) sum += a[i];

// 2 · Two passes in sequence — O(n) + O(n) = O(n), not O(n²)
for (int i = 0; i < n; i++) max = Math.max(max, a[i]);
for (int i = 0; i < n; i++) if (a[i] == max) count++;

// 3 · Nested, both bounded by n — O(n²)
for (int i = 0; i < n; i++)
    for (int j = 0; j < n; j++)
        prod[i][j] = a[i] * a[j];

// 4 · Inner loop starts at i + 1 — still O(n²)
//     (n-1) + (n-2) + ... + 1 = n(n-1)/2 pairs
for (int i = 0; i < n; i++)
    for (int j = i + 1; j < n; j++)
        if (a[i] + a[j] == target) return true;

// 5 · The range halves each pass — O(log n)
while (lo <= hi) {
    int mid = lo + (hi - lo) / 2;
    if (a[mid] < target) lo = mid + 1; else hi = mid - 1;
}
Shapes 6–9 · the ones people misread
// 6 · Linear outer, doubling inner — O(n log n)
//     the inner loop runs log2(n) times per i
for (int i = 0; i < n; i++)
    for (int j = 1; j < n; j *= 2)
        work(i, j);

// 7 · Two different inputs — O(n · L), never "O(n²)"
for (String w : words)                      // n words
    for (int j = 0; j < w.length(); j++)    // L chars each
        freq[w.charAt(j) - 'a']++;

// 8 · Square-root bound — O(√n)
//     d stops as soon as d * d passes n
int divisors = 0;
for (long d = 1; d * d <= n; d++)
    if (n % d == 0) divisors += (d * d == n) ? 1 : 2;

// 9 · Constant inner bound — O(26 · n) = O(n)
//     say "26n" once, so they hear you noticed it
for (int i = 0; i < n; i++)
    for (int c = 0; c < 26; c++)
        best = Math.max(best, cnt[i][c]);
The number of loops is a hint, not a proofTwo nested loops can be O(n): in a sliding window the inner while moves a pointer that persists across the whole run, so it is counted once overall — the amortised slide covers it. One loop can be O(n²): a body that calls s += c, list.remove(0) or list.contains(x) hides a second loop inside a library call — the next slide lists them.
