LC 212 traced on a 2×2 board with a three-word dictionary

The board is o a / a n, and the words are "oath", "oan", "pea". The point of the trie is that all three are searched in a single board traversal, and a branch dies the moment no word continues down it.

Two optimisations that matter at scaleNull the isWord flag after collecting a word, so the same word is never added twice from a different path — cheaper and cleaner than de-duplicating a result list afterwards. Prune dead trie branches: after a child's subtree is exhausted and it holds no words, set that child link to null. On the large LC 212 test cases this shrinks the trie as the search proceeds and turns a timeout into a comfortable pass.
