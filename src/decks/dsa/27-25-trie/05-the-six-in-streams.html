A trie walk is a fold; a wildcard is an anyMatch

Walking a word down a trie is a left fold over its letters, and Java 17 has no foldLeft. On a sequential stream the three-argument reduce behaves as one, provided its combiner never runs, so 208 and 211 make that combiner throw. A . in 211 becomes an anyMatch over all 26 children. Within their limits, three of the six need no trie at all: a hash set of roots for 648, a scan of at most 50 keys for 677, and a scan of the sorted products for 1268. 212 is the exception. Its speed comes from pruning the trie as words are found, and a stream can only drive that search.

LC 208 · Implement Trie (Prefix Tree) · stateful
class Trie {
    private static class Node {
        final Node[] next = new Node[26];
        boolean word;

        Node child(int c, boolean create) {
            if (next[c - 'a'] == null && create)
                next[c - 'a'] = new Node();
            return next[c - 'a'];
        }
    }

    private final Node root = new Node();

    public void insert(String word) {
        walk(word, true).word = true;
    }

    public boolean search(String word) {
        Node n = walk(word, false);
        return n != null && n.word;
    }

    public boolean startsWith(String prefix) {
        return walk(prefix, false) != null;
    }

    // Java 17 has no foldLeft. On a sequential stream the
    // three-argument reduce is one; its combiner never runs.
    private Node walk(String w, boolean create) {
        return w.chars().boxed().reduce(root,
                (n, c) -> n == null ? null : n.child(c, create),
                (a, b) -> { throw new AssertionError(); });
    }
}
LC 211 · Design Add and Search Words Data Structure · stateful
class WordDictionary {
    private static class Node {
        final Node[] next = new Node[26];
        boolean word;
    }

    private final Node root = new Node();

    public void addWord(String word) {
        // The sequential fold down the trie from 208's insert.
        Node end = word.chars().boxed().reduce(root, (n, c) -> {
            int i = c - 'a';
            if (n.next[i] == null) n.next[i] = new Node();
            return n.next[i];
        }, (a, b) -> { throw new AssertionError(); });
        end.word = true;
    }

    public boolean search(String word) {
        return match(root, word, 0);
    }

    // A '.' tries every child: anyMatch over them, recursively.
    // The search reads the trie and never changes it.
    private static boolean match(Node n, String w, int i) {
        if (n == null) return false;
        if (i == w.length()) return n.word;
        char c = w.charAt(i);
        Stream<Node> options = c == '.'
                ? Arrays.stream(n.next)
                : Stream.of(n.next[c - 'a']);
        return options.anyMatch(ch -> match(ch, w, i + 1));
    }
}
LC 648 · Replace Words · clean
class Solution {
    public String replaceWords(List<String> dictionary,
                               String sentence) {
        Set<String> roots = new HashSet<>(dictionary);
        int longest = dictionary.stream()
                .mapToInt(String::length).max().orElse(0);
        // A hash set of roots stands in for the trie: try each
        // prefix up to the longest root, shortest first.
        return Arrays.stream(sentence.split(" "))
                .map(w -> IntStream.rangeClosed(1, w.length())
                        .limit(longest)
                        .mapToObj(k -> w.substring(0, k))
                        .filter(roots::contains)
                        .findFirst().orElse(w))
                .collect(Collectors.joining(" "));
    }
}
LC 677 · Map Sum Pairs · clean
class MapSum {
    private final Map<String, Integer> vals = new HashMap<>();

    public void insert(String key, int val) {
        vals.put(key, val);    // a repeated key overwrites
    }

    // At most 50 calls and keys of at most 50 letters: a scan
    // of every key per sum is plenty, and needs no trie.
    public int sum(String prefix) {
        return vals.entrySet().stream()
                .filter(e -> e.getKey().startsWith(prefix))
                .mapToInt(Map.Entry::getValue)
                .sum();
    }
}
LC 1268 · Search Suggestions System · clean
class Solution {
    public List<List<String>> suggestedProducts(
            String[] products, String searchWord) {
        List<String> sorted = Arrays.stream(products).sorted()
                .toList();
        // For each prefix typed so far, the first three sorted
        // products that start with it.
        return IntStream.rangeClosed(1, searchWord.length())
                .mapToObj(k -> searchWord.substring(0, k))
                .map(p -> sorted.stream()
                        .filter(s -> s.startsWith(p))
                        .limit(3)
                        .toList())
                .toList();
    }
}
LC 212 · Word Search II · forced
class Solution {
    private static class Node {
        final Node[] next = new Node[26];
        String word;       // set on the node ending a word
    }

    private static final int[][] STEPS =
            { {1, 0}, {-1, 0}, {0, 1}, {0, -1} };

    public List<String> findWords(char[][] board,
                                  String[] words) {
        Node root = new Node();
        BinaryOperator<Node> never = (a, b) -> {
            throw new AssertionError();
        };
        Arrays.stream(words).forEach(w -> w.chars().boxed()
                .reduce(root, Solution::child, never).word = w);
        int m = board.length, n = board[0].length;
        List<String> found = new ArrayList<>();
        // The search marks cells and prunes found words from
        // the trie. That mutation is what keeps it fast.
        IntStream.range(0, m * n).forEach(x ->
                dfs(board, x / n, x % n, root, found));
        return found;
    }

    private static Node child(Node n, int c) {
        int i = c - 'a';
        if (n.next[i] == null) n.next[i] = new Node();
        return n.next[i];
    }

    private static void dfs(char[][] b, int r, int c,
                            Node parent, List<String> found) {
        if (r < 0 || c < 0 || r >= b.length || c >= b[0].length
                || b[r][c] == '#') return;
        char ch = b[r][c];
        Node node = parent.next[ch - 'a'];
        if (node == null) return;
        if (node.word != null) {          // report it once
            found.add(node.word);
            node.word = null;
        }
        b[r][c] = '#';                    // visited
        Arrays.stream(STEPS).forEach(d ->
                dfs(b, r + d[0], c + d[1], node, found));
        b[r][c] = ch;
        // Nothing left to find below this node: prune it.
        if (Arrays.stream(node.next).allMatch(Objects::isNull))
            parent.next[ch - 'a'] = null;
    }
}
A fold that says it is sequentialThe accumulator in reduce(root, step, combiner) is not associative: folding "ap" and "ple" separately from the root gives the wrong node. That is only correct on a sequential stream, where the combiner is never called. A combiner that throws AssertionError writes that fact into the code, and it fails loudly if someone later adds .parallel(). That one line is what the stateful label means.
When the trie is the algorithm648, 677 and 1268 can drop the trie because their limits are small. 212 cannot. The trie lets one DFS serve up to 30,000 words that share prefixes, and deleting a word's branch once it is found stops the search from walking those paths again. Both are mutation during the search, so the streams here only drive the DFS, and the loop is the better code.
