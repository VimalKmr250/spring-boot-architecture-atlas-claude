Why union-find and not a traversalDFS also detects the cycle, but it must re-examine the graph built so far after every edge, giving O(E²) if you want the last redundant edge. Union-find processes each edge once and answers immediately, because the connectivity state is carried forward rather than recomputed. That incremental property is the whole reason this structure exists.
