A Bellman–Ford round is a pure function; Dijkstra's queue is the loop

One Bellman–Ford round maps a distance array to the next, and nothing else. So Stream.iterate(start, relax).skip(rounds) is the whole algorithm. For 787, the rule that makes "at most k stops" exact, reading only the previous round's array, comes for free. Floyd–Warshall is the same kind of fold, over matrices. Where the graph is too big for rounds (1514), Dijkstra's priority queue is drained and refilled by a single loop, and a stream can only drive that loop.

LC 743 · Network Delay Time · clean
class Solution {
    static final int INF = Integer.MAX_VALUE;

    public int networkDelayTime(int[][] times, int n, int k) {
        // v -> the edges [u, v, w] arriving at v
        Map<Integer, List<int[]>> into = Arrays.stream(times)
                .collect(Collectors.groupingBy(e -> e[1]));
        int[] start = IntStream.rangeClosed(0, n)
                .map(v -> v == k ? 0 : INF).toArray();
        // Bellman-Ford: n - 1 rounds, each one a pure function
        // from the last distance array to the next.
        int[] dist = Stream.iterate(start, d -> relax(d, into))
                .skip(n - 1).findFirst().get();
        int worst = IntStream.rangeClosed(1, n)
                .map(v -> dist[v]).max().getAsInt();
        return worst == INF ? -1 : worst;
    }

    // One Bellman-Ford round: every node takes the best offer
    // arriving over any edge [u, v, w]. A pure function.
    static int[] relax(int[] d,
                       Map<Integer, List<int[]>> into) {
        return IntStream.range(0, d.length)
                .map(v -> Math.min(d[v], into
                        .getOrDefault(v, List.of()).stream()
                        .filter(e -> d[e[0]] != INF)
                        .mapToInt(e -> d[e[0]] + e[2])
                        .min().orElse(INF)))
                .toArray();
    }
}
LC 787 · Cheapest Flights Within K Stops · clean
class Solution {
    static final int INF = Integer.MAX_VALUE;

    public int findCheapestPrice(int n, int[][] flights,
                                 int src, int dst, int k) {
        Map<Integer, List<int[]>> into = Arrays.stream(flights)
                .collect(Collectors.groupingBy(f -> f[1]));
        int[] start = IntStream.range(0, n)
                .map(v -> v == src ? 0 : INF).toArray();
        // k stops = k + 1 flights = k + 1 rounds. Each round
        // reads only the previous array, so no round can chain
        // two flights: the copy the loop has to remember.
        int[] cost = Stream.iterate(start, d -> relax(d, into))
                .skip(k + 1).findFirst().get();
        return cost[dst] == INF ? -1 : cost[dst];
    }

    // One Bellman-Ford round: every node takes the best offer
    // arriving over any edge [u, v, w]. A pure function.
    static int[] relax(int[] d,
                       Map<Integer, List<int[]>> into) {
        return IntStream.range(0, d.length)
                .map(v -> Math.min(d[v], into
                        .getOrDefault(v, List.of()).stream()
                        .filter(e -> d[e[0]] != INF)
                        .mapToInt(e -> d[e[0]] + e[2])
                        .min().orElse(INF)))
                .toArray();
    }
}
LC 1514 · Path with Maximum Probability · forced
class Solution {
    public double maxProbability(int n, int[][] edges,
            double[] succProb, int start_node, int end_node) {
        // node -> [neighbour, edge index], both directions
        Map<Integer, List<int[]>> adj = IntStream
                .range(0, edges.length).boxed()
                .flatMap(i -> {
                    int[] e = edges[i];
                    return Stream.of(new int[]{ e[0], e[1], i },
                            new int[]{ e[1], e[0], i });
                })
                .collect(Collectors.groupingBy(e -> e[0]));
        double[] best = new double[n];
        best[start_node] = 1;
        Queue<double[]> pq = new PriorityQueue<>(
                (a, b) -> Double.compare(b[0], a[0]));
        pq.add(new double[]{ 1, start_node });
        // Dijkstra for the largest product. One loop drains and
        // refills the queue, and this stream IS that loop.
        Stream.iterate(pq.poll(), Objects::nonNull,
                       t -> pq.poll())
                .filter(t -> t[0] == best[(int) t[1]])  // fresh
                .forEach(t -> push(t, adj, succProb, best, pq));
        return best[end_node];
    }

    // queue every neighbour whose odds this path improves
    static void push(double[] t, Map<Integer, List<int[]>> adj,
                     double[] prob, double[] best,
                     Queue<double[]> pq) {
        adj.getOrDefault((int) t[1], List.of()).forEach(e -> {
            double p = t[0] * prob[e[2]];
            if (p > best[e[1]]) {
                best[e[1]] = p;
                pq.add(new double[]{ p, e[1] });
            }
        });
    }
}
LC 1631 · Path With Minimum Effort · stateful
class Solution {
    public int minimumEffortPath(int[][] heights) {
        // "Can I cross with no step steeper than e?" only gets
        // easier as e grows: binary-search e over 0 .. 10^6.
        return firstTrue(0, 1_000_000,
                         e -> crosses(heights, e));
    }

    // BFS by levels from the top-left, over gentle steps only.
    // claim tests AND marks a cell: the stateful lambda.
    static boolean crosses(int[][] h, int limit) {
        int m = h.length, n = h[0].length, end = m * n - 1;
        boolean[] seen = new boolean[m * n];
        seen[0] = true;
        BiPredicate<Integer, Integer> claim = (x, y) -> {
            int rise = h[y / n][y % n] - h[x / n][x % n];
            if (seen[y] || Math.abs(rise) > limit) return false;
            seen[y] = true;
            return true;
        };
        UnaryOperator<List<Integer>> next = l -> l
                .stream()
                .flatMap(x -> around(x, m, n)
                        .filter(y -> claim.test(x, y)).boxed())
                .toList();
        return Stream.iterate(List.of(0), l -> !l.isEmpty(),
                              next)
                .anyMatch(l -> seen[end]);
    }

    // the 4 neighbours of cell x = r * n + c, inside the grid
    static IntStream around(int x, int m, int n) {
        int c = x % n;
        int left = c > 0 ? x - 1 : -1;
        int right = c < n - 1 ? x + 1 : -1;
        return IntStream.of(x - n, x + n, left, right)
                .filter(y -> y >= 0 && y < m * n);
    }

    // smallest e in [lo, hi] with ok(e); assumes ok(hi)
    static int firstTrue(int lo, int hi, IntPredicate ok) {
        return Stream.iterate(new int[]{ lo, hi }, r -> {
                    int mid = (r[0] + r[1]) >>> 1;
                    return ok.test(mid)
                            ? new int[]{ r[0], mid }
                            : new int[]{ mid + 1, r[1] };
                })
                .filter(r -> r[0] == r[1])
                .findFirst().get()[0];
    }
}
LC 1334 · Find the City With the Smallest Number of Neighbors · clean
class Solution {
    // half of MAX_VALUE, so INF + INF still fits in an int
    static final int INF = Integer.MAX_VALUE / 2;

    // after k steps, d holds the shortest paths whose inner
    // nodes are all below k: one Floyd-Warshall step, pure
    record FW(int k, int[][] d) {
        FW next() {
            int n = d.length;
            int[][] e = IntStream.range(0, n)
                    .mapToObj(i -> IntStream.range(0, n)
                            .map(j -> Math.min(d[i][j],
                                    d[i][k] + d[k][j]))
                            .toArray())
                    .toArray(int[][]::new);
            return new FW(k + 1, e);
        }
    }

    public int findTheCity(int n, int[][] edges,
                           int distanceThreshold) {
        int[][] start = IntStream.range(0, n)
                .mapToObj(i -> IntStream.range(0, n)
                        .map(j -> i == j ? 0 : INF).toArray())
                .toArray(int[][]::new);
        // edges are distinct, so each write hits its own cells
        Arrays.stream(edges).forEach(e ->
                start[e[0]][e[1]] = start[e[1]][e[0]] = e[2]);
        int[][] d = Stream.iterate(new FW(0, start), FW::next)
                .skip(n).findFirst().get().d();
        // Fewest cities in reach; ties go to the larger index.
        int t = distanceThreshold;
        ToLongFunction<Integer> reach = i -> IntStream
                .range(0, n)
                .filter(j -> j != i && d[i][j] <= t)
                .count();
        Comparator<Integer> order = Comparator
                .comparingLong(reach)
                .thenComparing(Comparator.reverseOrder());
        return IntStream.range(0, n).boxed().min(order).get();
    }
}
LC 1976 · Number of Ways to Arrive at Destination · stateful
class Solution {
    static final long INF = Long.MAX_VALUE / 2;
    static final int MOD = 1_000_000_007;

    public int countPaths(int n, int[][] roads) {
        // both directions of every road, grouped by arrival
        Map<Integer, List<int[]>> into = Arrays.stream(roads)
                .flatMap(r -> Stream.of(r,
                        new int[]{ r[1], r[0], r[2] }))
                .collect(Collectors.groupingBy(e -> e[1]));
        long[] start = LongStream.range(0, n)
                .map(v -> v == 0 ? 0 : INF).toArray();
        // Distances: n - 1 pure Bellman-Ford rounds (n <= 200).
        long[] dist = Stream.iterate(start, d -> relax(d, into))
                .skip(n - 1).findFirst().get();
        // Ways, in order of distance: an edge u -> v lies on a
        // shortest path exactly when dist[u] + w == dist[v].
        BiPredicate<int[], Integer> tight =
                (e, v) -> dist[e[0]] + e[2] == dist[v];
        long[] ways = new long[n];
        ways[0] = 1;
        IntStream.range(1, n).boxed()
                .sorted(Comparator.comparingLong(v -> dist[v]))
                .forEach(v -> ways[v] = into.get(v).stream()
                        .filter(e -> tight.test(e, v))
                        .mapToLong(e -> ways[e[0]])
                        .reduce(0, (a, b) -> (a + b) % MOD));
        return (int) ways[n - 1];
    }

    // one round: every node takes its best incoming offer
    static long[] relax(long[] d,
                        Map<Integer, List<int[]>> into) {
        return IntStream.range(0, d.length)
                .mapToLong(v -> Math.min(d[v], into
                        .getOrDefault(v, List.of()).stream()
                        .mapToLong(e -> d[e[0]] + e[2])
                        .min().orElse(INF)))
                .toArray();
    }
}
The copy you cannot forget787's loop version must relax from a copy of the last round's array. Relaxing in place lets one round chain several flights, and that silently breaks the k-stops limit. The harness includes that exact trap: a three-flight route that in-place relaxation would accept with k = 1. A Stream.iterate step reads only its input and returns a new array, so the copy is not a detail you have to remember. It is the only thing the code can do.
Where streams stopDijkstra needs a priority queue that the same loop drains and refills. Pulling it through Stream.iterate(pq.poll(), …) works sequentially, but the forEach body is the whole algorithm, which is the loop dressed up as a stream. Bellman–Ford rounds are the clean alternative whenever V·E fits the budget, and here that holds up to n = 200.
