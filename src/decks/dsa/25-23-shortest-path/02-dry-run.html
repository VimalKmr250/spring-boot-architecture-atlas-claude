Why the stale check is written as d > dist[node]When a shorter route to a node is found, a new entry is pushed and the old one is left behind. The old entry carries a distance larger than the recorded one, so that single comparison identifies it. Using != would also work, but > reads as what it means: "this entry describes a route we have already beaten." A visited[] array is an equally valid alternative — pick one, not both.
