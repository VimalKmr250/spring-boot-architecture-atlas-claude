Two pointers are a state machine, and Stream.iterate runs state machines

Everything the loop carries fits in a small record: the pair (l, r), plus a water line for 42. Stream.iterate(seed, hasNext, next) steps it with a pure function, and the rest of the pipeline reads the states it emits: filter for a hit, mapToInt for a score, then max, min or sum. All six are clean and keep the loop's time bound. The only price is one small allocation per step.

LC 167 · Two Sum II — Input Array Is Sorted · clean
class Solution {
    record Pair(int l, int r) {
        int sum(int[] a) { return a[l] + a[r]; }
    }

    public int[] twoSum(int[] numbers, int target) {
        // A two-pointer loop is a state machine on (l, r).
        // Stream.iterate runs it; findFirst stops at the hit.
        return Stream.iterate(new Pair(0, numbers.length - 1),
                        p -> p.sum(numbers) < target
                                ? new Pair(p.l() + 1, p.r())
                                : new Pair(p.l(), p.r() - 1))
                .filter(p -> p.sum(numbers) == target)
                .findFirst()
                .map(p -> new int[]{ p.l() + 1, p.r() + 1 })
                .orElseThrow();
    }
}
LC 15 · 3Sum · clean
class Solution {
    // (l, r) closes in on a[l] + a[r] == want; a hit moves both
    record Pair(int l, int r) {
        Pair next(int[] a, int want) {
            int s = a[l] + a[r];
            return new Pair(s <= want ? l + 1 : l,
                            s >= want ? r - 1 : r);
        }
    }

    public List<List<Integer>> threeSum(int[] nums) {
        Arrays.sort(nums);
        // Fix the first value; keep every hit of the (l, r)
        // scan. distinct() replaces the duplicate-skip loops.
        return IntStream.range(0, nums.length - 2).boxed()
                .flatMap(i -> triplets(nums, i))
                .distinct()
                .toList();
    }

    static Stream<List<Integer>> triplets(int[] a, int i) {
        return Stream.iterate(new Pair(i + 1, a.length - 1),
                        p -> p.l() < p.r(),
                        p -> p.next(a, -a[i]))
                .filter(p -> a[p.l()] + a[p.r()] == -a[i])
                .map(p -> List.of(a[i], a[p.l()], a[p.r()]));
    }
}
LC 16 · 3Sum Closest · clean
class Solution {
    // One inner scan: first index i, then l and r closing in
    record Scan(int i, int l, int r) {
        int sum(int[] a) { return a[i] + a[l] + a[r]; }
        Scan next(int[] a, int target) {
            return sum(a) < target ? new Scan(i, l + 1, r)
                                   : new Scan(i, l, r - 1);
        }
    }

    public int threeSumClosest(int[] nums, int target) {
        Arrays.sort(nums);
        Comparator<Integer> byGap = Comparator.comparingInt(
                x -> Math.abs(x - target));
        // Every sum any scan visits; the answer is the nearest.
        return IntStream.range(0, nums.length - 2).boxed()
                .flatMap(i -> scan(nums, i, target))
                .map(s -> s.sum(nums))
                .min(byGap)
                .orElseThrow();
    }

    static Stream<Scan> scan(int[] a, int i, int target) {
        return Stream.iterate(new Scan(i, i + 1, a.length - 1),
                s -> s.l() < s.r(), s -> s.next(a, target));
    }
}
LC 18 · 4Sum · clean
class Solution {
    // (l, r) closes in on a[l] + a[r] == want; a hit moves both
    record Pair(int l, int r) {
        Pair next(int[] a, long want) {
            long s = (long) a[l] + a[r];
            return new Pair(s <= want ? l + 1 : l,
                            s >= want ? r - 1 : r);
        }
    }

    public List<List<Integer>> fourSum(int[] nums, int target) {
        Arrays.sort(nums);
        int n = nums.length;
        // Two flatMaps fix a pair of values; the (l, r) scan
        // finds the rest. Sums are long: 4 × 10⁹ overflows int.
        return IntStream.range(0, n).boxed()
                .flatMap(i -> IntStream.range(i + 1, n).boxed()
                        .flatMap(j -> rest(nums, i, j, target)))
                .distinct()
                .toList();
    }

    // every a[i], a[j], a[l], a[r] summing to target, j < l < r
    static Stream<List<Integer>> rest(int[] a, int i, int j,
                                      long target) {
        long want = target - a[i] - a[j];
        return Stream.iterate(new Pair(j + 1, a.length - 1),
                        p -> p.l() < p.r(),
                        p -> p.next(a, want))
                .filter(p -> (long) a[p.l()] + a[p.r()] == want)
                .map(p -> List.of(a[i], a[j],
                                  a[p.l()], a[p.r()]));
    }
}
LC 11 · Container With Most Water · clean
class Solution {
    record Pair(int l, int r) {}

    public int maxArea(int[] height) {
        // Start at both ends. The shorter wall moves in: no
        // container still using it can be any better. Every
        // state is a candidate, so score each and keep the max.
        return Stream.iterate(new Pair(0, height.length - 1),
                        p -> p.l() < p.r(),
                        p -> height[p.l()] < height[p.r()]
                                ? new Pair(p.l() + 1, p.r())
                                : new Pair(p.l(), p.r() - 1))
                .mapToInt(p -> (p.r() - p.l()) * Math.min(
                        height[p.l()], height[p.r()]))
                .max().getAsInt();
    }
}
LC 42 · Trapping Rain Water · clean
class Solution {
    // l, r close in; level = the water line reached so far
    record State(int l, int r, int level) {
        int lower(int[] h) { return Math.min(h[l], h[r]); }

        // water above the bar this state is about to settle
        int water(int[] h) {
            return Math.max(level, lower(h)) - lower(h);
        }

        State next(int[] h) {
            int lv = Math.max(level, lower(h));
            return h[l] < h[r] ? new State(l + 1, r, lv)
                               : new State(l, r - 1, lv);
        }
    }

    public int trap(int[] height) {
        // Each state settles the lower of its two end bars. The
        // water line only rises, so it is one running maximum.
        int n = height.length;
        return Stream.iterate(new State(0, n - 1, 0),
                              s -> s.l() <= s.r(),
                              s -> s.next(height))
                .mapToInt(s -> s.water(height))
                .sum();
    }
}
The idiom worth keepingStream.iterate(seed, hasNext, next) is the pure way to run any loop whose state fits in a record. Put the step on the record as a method, as every solution here does, and the pipeline reads like the loop's specification: the states, which ones to keep, what to compute from them. The same shape runs binary search, fast and slow pointers, and rolling DP later in this deck.
The one trapThe three-argument iterate calls next once more on the last state it emits, and only then does hasNext reject the result. That is harmless here, because next reads a[l] and a[r] of a state that already passed the test. When a step reads one index past its state, as a fold over an array does, use Stream.iterate(seed, f).skip(n).findFirst() instead: it applies f exactly n times.
