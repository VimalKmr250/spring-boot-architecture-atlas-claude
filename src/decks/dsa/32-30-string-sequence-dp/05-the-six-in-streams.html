Two strings, one table: the left cell is state unless the recurrence skips it

Every problem here fills a table indexed by prefixes of two strings, one row at a time. 1143, 583, 1312, 72 and 97 read the cell to their left in the same row, so the row is filled by a stream that reads what it just wrote: stateful, and correct only sequentially. 115 is the exception worth noticing. Its cell reads only the row above, so it folds into a fresh row per character with Stream.iterate, and that pipeline is clean.

LC 1143 · Longest Common Subsequence · stateful
class Solution {
    public int longestCommonSubsequence(String a, String b) {
        int n = b.length();
        int[][] rows = new int[2][n + 1];   // this row and the one above
        // cur[j] = a match ? up-left + 1 : max(up, left). "left" is this
        // row's previous entry, written a moment ago: sequential only.
        IntStream.rangeClosed(1, a.length()).forEach(i -> {
            int[] up = rows[(i + 1) % 2], cur = rows[i % 2];
            IntStream.rangeClosed(1, n).forEach(j -> cur[j] = a.charAt(i - 1) == b.charAt(j - 1)
                    ? up[j - 1] + 1 : Math.max(up[j], cur[j - 1]));
        });
        return rows[a.length() % 2][n];
    }
}
LC 583 · Delete Operation for Two Strings · stateful
class Solution {
    public int minDistance(String a, String b) {
        // Keep the longest common subsequence; delete everything else.
        return a.length() + b.length() - 2 * lcs(a, b);
    }

    // 1143's table: two alternating rows, reading "left".
    private static int lcs(String a, String b) {
        int n = b.length();
        int[][] rows = new int[2][n + 1];
        IntStream.rangeClosed(1, a.length()).forEach(i -> {
            int[] up = rows[(i + 1) % 2], cur = rows[i % 2];
            IntStream.rangeClosed(1, n).forEach(j -> cur[j] = a.charAt(i - 1) == b.charAt(j - 1)
                    ? up[j - 1] + 1 : Math.max(up[j], cur[j - 1]));
        });
        return rows[a.length() % 2][n];
    }
}
LC 1312 · Minimum Insertion Steps · stateful
class Solution {
    public int minInsertions(String s) {
        // The longest palindromic subsequence stays; every other
        // character needs a mirror inserted on the other side.
        return s.length() - lcs(s, new StringBuilder(s).reverse().toString());
    }

    // 1143's table: two alternating rows, reading "left".
    private static int lcs(String a, String b) {
        int n = b.length();
        int[][] rows = new int[2][n + 1];
        IntStream.rangeClosed(1, a.length()).forEach(i -> {
            int[] up = rows[(i + 1) % 2], cur = rows[i % 2];
            IntStream.rangeClosed(1, n).forEach(j -> cur[j] = a.charAt(i - 1) == b.charAt(j - 1)
                    ? up[j - 1] + 1 : Math.max(up[j], cur[j - 1]));
        });
        return rows[a.length() % 2][n];
    }
}
LC 72 · Edit Distance · stateful
class Solution {
    public int minDistance(String a, String b) {
        int n = b.length();
        int[][] rows = new int[2][n + 1];
        Arrays.setAll(rows[0], j -> j);     // row 0: insert j characters
        // cur[j] = a match ? up-left : 1 + min(up-left, up, left), where
        // "left" was written a moment ago in this row: sequential only.
        IntStream.rangeClosed(1, a.length()).forEach(i -> {
            int[] up = rows[(i + 1) % 2], cur = rows[i % 2];
            cur[0] = i;                      // column 0: delete i characters
            IntStream.rangeClosed(1, n).forEach(j -> cur[j] = a.charAt(i - 1) == b.charAt(j - 1)
                    ? up[j - 1] : 1 + Math.min(up[j - 1], Math.min(up[j], cur[j - 1])));
        });
        return rows[a.length() % 2][n];
    }
}
LC 115 · Distinct Subsequences · clean
class Solution {
    public int numDistinct(String s, String t) {
        int n = t.length();
        int[] start = new int[n + 1];
        start[0] = 1;                       // the empty t occurs once in anything
        // ways[j] after one more character of s reads only the PREVIOUS
        // row: ways[j] + (match ? ways[j - 1] : 0). A fresh row: clean.
        record Row(int i, int[] ways) {}
        return Stream.iterate(new Row(0, start), r -> new Row(r.i() + 1,
                        IntStream.rangeClosed(0, n).map(j -> r.ways()[j]
                                + (j > 0 && s.charAt(r.i()) == t.charAt(j - 1) ? r.ways()[j - 1] : 0))
                                .toArray()))
                .skip(s.length()).findFirst().get().ways()[n];
    }
}
LC 97 · Interleaving String · stateful
class Solution {
    public boolean isInterleave(String s1, String s2, String s3) {
        int m = s1.length(), n = s2.length();
        if (m + n != s3.length()) return false;
        boolean[] ok = new boolean[n + 1];
        // ok[j] for row i: s3's next character came from s1 (the row above,
        // ok[j]) or from s2 (the left cell, ok[j - 1], written a moment ago).
        IntStream.rangeClosed(0, m).forEach(i ->
                IntStream.rangeClosed(0, n).forEach(j -> ok[j] = i == 0 && j == 0
                        || i > 0 && ok[j] && s1.charAt(i - 1) == s3.charAt(i + j - 1)
                        || j > 0 && ok[j - 1] && s2.charAt(j - 1) == s3.charAt(i + j - 1)));
        return ok[n];
    }
}
Two rows, alternatingrows[i % 2] is the row being built and rows[(i + 1) % 2] the one above, so the table costs two rows of memory. The left cell sits in the row being built, written one step earlier by the same stream, so these are sequential only. 72 also writes its base case, cur[0] = i, before the inner stream starts, because the left cell of column 1 is that base case.
115 reads only the row aboveIts next row depends on ways[j] and ways[j - 1] of the previous row and never on its own, so each step maps the old row to a new one. The in-place loop gets the same effect by walking j downwards; the fresh row makes the direction irrelevant, the same trade the knapsack slide makes. LeetCode guarantees the answer fits in an int, and because the table only adds, intermediate overflow wraps and cancels out by the end.
