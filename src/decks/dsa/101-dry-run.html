Why there is no explicit base caseThe recursion terminates because start eventually reaches nums.length and the loop body never executes. Adding if (start == n) return; would be harmless but redundant — the loop is its own base case. Problems that do need one, such as combinations of a fixed size k, use it to decide when to record rather than when to stop.
