Recursing through a stream eats the stack, so walk the levels instead

The natural stream DFS, Stream.of(left, right).mapToInt(this::depth), is pure, short and fragile. Every level of recursion now costs several frames of pipeline machinery instead of one, and LeetCode's skewed test trees go deep: 10⁴ nodes for 104 and 543, 3·10⁴ for 124. So these six walk the tree iteratively, level by level with Stream.iterate, and each node carries in a record whatever the DFS would have passed down. The two that need children before parents (543 and 124) read the levels bottom-up into a map.

LC 104 · Maximum Depth of Binary Tree · clean
class Solution {
    public int maxDepth(TreeNode root) {
        // The depth is the number of levels. Nothing recurses,
        // so a 10⁴-deep skewed tree costs no stack at all.
        return (int) levels(root).count();
    }

    // ---- the same level walk in 104, 226, 543 and 124 ----
    static Stream<List<TreeNode>> levels(TreeNode root) {
        List<TreeNode> first = root == null ? List.of()
                                            : List.of(root);
        return Stream.iterate(first, l -> !l.isEmpty(),
                              Solution::below);
    }

    // the next level down: every child of this one, in order
    static List<TreeNode> below(List<TreeNode> level) {
        return level.stream()
                .flatMap(n -> Stream.of(n.left, n.right))
                .filter(Objects::nonNull)
                .toList();
    }
}
LC 226 · Invert Binary Tree · clean
class Solution {
    public TreeNode invertTree(TreeNode root) {
        // Collect every node first, then swap each one's
        // children: the walk is over before anything moves.
        levels(root).flatMap(List::stream).toList()
                .forEach(n -> {
                    TreeNode t = n.left;
                    n.left = n.right;
                    n.right = t;
                });
        return root;
    }

    // ---- the same level walk in 104, 226, 543 and 124 ----
    static Stream<List<TreeNode>> levels(TreeNode root) {
        List<TreeNode> first = root == null ? List.of()
                                            : List.of(root);
        return Stream.iterate(first, l -> !l.isEmpty(),
                              Solution::below);
    }

    // the next level down: every child of this one, in order

                .toList();
    }
}
LC 112 · Path Sum · clean
class Solution {
    // a node, with the sum of the path from the root to it
    record At(TreeNode node, int sum) {
        boolean hits(int target) {
            return node.left == null && node.right == null
                    && sum == target;
        }
        Stream<At> children() {
            return Stream.of(node.left, node.right)
                    .filter(Objects::nonNull)
                    .map(c -> new At(c, sum + c.val));
        }
    }

    public boolean hasPathSum(TreeNode root, int targetSum) {
        if (root == null) return false;
        // What recursion would pass down, each node carries.
        At start = new At(root, root.val);
        return Stream.iterate(List.of(start), l -> !l.isEmpty(),
                        l -> l.stream().flatMap(At::children)
                                .toList())
                .flatMap(List::stream)
                .anyMatch(a -> a.hits(targetSum));
    }
}
LC 113 · Path Sum II · clean
class Solution {
    // a node, its root-to-node sum, and the path itself
    record At(TreeNode node, int sum, List<Integer> path) {
        boolean hits(int target) {
            return node.left == null && node.right == null
                    && sum == target;
        }
        Stream<At> children() {
            return Stream.of(node.left, node.right)
                    .filter(Objects::nonNull)
                    .map(c -> new At(c, sum + c.val,
                                     with(c.val)));
        }
        List<Integer> with(int v) {
            return Stream.concat(path.stream(), Stream.of(v))
                    .toList();
        }
    }

    public List<List<Integer>> pathSum(TreeNode root,
                                       int targetSum) {
        if (root == null) return List.of();
        // Each node carries its own immutable path, so there is
        // nothing to undo: no add-then-remove backtracking.
        At start = new At(root, root.val, List.of(root.val));
        return Stream.iterate(List.of(start), l -> !l.isEmpty(),
                        l -> l.stream().flatMap(At::children)
                                .toList())
                .flatMap(List::stream)
                .filter(a -> a.hits(targetSum))
                .map(At::path)
                .toList();
    }
}
LC 543 · Diameter of Binary Tree · stateful
class Solution {
    public int diameterOfBinaryTree(TreeNode root) {
        List<List<TreeNode>> lv = levels(root).toList();
        int d = lv.size();
        // Heights need both children first, so fill a map from
        // the deepest level up. That fill order is the state.
        Map<TreeNode, Integer> h = new HashMap<>();
        IntStream.range(0, d).mapToObj(i -> lv.get(d - 1 - i))
                .flatMap(List::stream)
                .forEach(n -> h.put(n, 1 + Math.max(
                        h.getOrDefault(n.left, 0),
                        h.getOrDefault(n.right, 0))));
        // The longest path through n uses both child heights.
        return h.keySet().stream()
                .mapToInt(n -> h.getOrDefault(n.left, 0)
                        + h.getOrDefault(n.right, 0))
                .max().orElse(0);
    }

    // ---- the same level walk in 104, 226, 543 and 124 ----
    static Stream<List<TreeNode>> levels(TreeNode root) {
        List<TreeNode> first = root == null ? List.of()
                                            : List.of(root);
        return Stream.iterate(first, l -> !l.isEmpty(),
                              Solution::below);
    }

    // the next level down: every child of this one, in order
    static List<TreeNode> below(List<TreeNode> level) {
        return level.stream()
                .flatMap(n -> Stream.of(n.left, n.right))
                .filter(Objects::nonNull)
                .toList();
    }
}
LC 124 · Binary Tree Maximum Path Sum · stateful
class Solution {
    public int maxPathSum(TreeNode root) {
        List<List<TreeNode>> lv = levels(root).toList();
        int d = lv.size();
        // gain(n) = the best downward path that starts at n,
        // filled deepest level first. A negative child gain is
        // simply not taken.
        Map<TreeNode, Integer> gain = new HashMap<>();
        ToIntFunction<TreeNode> g =
                n -> n == null ? 0 : Math.max(0, gain.get(n));
        IntStream.range(0, d).mapToObj(i -> lv.get(d - 1 - i))
                .flatMap(List::stream)
                .forEach(n -> gain.put(n, n.val
                        + Math.max(g.applyAsInt(n.left),
                                   g.applyAsInt(n.right))));
        // The best path bends at some n and takes both sides.
        return gain.keySet().stream()
                .mapToInt(n -> n.val + g.applyAsInt(n.left)
                        + g.applyAsInt(n.right))
                .max().getAsInt();
    }

    // ---- the same level walk in 104, 226, 543 and 124 ----
    static Stream<List<TreeNode>> levels(TreeNode root) {
        List<TreeNode> first = root == null ? List.of()
                                            : List.of(root);
        return Stream.iterate(first, l -> !l.isEmpty(),
                              Solution::below);
    }

    // the next level down: every child of this one, in order
    static List<TreeNode> below(List<TreeNode> level) {
        return level.stream()
                .flatMap(n -> Stream.of(n.left, n.right))
                .filter(Objects::nonNull)
                .toList();
    }
}
Measured, not guessedOn a 1 MB thread stack with OpenJDK 25, a skewed tree gave these limits. Plain recursive maxDepth survived about 41,000 levels. The version recursing through Stream.of(left, right).mapToInt(…) survived about 10,000 once the JIT had compiled it, and only 1,500 to 3,000 in a fresh JVM before it had. Every solution here runs 10⁴ to 3·10⁴-deep skewed trees on that same 1 MB stack without trouble, because nothing in them recurses.
Return versus record, in stream form104, 112 and 113 are "pass something down", so the value rides in the record. 543 and 124 are "return one thing, record another", and returning needs children before parents. Reading the levels bottom-up gives that order without recursion, at the cost of a map. That map is exactly what makes those two stateful.
