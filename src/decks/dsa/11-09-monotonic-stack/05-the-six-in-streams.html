No stack: jump along the answers you have already found

A monotonic stack is state that every element both reads and changes, and no Java 17 stream stage can hold that. But the stack's contents can be read out of the answer array itself. To find the next warmer day after i, start at i + 1 and keep jumping to that day's own next warmer day: every day a jump skips was no warmer than the day it left from. Fill the answers right to left, and each one becomes a short, pure chain over answers already written, with the total work still O(n).

LC 739 · Daily Temperatures · stateful
class Solution {
    public int[] dailyTemperatures(int[] t) {
        int n = t.length;
        int[] next = new int[n];   // next warmer day, or n
        // Right to left. From i + 1, jump along answers already
        // found: a jump from j to next[j] skips only days no
        // warmer than t[j], so none of them can beat t[i].
        IntStream.iterate(n - 1, i -> i >= 0, i -> i - 1)
                .forEach(i -> next[i] = IntStream
                        .iterate(i + 1, j -> next[j])
                        .filter(j -> j == n || t[j] > t[i])
                        .findFirst().getAsInt());
        return IntStream.range(0, n)
                .map(i -> next[i] == n ? 0 : next[i] - i)
                .toArray();
    }
}
LC 496 · Next Greater Element I · clean
class Solution {
    public int[] nextGreaterElement(int[] nums1, int[] nums2) {
        int n = nums2.length;
        Map<Integer, Integer> pos = IntStream.range(0, n)
                .boxed()
                .collect(Collectors.toMap(i -> nums2[i],
                                          i -> i));
        // At most 1000 × 1000: scan right of each value's
        // position for the first greater one. O(m·n), and pure.
        return Arrays.stream(nums1)
                .map(x -> IntStream.range(pos.get(x) + 1, n)
                        .map(j -> nums2[j])
                        .filter(v -> v > x)
                        .findFirst().orElse(-1))
                .toArray();
    }
}
LC 503 · Next Greater Element II · stateful
class Solution {
    public int[] nextGreaterElements(int[] nums) {
        int n = nums.length, m = 2 * n;
        // Unroll the circle: position p holds nums[p % n]. Then
        // it is 739's jumps over 2n positions, right to left.
        int[] next = new int[m];   // next greater, or m
        IntStream.iterate(m - 1, i -> i >= 0, i -> i - 1)
                .forEach(i -> next[i] = IntStream
                        .iterate(i + 1, j -> next[j])
                        .filter(j -> j == m
                                || nums[j % n] > nums[i % n])
                        .findFirst().getAsInt());
        return IntStream.range(0, n)
                .map(i -> next[i] == m ? -1 : nums[next[i] % n])
                .toArray();
    }
}
LC 901 · Online Stock Span · stateful
class StockSpanner {
    private final List<Integer> price = new ArrayList<>();
    // prev.get(i) = the last day before i with a higher price
    private final List<Integer> prev = new ArrayList<>();

    public int next(int p) {
        int i = price.size();
        // Jump left along answers already stored. Each day a
        // jump skips was <= the day it left from, so <= p too.
        int j = IntStream.iterate(i - 1, k -> prev.get(k))
                .filter(k -> k < 0 || price.get(k) > p)
                .findFirst().getAsInt();
        price.add(p);
        prev.add(j);
        return i - j;
    }
}
LC 84 · Largest Rectangle in Histogram · stateful
class Solution {
    public int largestRectangleArea(int[] h) {
        int n = h.length;
        int[] left = new int[n];    // previous lower bar, or -1
        int[] right = new int[n];   // next lower bar, or n
        // Two jump fills in opposite directions, as in 739.
        IntStream.range(0, n)
                .forEach(i -> left[i] = IntStream
                        .iterate(i - 1, j -> left[j])
                        .filter(j -> j < 0 || h[j] < h[i])
                        .findFirst().getAsInt());
        IntStream.iterate(n - 1, i -> i >= 0, i -> i - 1)
                .forEach(i -> right[i] = IntStream
                        .iterate(i + 1, j -> right[j])
                        .filter(j -> j == n || h[j] < h[i])
                        .findFirst().getAsInt());
        // Bar i is the lowest across (left[i], right[i]).
        return IntStream.range(0, n)
                .map(i -> h[i] * (right[i] - left[i] - 1))
                .max().getAsInt();
    }
}
LC 85 · Maximal Rectangle · stateful
class Solution {
    // Column heights of the '1' runs ending at row "row" - 1
    record Hist(int row, int[] h) {
        Hist next(char[][] m) {
            int[] nh = IntStream.range(0, h.length)
                    .map(c -> m[row][c] == '1' ? h[c] + 1 : 0)
                    .toArray();
            return new Hist(row + 1, nh);
        }
    }

    public int maximalRectangle(char[][] matrix) {
        // Each row's histogram is a pure function of the one
        // above it; then every row is 84 on its own.
        int cols = matrix[0].length;
        return Stream.iterate(new Hist(0, new int[cols]),
                              s -> s.next(matrix))
                .skip(1)
                .limit(matrix.length)
                .mapToInt(s -> largest(s.h()))
                .max().getAsInt();
    }

    // 84, unchanged: jump fills for the lower bars either side
    static int largest(int[] h) {
        int n = h.length;
        int[] left = new int[n], right = new int[n];
        IntStream.range(0, n)
                .forEach(i -> left[i] = IntStream
                        .iterate(i - 1, j -> left[j])
                        .filter(j -> j < 0 || h[j] < h[i])
                        .findFirst().getAsInt());
        IntStream.iterate(n - 1, i -> i >= 0, i -> i - 1)
                .forEach(i -> right[i] = IntStream
                        .iterate(i + 1, j -> right[j])
                        .filter(j -> j == n || h[j] < h[i])
                        .findFirst().getAsInt());
        return IntStream.range(0, n)
                .map(i -> h[i] * (right[i] - left[i] - 1))
                .max().getAsInt();
    }
}
Why the jumps are still O(n)A jump from j to next[j] skips a block that every later chain skips as well, so no element is walked over twice. It is the stack's amortisation argument, with the answer array playing the stack's part. The fill order is what makes it work: right to left for "next", left to right for "previous". The harness checks sorted, reverse-sorted, flat and sawtooth inputs of 10⁵, and each runs in milliseconds.
Stateful is the honest labelforEach writes next[i] and later iterations read it. That makes next a memo table, and the order of the outer stream carries the correctness, so never make it parallel. What the jumps buy you is that each answer comes from a pure inner pipeline over finished entries, rather than a while loop mutating a Deque inside a lambda. In the interview, still write the stack: it is the version the interviewer is looking for.
