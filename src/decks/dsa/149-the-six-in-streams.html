Fixed lookback is a record; a table that reads itself is state

When a recurrence looks back a fixed number of steps, the whole state fits in a small record, and Stream.iterate(seed, step).skip(n) applies the step exactly n times. That covers 70, 198 and 213. Each step returns a new record, so all three are clean. 322, 279 and 300 look back an unbounded distance, so they need the whole table. Each entry is still a clean pipeline, a min or a max over the choices, but it reads entries that earlier elements of the same stream wrote. That is state, and it makes them correct only sequentially.

LC 70 · Climbing Stairs · clean
class Solution {
    public int climbStairs(int n) {
        // (ways to reach i - 1, ways to reach i). One more step
        // shifts the pair: (a, b) becomes (b, a + b).
        record Ways(int prev, int cur) {
            Ways climb() { return new Ways(cur, prev + cur); }
        }
        return Stream.iterate(new Ways(1, 1), Ways::climb)
                .skip(n - 1).findFirst().get().cur();
    }
}
LC 198 · House Robber · clean
class Solution {
    public int rob(int[] nums) {
        return robRange(nums, 0, nums.length);
    }

    // f(i) = max(f(i - 1), f(i - 2) + a[i]): cur and prev are
    // the best totals for the houses before i and before i - 1.
    private record Best(int i, int prev, int cur) {
        Best next(int[] a) {
            int best = Math.max(cur, prev + a[i]);
            return new Best(i + 1, cur, best);
        }
    }

    private static int robRange(int[] a, int from, int to) {
        Best start = new Best(from, 0, 0);
        return Stream.iterate(start, b -> b.next(a))
                .skip(to - from).findFirst().get().cur();
    }
}
LC 213 · House Robber II · clean
class Solution {
    public int rob(int[] nums) {
        int n = nums.length;
        // The first and last houses touch: rob all but the last
        // or all but the first, and keep the better total.
        return n == 1 ? nums[0]
                : Math.max(robRange(nums, 0, n - 1),
                           robRange(nums, 1, n));
    }

    // f(i) = max(f(i - 1), f(i - 2) + a[i]): cur and prev are
    // the best totals for the houses before i and before i - 1.
    private record Best(int i, int prev, int cur) {
        Best next(int[] a) {
            int best = Math.max(cur, prev + a[i]);
            return new Best(i + 1, cur, best);
        }
    }

    private static int robRange(int[] a, int from, int to) {
        Best start = new Best(from, 0, 0);
        return Stream.iterate(start, b -> b.next(a))
                .skip(to - from).findFirst().get().cur();
    }
}
LC 322 · Coin Change · stateful
class Solution {
    public int coinChange(int[] coins, int amount) {
        // best[a]: the fewest coins making a, or -1. It reads
        // best[a - c], which earlier elements of this stream
        // wrote, so it is correct only sequentially.
        int[] best = new int[amount + 1];
        IntStream.rangeClosed(1, amount).forEach(a ->
                best[a] = Arrays.stream(coins)
                        .filter(c -> c <= a && best[a - c] >= 0)
                        .map(c -> best[a - c] + 1)
                        .min().orElse(-1));
        return best[amount];
    }
}
LC 279 · Perfect Squares · stateful
class Solution {
    public int numSquares(int n) {
        int[] best = new int[n + 1];
        // best[i] = 1 + min over j of best[i - j*j]. Like 322,
        // it reads entries that this stream wrote earlier.
        IntStream.rangeClosed(1, n).forEach(i -> best[i] = 1 +
                IntStream.rangeClosed(1, (int) Math.sqrt(i))
                        .map(j -> best[i - j * j])
                        .min().getAsInt());
        return best[n];
    }
}
LC 300 · Longest Increasing Subsequence · stateful
class Solution {
    public int lengthOfLIS(int[] nums) {
        int n = nums.length;
        int[] lis = new int[n];
        // lis[i] is the longest increasing run ending at i.
        // It reads lis[j] for j < i, which this stream wrote.
        IntStream.range(0, n).forEach(i -> lis[i] = 1 +
                IntStream.range(0, i)
                        .filter(j -> nums[j] < nums[i])
                        .map(j -> lis[j])
                        .max().orElse(0));
        return Arrays.stream(lis).max().getAsInt();
    }
}
skip(n) is the loop counterStream.iterate(seed, step).skip(n).findFirst() returns the seed after exactly n steps. It is the stream spelling of for (int i = 0; i < n; i++) state = step(state);. 70 starts from (ways to 0, ways to 1), so n − 1 steps reach (ways to n − 1, ways to n). The record in 198 carries the index i as well as the two totals, which is what lets 213 run the same fold over two index ranges without copying the array.
The table is the stateforEach(a -> best[a] = …) is correct only because a sequential stream visits a in increasing order, so best[a - c] is already filled when best[a] needs it. In parallel, some entries would read zeros that have not been written yet and report wrong answers. That is the honest cost of streaming an unbounded-lookback DP. The pipeline inside each entry is still the clearest statement of the recurrence, but the loop around it is the same code with the ordering made explicit.
