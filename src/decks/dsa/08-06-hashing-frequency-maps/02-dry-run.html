Longest consecutive sequence, in O(n), on unsorted input. Sorting would be O(n log n) and is explicitly ruled out by the follow-up. The trick is a single guard: only start counting from a value that begins a run — one whose predecessor is absent.

The amortisation argument, stated properlyA value is walked over only by the head of its own run, and every value belongs to exactly one run. So across the entire algorithm the inner while executes at most n times in total — not n times per element. Total work is O(n) probes for the head guard plus O(n) for all walks combined. Being able to state it is what turns "I think it's O(n)" into an answer the interviewer accepts.
