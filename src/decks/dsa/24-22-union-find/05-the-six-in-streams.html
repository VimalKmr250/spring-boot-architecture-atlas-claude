Union-find is mutable by design; the stream decides which edges it sees

A disjoint-set forest is a mutable structure by definition: every union rewires a parent link. So all six of these are stateful, and honestly labelled so. What the stream adds is the shape of the question. It can count the unions that merged something (provinces = n − merges), find the first edge whose union fails (684), or group indices by their root (1202). Here find is a read-only IntStream.iterate up the parent links, and union by size keeps those walks O(log n).

LC 547 · Number of Provinces · stateful
class Solution {
    public int findCircleNum(int[][] isConnected) {
        int n = isConnected.length;
        DSU dsu = new DSU(n);
        // Every city starts alone, and each union that merges
        // two groups removes one: provinces = n - merges.
        long merges = IntStream.range(0, n).boxed()
                .flatMap(i -> IntStream.range(i + 1, n)
                        .filter(j -> isConnected[i][j] == 1)
                        .mapToObj(j -> new int[]{ i, j }))
                .filter(e -> dsu.union(e[0], e[1]))
                .count();
        return (int) (n - merges);
    }

    // ---- the same union-find in all six ----
    record DSU(int[] parent, int[] size) {
        DSU(int n) {
            this(IntStream.range(0, n).toArray(),
                 IntStream.range(0, n).map(i -> 1).toArray());
        }

        // Walk the parent links up to the root; writes nothing.
        int find(int x) {
            return IntStream.iterate(x, y -> parent[y])
                    .filter(y -> parent[y] == y)
                    .findFirst().getAsInt();
        }

        // Union by size keeps every tree O(log n) deep. The
        // two writes here are the only state in the solution.
        boolean union(int a, int b) {
            int ra = find(a), rb = find(b);
            if (ra == rb) return false;
            int big = size[ra] >= size[rb] ? ra : rb;
            int small = big == ra ? rb : ra;
            parent[small] = big;
            size[big] += size[small];
            return true;
        }
    }
}
LC 684 · Redundant Connection · stateful
class Solution {
    public int[] findRedundantConnection(int[][] edges) {
        DSU dsu = new DSU(edges.length + 1);
        // The first edge whose ends are already joined closes
        // the cycle: the last cycle edge in input order.
        return Arrays.stream(edges)
                .filter(e -> !dsu.union(e[0], e[1]))
                .findFirst().get();

LC 1319 · Number of Operations to Make Network Connected · stateful
class Solution {
    public int makeConnected(int n, int[][] connections) {
        if (connections.length < n - 1) return -1;  // too few
        DSU dsu = new DSU(n);
        long merges = Arrays.stream(connections)
                .filter(c -> dsu.union(c[0], c[1]))
                .count();
        // With enough spare cables, each extra component costs
        // exactly one move: components - 1.

LC 990 · Satisfiability of Equality Equations · stateful
class Solution {
    public boolean equationsPossible(String[] equations) {
        DSU dsu = new DSU(26);
        // Every "==" first, so the groups are final ...
        Arrays.stream(equations)
                .filter(e -> e.charAt(1) == '=')
                .forEach(e -> dsu.union(e.charAt(0) - 'a',
                                        e.charAt(3) - 'a'));
        // ... then no "!=" may join two letters of one group.
        return Arrays.stream(equations)
                .filter(e -> e.charAt(1) == '!')
                .allMatch(e -> dsu.find(e.charAt(0) - 'a')
                        != dsu.find(e.charAt(3) - 'a'));

LC 1202 · Smallest String With Swaps · stateful
class Solution {
    public String smallestStringWithSwaps(String s,
            List<List<Integer>> pairs) {
        int n = s.length();
        DSU dsu = new DSU(n);
        pairs.forEach(p -> dsu.union(p.get(0), p.get(1)));
        // Indices that share a root can be permuted freely, so
        // each group gets its own letters back, sorted.
        char[] out = new char[n];
        IntStream.range(0, n).boxed()
                .collect(Collectors.groupingBy(dsu::find))
                .values()
                .forEach(idx -> {
                    List<Character> letters = idx.stream()
                            .map(s::charAt).sorted().toList();
                    IntStream.range(0, idx.size())
                            .forEach(k -> out[idx.get(k)] =
                                    letters.get(k));
                });
        return new String(out);
    }

    // ---- the same union-find in all six ----
    record DSU(int[] parent, int[] size) {
        DSU(int n) {

LC 1579 · Remove Max Number of Edges to Keep Graph Fully Traversable · stateful
class Solution {
    public int maxNumEdgesToRemove(int n, int[][] edges) {
        DSU alice = new DSU(n + 1), bob = new DSU(n + 1);
        // Shared edges first: one can replace two private ones.
        // | not ||: both forests must see every shared edge.
        long shared = Arrays.stream(edges)
                .filter(e -> e[0] == 3)
                .filter(e -> alice.union(e[1], e[2])
                           | bob.union(e[1], e[2]))
                .count();
        long a = Arrays.stream(edges).filter(e -> e[0] == 1)
                .filter(e -> alice.union(e[1], e[2])).count();
        long b = Arrays.stream(edges).filter(e -> e[0] == 2)
                .filter(e -> bob.union(e[1], e[2])).count();
        // Each person needs n - 1 merges to span every node.
        if (shared + a != n - 1 || shared + b != n - 1)
            return -1;
        return (int) (edges.length - shared - a - b);
    }

    // ---- the same union-find in all six ----
    record DSU(int[] parent, int[] size) {
        DSU(int n) {
            this(IntStream.range(0, n).toArray(),
                 IntStream.range(0, n).map(i -> 1).toArray());
        }

        // Walk the parent links up to the root; writes nothing.
        int find(int x) {
            return IntStream.iterate(x, y -> parent[y])
                    .filter(y -> parent[y] == y)
                    .findFirst().getAsInt();
        }

        // Union by size keeps every tree O(log n) deep. The
        // two writes here are the only state in the solution.
        boolean union(int a, int b) {
            int ra = find(a), rb = find(b);
            if (ra == rb) return false;
            int big = size[ra] >= size[rb] ? ra : rb;
            int small = big == ra ? rb : ra;
            parent[small] = big;
            size[big] += size[small];
            return true;
        }
    }
}
Why | and not ||In 1579, every shared edge must be offered to both forests. alice.union(…) || bob.union(…) would skip Bob every time Alice's union returned true. The short-circuit that makes || fast becomes a bug when both sides have effects. The non-short-circuit | always evaluates both, and that is the whole point of using it here.
A find that writes nothingfind walks the parent links with IntStream.iterate and changes nothing, so the only writes in each solution are the two lines inside union. Union by size keeps every tree O(log n) deep, which is what path compression would otherwise buy. The price is that the loop's α(n) per operation becomes log n here, which is still milliseconds at 10⁵ edges.
