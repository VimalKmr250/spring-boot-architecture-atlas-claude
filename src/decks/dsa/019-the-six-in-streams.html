A window cannot slide in a stream, so change the question

A sliding window is two pointers plus a count that both of them update: state carried from one element to the next, which no Java 17 stream stage can hold. So each pipeline below asks a question with no moving window in it: how far a run goes from each start, where each letter occurs, which indices a window may swallow. Only 904 carries the loop's state itself, in a record handed from step to step.

LC 3 · Longest Substring Without Repeating Characters · stateful
class Solution {
    public int lengthOfLongestSubstring(String s) {
        // From each start: how long do letters stay distinct?
        // A distinct run is at most ~95 printable characters,
        // so every inner stream stops early: O(n·k), not O(n²).
        return IntStream.range(0, s.length())
                .map(l -> {
                    Set<Integer> seen = new HashSet<>();
                    return (int) IntStream.range(l, s.length())
                            .map(s::charAt)
                            .takeWhile(seen::add)   // STATE
                            .count();
                })
                .max().orElse(0);
    }
}
LC 209 · Minimum Size Subarray Sum · stateful
class Solution {
    public int minSubArrayLen(int target, int[] nums) {
        // p[i] = sum of the first i values. Java 17 has no
        // scan, so the running total is a stateful map.
        int[] run = {0};
        int[] p = IntStream.concat(IntStream.of(0),
                Arrays.stream(nums).map(v -> run[0] += v))
                .toArray();
        // Values are positive, so p strictly increases: for
        // each end r, binary-search the latest start l that
        // still leaves p[r] - p[l] >= target.
        return IntStream.rangeClosed(1, nums.length)
                .filter(r -> p[r] >= target)
                .map(r -> {
                    int key = p[r] - target;
                    int i = Arrays.binarySearch(p, 0, r, key);
                    return r - (i >= 0 ? i : -i - 2);
                })
                .min().orElse(0);
    }
}
LC 424 · Longest Repeating Character Replacement · clean
class Solution {
    public int characterReplacement(String s, int k) {
        int n = s.length();
        // Fix the letter c the window is made of. Its "other"
        // indices are the ones to replace, and the best window
        // swallows k of them: from just after other[i-1] to
        // just before other[i+k]. Nothing slides.
        return IntStream.rangeClosed('A', 'Z').map(c -> {
            int[] other = IntStream.range(0, n)
                    .filter(i -> s.charAt(i) != c).toArray();
            int m = other.length;
            return IntStream.rangeClosed(0, Math.max(0, m - k))
                    .map(i -> (i + k < m ? other[i + k] : n)
                            - (i > 0 ? other[i - 1] : -1) - 1)
                    .max().getAsInt();
        }).max().getAsInt();
    }
}
LC 904 · Fruit Into Baskets · clean
class Solution {
    // b = the last fruit, a = the other type in the window,
    // run = b's ending the window, len = the window's length
    record State(int i, int a, int b,
                 int run, int len, int best) {
        State eat(int f) {
            int newLen = f == a || f == b ? len + 1 : run + 1;
            return new State(i + 1, f == b ? a : b, f,
                             f == b ? run + 1 : 1,
                             newLen, Math.max(best, newLen));
        }
    }

    public int totalFruit(int[] fruits) {
        // One pure step per fruit. A third type keeps only the
        // trailing run of b, so the window restarts at run + 1.
        return Stream.iterate(new State(0, -1, -1, 0, 0, 0),
                              s -> s.eat(fruits[s.i()]))
                .skip(fruits.length)
                .findFirst().get().best();
    }
}
LC 567 · Permutation in String · clean
class Solution {
    public boolean checkInclusion(String s1, String s2) {
        int m = s1.length();
        int[] need = counts(s1);
        // Every window of width |s1|, counted from scratch:
        // O(n·m), at most 2.5·10⁷ steps at these limits.
        return IntStream.rangeClosed(0, s2.length() - m)
                .anyMatch(i -> Arrays.equals(
                        counts(s2.substring(i, i + m)), need));
    }

    // A mutable reduction with a real combiner: parallel-safe.
    private static int[] counts(String s) {
        return s.chars().collect(() -> new int[26],
                (a, c) -> a[c - 'a']++,
                (a, b) -> Arrays.setAll(a, i -> a[i] + b[i]));
    }
}
LC 76 · Minimum Window Substring · clean
class Solution {
    private static final int NONE = Integer.MAX_VALUE;
    private int[][] at;    // at[c] = indices of c, ascending
    private int[] need;    // need[c] = copies of c in t
    private int[] letters; // the letters t needs

    public String minWindow(String s, String t) {
        int n = s.length();
        at = IntStream.range(0, 128)
                .mapToObj(c -> IntStream.range(0, n)
                        .filter(i -> s.charAt(i) == c)
                        .toArray())
                .toArray(int[][]::new);
        need = t.chars().collect(() -> new int[128],
                (a, c) -> a[c]++,
                (a, b) -> Arrays.setAll(a, i -> a[i] + b[i]));
        letters = IntStream.range(0, 128)
                .filter(c -> need[c] > 0).toArray();
        // A shortest cover always starts on a needed letter.
        return IntStream.range(0, n)
                .filter(l -> need[s.charAt(l)] > 0)
                .mapToObj(l -> new int[]{ l, end(l) })
                .filter(w -> w[1] != NONE)
                .min(Comparator.comparingInt(w -> w[1] - w[0]))
                .map(w -> s.substring(w[0], w[1]))
                .orElse("");
    }

    // The shortest cover from l ends just after the need[c]-th
    // occurrence of every needed letter c at or after l.
    private int end(int l) {
        return IntStream.of(letters).map(c -> {
            int i = Arrays.binarySearch(at[c], l);
            int k = (i < 0 ? -i - 1 : i) + need[c] - 1;
            return k < at[c].length ? at[c][k] + 1 : NONE;
        }).max().getAsInt();
    }
}
Where the loop still winsFive of the six pay for not sliding: a log factor (209, 76), the alphabet (3, 424) or the window width (567). Every one fits the constraints, but the loop is linear with O(1) extra space in all six. If an interviewer asks for a stream version, give one of these and name its cost. That sentence is what they are listening for.
The idea worth keeping424's reading is a real technique, not a stream trick. A window allowed at most k marked positions is bounded by the marks just outside it, so the best one spans k consecutive gaps. The same reading solves Max Consecutive Ones III directly, and counts the subarrays in Count Number of Nice Subarrays as products of neighbouring gaps.
