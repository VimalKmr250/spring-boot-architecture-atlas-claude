Why the expiry test uses <=The window covering index i starts at i − k + 1, so an index is stale exactly when it is <= i − k. Writing < i − k keeps one element too many and silently reports a maximum from outside the window. The test fires at most once per step because only one index can newly expire, but write it as a while anyway — it costs nothing and it is the form that survives when the window width varies.
