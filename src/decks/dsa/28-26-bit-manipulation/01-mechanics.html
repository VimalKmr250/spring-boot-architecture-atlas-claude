Treat an integer as thirty-two independent lanes

Bitwise operators act on every bit at once, so an int is really 32 parallel computations. The pattern is recognising when a problem's structure matches one of those operators — and XOR is the one that matters most, because it is self-cancelling.

XOR — the three properties that solve problems

x ^ x = 0
A value cancels itself. Pairs vanish, leaving only what is unpaired.
x ^ 0 = x
Zero is the identity, so it is the correct accumulator seed.
Commutative and associative
Order is irrelevant, so you can XOR a whole array in one pass and never sort or group anything.

Together these turn "find the one element appearing once while all others appear twice" into a single fold — O(n) time, O(1) space, no hash map.

The operations worth memorising

n & (n − 1)
Clears the lowest set bit. Looping until zero counts set bits in as many steps as there are ones, not 32.
n & (−n)
Isolates the lowest set bit, useful for splitting a set into two groups.
n >>> 1
Unsigned right shift. Use it, not >>, or a negative number's sign bit fills in and the loop never ends.
(n >> i) & 1
Reads bit i. Pair it with n |= (1 << i) to write one.

Applies when

Elements pair up and cancel, you must count or reverse bits, or the constraints demand O(1) extra space where a hash map would be natural. Also for subset enumeration via bitmasks.

Does not apply when

A hash map is allowed and the input is small — it is clearer and equally fast. Reach for bits when the space constraint or the structure genuinely calls for it, not to show off.

Complexity

O(n) for a single XOR fold, O(1) space. Bit counting is O(set bits) with the clearing trick, or O(32) naively. Reversing bits is a fixed 32 steps.

Recognition cues — the literal words in the statement"every element appears twice except for one" · "appears three times except for one" · "you must implement a solution with linear runtime and constant extra space" (decisive — it rules out a hash map) · "the number of 1 bits" · "reverse the bits" · "the missing number in the range". The constant-space demand alongside a counting problem is the strongest signal in this pattern.
