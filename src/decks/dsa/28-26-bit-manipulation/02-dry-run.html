Every value appears three times except one. Plain XOR fails — three copies leave one behind rather than cancelling. The fix is to count each bit lane modulo 3, and the answer's bits are the lanes where the count is not zero.

Why the counting version is the better interview answerThe state machine is four tokens long and impossible to derive under pressure if you have not memorised it. The modulo-3 count is derivable from first principles in thirty seconds: each bit lane is independent, triplicated values contribute a multiple of three, so the remainder is the unique value's bit. Present that, get it working, and then offer the compressed form as an optimisation — the reasoning is what is being assessed.
