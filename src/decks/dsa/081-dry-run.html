LC 25 traced on 1→2→3→4→5, k = 3

Reverse each group of three; leave any short remainder alone. The result is 3→2→1→4→5. The whole problem is bookkeeping: for each group you need the node before it, its old head, and its old tail — because the old head becomes the new tail and must be reconnected.

StepWhat it doesWhy it is needed
Find kthWalk k steps from groupPrev.If it is null, fewer than k nodes remain — stop, leaving the tail alone.
Save nextGroupkth.next, before anything is rewired.The reversal overwrites it; without this the rest of the list is lost.
ReverseStandard three-pointer reverse, seeded with prev = nextGroup.Seeding with nextGroup instead of null performs the tail reconnection for free.
Reconnect frontgroupPrev.next = kth.kth is now the group's first node, so the preceding node must point at it.
AdvancegroupPrev = oldHead.The old head is now the group's last node, so it precedes the next group.
The trick worth stealingSeeding the reversal with prev = nextGroup rather than null means the old head's next already points at the following group when the reversal finishes. One of the two reconnections happens automatically, which removes a line and with it the most common place this problem goes wrong.
