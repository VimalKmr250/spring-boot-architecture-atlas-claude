A row that reads only the row above is clean; a left neighbour is a running scan

Grid DP sweeps rows, so the natural stream is Stream.iterate over rows with a fresh row per step. That is clean when a cell reads only the previous row, as in 931 and 120. 62, 63, 64 and 221 also read the cell to their left in the same row, which is a running scan. Java 17 streams have no scan operation (Gatherers.scan arrived in JDK 24), so the row is filled by a stream that reads what it just wrote. That is state, and it makes them correct only sequentially.

LC 62 · Unique Paths · stateful
class Solution {
    public int uniquePaths(int m, int n) {
        int[] ways = new int[n];
        Arrays.fill(ways, 1);               // the top row: one way to each cell
        // Each later row: ways[j] (from above) + ways[j - 1] (from the
        // left, written a moment ago by this same stream). Sequential only.
        IntStream.range(1, m).forEach(i ->
                IntStream.range(1, n).forEach(j -> ways[j] += ways[j - 1]));
        return ways[n - 1];
    }
}
LC 63 · Unique Paths II · stateful
class Solution {
    public int uniquePathsWithObstacles(int[][] grid) {
        int n = grid[0].length;
        int[] ways = new int[n];
        ways[0] = 1;                        // a virtual way in, above (0, 0)
        // Every row, the first included: an obstacle zeroes the cell,
        // otherwise add the left cell that this pass already updated.
        Arrays.stream(grid).forEach(row ->
                IntStream.range(0, n).forEach(j ->
                        ways[j] = row[j] == 1 ? 0 : ways[j] + (j > 0 ? ways[j - 1] : 0)));
        return ways[n - 1];
    }
}
LC 64 · Minimum Path Sum · stateful
class Solution {
    public int minPathSum(int[][] grid) {
        int n = grid[0].length;
        int[] best = new int[n];
        Arrays.fill(best, Integer.MAX_VALUE);
        best[0] = 0;                        // a virtual 0 above the start
        // best[j] = this cell + min(above = best[j], left = best[j - 1]),
        // and the left entry was written a moment ago by this stream.
        Arrays.stream(grid).forEach(row ->
                IntStream.range(0, n).forEach(j -> best[j] = row[j]
                        + (j == 0 ? best[0] : Math.min(best[j], best[j - 1]))));
        return best[n - 1];
    }
}
LC 221 · Maximal Square · stateful
class Solution {
    public int maximalSquare(char[][] matrix) {
        int n = matrix[0].length;
        int[][] rows = new int[2][n + 1];   // this row and the one above, 0-padded
        // side[j] = 1 + min(up, up-left, left) on a '1'. "left" was
        // written a moment ago in this row, so it is sequential only.
        int side = IntStream.range(0, matrix.length).map(i -> {
            int[] up = rows[(i + 1) % 2], cur = rows[i % 2];
            IntStream.rangeClosed(1, n).forEach(j -> cur[j] = matrix[i][j - 1] == '1'
                    ? 1 + Math.min(Math.min(up[j], up[j - 1]), cur[j - 1]) : 0);
            return Arrays.stream(cur).max().getAsInt();
        }).max().getAsInt();
        return side * side;
    }
}
LC 931 · Minimum Falling Path Sum · clean
class Solution {
    public int minFallingPathSum(int[][] matrix) {
        int n = matrix.length;
        // Each row reads only the row above, at j - 1, j and j + 1 clamped
        // to the edges. A fresh row per step, so the fold is clean.
        record Row(int i, int[] sum) {}
        Row last = Stream.iterate(new Row(0, matrix[0]), r -> new Row(r.i() + 1,
                        IntStream.range(0, n).map(j -> matrix[r.i() + 1][j]
                                + IntStream.rangeClosed(Math.max(0, j - 1), Math.min(n - 1, j + 1))
                                        .map(k -> r.sum()[k]).min().getAsInt())
                                .toArray()))
                .skip(n - 1).findFirst().get();
        return Arrays.stream(last.sum()).min().getAsInt();
    }
}
LC 120 · Triangle · clean
class Solution {
    public int minimumTotal(List<List<Integer>> triangle) {
        int rows = triangle.size();
        // Bottom-up: row r holds the best sum from each cell down. Row
        // r - 1 reads cells j and j + 1 of row r, which always exist.
        record Row(int r, int[] best) {}
        int[] bottom = triangle.get(rows - 1).stream().mapToInt(Integer::intValue).toArray();
        return Stream.iterate(new Row(rows - 1, bottom), w -> new Row(w.r() - 1,
                        IntStream.range(0, w.r()).map(j -> triangle.get(w.r() - 1).get(j)
                                + Math.min(w.best()[j], w.best()[j + 1])).toArray()))
                .skip(rows - 1).findFirst().get().best()[0];
    }
}
The left neighbour is the stateways[j] += ways[j - 1] is a prefix sum along the row: each cell needs the one the stream wrote just before it, so a parallel stream would read stale or zero values. Sweeping anti-diagonals instead would make 62–64 clean, because every cell on a diagonal reads only cells on the previous one, but the index arithmetic is rarely worth it in an interview. 221 keeps two alternating rows because it also needs the up-left value, which a single in-place row has already overwritten.
A fresh row is the clean shape931 and 120 never read their own row, so each step is a pure map from the old row to a new one. Clamping j - 1 and j + 1 with Math.max and Math.min is the whole edge case in 931. Going bottom-up in 120 means the row being built is always one shorter than the row it reads, so no index can fall off the end.
