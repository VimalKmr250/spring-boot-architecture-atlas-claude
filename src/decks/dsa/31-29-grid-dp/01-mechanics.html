Each cell is answered by the cells that reach it

When movement is restricted to right and down, a grid becomes a directed acyclic graph with a natural order: every cell depends only on cells above and to the left. Fill the table row by row and each dependency is already computed when you need it.

The state and the transition

dp[r][c] = the answer for the subproblem that ends at cell (r, c) — a path count, a minimum cost, a square size.

With right-and-down movement, only two cells reach (r, c): the one above and the one to the left. So the transition combines exactly those two — summing them for a count, taking the smaller for a minimum.

That the dependencies are already filled is what makes the plain double loop correct without any explicit ordering work.

The first row and column

Cells on the top edge have no cell above; cells on the left edge have none to the left. Those are the base cases, and there are two ways to handle them.

Fill them explicitly before the main loops — clear, but easy to get subtly wrong. Or pad the table with an extra row and column of sentinel values, so every real cell has both neighbours and the main loop needs no branches at all.

Padding costs one row and one column and removes an entire class of edge cases. Prefer it whenever the sentinel has a natural value.

Applies when

Movement through a grid is monotone — right and down, or strictly downward — so no cycle can form. Also for questions about the largest sub-square or sub-rectangle satisfying a property.

Does not apply when

Movement is in all four directions, which creates cycles and needs BFS or Dijkstra instead. The acyclic direction is precisely what makes a simple double loop valid.

Complexity

O(rows × cols) time — each cell is computed once from O(1) predecessors. Space is O(cols) with a rolling row, or O(1) if you are allowed to overwrite the input grid.

Recognition cues — the literal words in the statement"can only move either down or right" (decisive — it guarantees acyclicity) · "how many possible unique paths" · "minimises the sum of all numbers along its path" · "the largest square containing only 1s" · "a falling path" · "move to an adjacent number on the row below". The restricted movement direction is the single clearest signal in this pattern.
