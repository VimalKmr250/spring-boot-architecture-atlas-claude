A caterpillar crawling along the array

Forget the code for a minute. A sliding window is a caterpillar on a branch: its head reaches forward one letter at a time, and its tail creeps forward only when the body breaks a rule. Neither end ever crawls backwards. This slide shows why that is allowed, on LC 3 — the longest stretch of "abcabcbb" with no repeated letter. Everything after it is bookkeeping.

Fact 1 · Cutting the front off a clean window leaves it clean

abcclean
abcstill clean

If abc has no repeats, bc cannot have any — you only took a letter away. So when the tail moves forward there is nothing to re-check. The head stays where it is and carries on. That is every grey cell in the picture, saved.

Fact 2 · Stretching a broken window never fixes it

abcabroken
abcabstill broken

If abca repeats a, every longer window from the same start repeats it too — both as are still inside. So a start that breaks is broken for every future end. The tail can leave it behind for good; it never has a reason to come back.

So it cannot miss the answer

The best stretch ends at some letter. When the head reaches that letter, the tail is at the earliest start that is still clean — it only ever stepped past starts that were broken, and Fact 2 says they are still broken.

So at that moment the window is the longest clean stretch ending there, and it gets recorded. The head visits every letter, so every possible ending is tried once.

Put the two facts togetherFact 1 means the head never goes back — there is nothing behind it to re-check. Fact 2 means the tail never goes back — every start it has passed is dead for good. Two ends that only move forward make at most n moves each, so the whole run is at most 2n moves. The slow way restarts at every start; the window never restarts at all.

The whole algorithm, in plain English

for each letter, left to right: // the head moves bring it into the window while the window breaks the rule: // Fact 2: it won't fix itself drop the letter at the tail // the tail moves the window is fine again // Fact 1: nothing to re-check if it is the longest so far, remember it

Six lines, and the Java on the following slides is exactly these six lines with names attached. If a line of code ever confuses you, find which of these six it is.
