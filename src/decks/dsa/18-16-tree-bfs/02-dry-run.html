Filter nulls on enqueue, not on dequeueCheck if (node.left != null) before adding. The alternative — enqueuing nulls and skipping them on dequeue — makes the size snapshot meaningless, because a level's recorded width then includes phantom entries. The one exception is when you deliberately use null as a level separator, which is an alternative formulation of this pattern but does not mix with the size snapshot.
