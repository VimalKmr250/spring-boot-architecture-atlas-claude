Build, seed, drain, check

Four phases, and the first is where the mistakes live. Get the edge direction right and the rest is mechanical.

Kahn's algorithm — the template
/**
 * [a, b] means "b must come before a", so the edge runs b -> a
 * and indegree[a] counts how many prerequisites a is still waiting on.
 *
 * Returns a valid order, or an empty array when a cycle exists.
 */
int[] topoSort(int n, int[][] pairs) {
    // 1 · BUILD — adjacency plus indegree, in one pass
    List<List<Integer>> adj = new ArrayList<>();
    for (int i = 0; i < n; i++) adj.add(new ArrayList<>());

    int[] indeg = new int[n];
    for (int[] p : pairs) {
        int after = p[0], before = p[1];
        adj.get(before).add(after);     // before UNLOCKS after
        indeg[after]++;                 // after is BLOCKED by one more
    }

    // 2 · SEED — every node that starts unblocked
    Queue<Integer> q = new ArrayDeque<>();
    for (int i = 0; i < n; i++) if (indeg[i] == 0) q.offer(i);

    // 3 · DRAIN
    int[] order = new int[n];
    int idx = 0;

    while (!q.isEmpty()) {
        int cur = q.poll();
        order[idx++] = cur;

        for (int next : adj.get(cur)) {
            // A node is freed exactly when its LAST blocker is removed.
            if (--indeg[next] == 0) q.offer(next);
        }
    }

    // 4 · CHECK — anything unemitted is part of a cycle
    return idx == n ? order : new int[0];
}
Variant · the DFS colouring form
// Three states. GRAY means "on the current recursion path", so
// meeting a GRAY node is a back edge — that is the cycle.
// The order comes out REVERSED, because a node is appended only
// after all its descendants are finished.
private static final int WHITE = 0, GRAY = 1, BLACK = 2;

boolean dfs(int u, List<List<Integer>> adj, int[] color, Deque<Integer> out) {
    color[u] = GRAY;

    for (int v : adj.get(u)) {
        if (color[v] == GRAY) return false;             // back edge → cycle
        if (color[v] == WHITE && !dfs(v, adj, color, out)) return false;
        // BLACK means already finished — safe to skip
    }

    color[u] = BLACK;
    out.push(u);        // push, so the final stack reads in topo order
    return true;
}
Variant · reverse the edges (LC 802)
// "Safe" means every path from the node leads to a terminal.
// Equivalently: the node reaches no cycle. Kahn's peels away nodes
// with OUTdegree zero — so build the graph BACKWARDS and use
// outdegree where indegree normally goes.
List<Integer> eventualSafeNodes(int[][] graph) {
    int n = graph.length;
    List<List<Integer>> rev = new ArrayList<>();
    for (int i = 0; i < n; i++) rev.add(new ArrayList<>());

    int[] outdeg = new int[n];
    for (int u = 0; u < n; u++) {
        outdeg[u] = graph[u].length;
        for (int v : graph[u]) rev.get(v).add(u);       // reversed edge
    }

    Queue<Integer> q = new ArrayDeque<>();
    for (int i = 0; i < n; i++) if (outdeg[i] == 0) q.offer(i);   // terminals

    boolean[] safe = new boolean[n];
    while (!q.isEmpty()) {
        int u = q.poll();
        safe[u] = true;
        for (int p : rev.get(u)) if (--outdeg[p] == 0) q.offer(p);
    }

    List<Integer> out = new ArrayList<>();
    for (int i = 0; i < n; i++) if (safe[i]) out.add(i);
    return out;      // already ascending, as the problem requires
}

The knobs

Edge direction
Prerequisite points at what it unlocks. Write one example out before coding — this is where the pattern goes wrong.
What you return
The order, or just whether the count reached V. Feasibility questions need nothing else.
Queue or priority queue
A plain queue gives any valid order. Swap in a PriorityQueue when the problem wants the lexicographically smallest one.
Reversed graph
When the question is about reaching terminals rather than being reachable, build the graph backwards and peel by outdegree.
Non-integer nodes
Map string names to indices with a HashMap, or keep the adjacency and indegree keyed on the string directly.
The three bugs that actually happenReversed edges — the algorithm runs happily and emits a plausible order that is backwards, which passes a symmetric test case and fails the rest. Seeding after the loop — the queue must be filled with all zero-indegree nodes before draining; a disconnected component with its own start is otherwise never reached. Skipping the count check — without it a cyclic input returns a partial order instead of the required empty array.
