Java 25 makes small programs shorter and large ones leaner, and some of its headline features are still previews

JDK 25, from September 2025, is the current LTS. Its final features fall into three groups: a simpler on-ramp for small programs, language changes that remove old restrictions, and runtime work that cuts memory and start-up time. The file below is a real compact source file, compiled with --release 25: no class around it, an instance main, and java.base imported automatically.

Java25.java · compiled with javac --release 25 -Xlint:all, no warnings
// A compact source file (JEP 512): no class declaration, an instance main, java.base imported for you.
// Run with: java Java25.java

/// Markdown documentation comments work too (JEP 467, JDK 23).
static final ScopedValue<String> USER = ScopedValue.newInstance();      // JEP 506, final in 25

record Rate(double fraction) { }

class Discount {
    final Rate rate;
    Discount(int percent) {
        if (percent < 0 || percent > 100)                               // JEP 513: code before this(...)
            throw new IllegalArgumentException("percent out of range: " + percent);
        this(new Rate(percent / 100.0));
    }
    Discount(Rate rate) { this.rate = rate; }
}

String whoAmI() { return USER.isBound() ? USER.get() : "nobody"; }

void main() {
    IO.println("compact source file on JDK " + Runtime.version().feature());   // java.lang.IO, JEP 512
    List<String> skus = List.of("tea", "milk", "jam");                  // no import needed
    IO.println("skus " + skus);

    ScopedValue.where(USER, "alice").run(() -> IO.println("inside the scope: " + whoAmI()));
    IO.println("outside it: " + whoAmI());

    IO.println("10% off: " + new Discount(10).rate);
    try {
        new Discount(140);
    } catch (IllegalArgumentException _) {                              // JEP 456: unnamed variable, 22
        IO.println("rejected before any field was set");
    }

    var windows = Stream.of(1, 2, 3, 4, 5, 6, 7).gather(Gatherers.windowFixed(3)).toList();   // JEP 485, 24
    IO.println("windowFixed(3) " + windows);
}

Code before this() and super()Flexible constructor bodies let a constructor validate its arguments, or compute values, before it calls this(…) or super(…), as long as it does not touch the object being built. Discount(140) was rejected before any field existed, without the old static-helper workaround.
What production code gainsScoped values to replace ThreadLocal request context, safely, with virtual threads. Compact headers: a header 4 bytes smaller, often 8 bytes less per object after alignment, measured on object layout. AOT profiles: faster warm-up, from method profiles recorded in a training run.
Previews are not for productionPreview APIs can change between releases, and code that uses them needs --enable-preview and runs only on that exact JDK version. Structured concurrency has changed shape across its previews. Talk about it in interviews; wait to ship it.
