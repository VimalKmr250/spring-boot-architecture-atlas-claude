An enum is a fixed set of singleton objects, so it can carry fields, behaviour and a checked switch

Each constant is created once, when the enum class is initialised, and no code can create another, not even reflection or deserialization. Constants can hold fields, and each can override methods. Two habits cause the bugs: storing ordinal(), and assuming every constant's class is the enum's class.

Enums.java · state machine, stable codes, EnumSet and EnumMap
import java.util.*;

public class Enums {
    enum Status {
        PLACED("P") {
            @Override Status next() { return PAID; }
        },
        PAID("A") {
            @Override Status next() { return SHIPPED; }
        },
        SHIPPED("S") {
            @Override Status next() { return this; }
            @Override boolean isFinal() { return true; }
        };

        private final String code;                         // a stable code for storage
        Status(String code) { this.code = code; }          // constructors are always private
        abstract Status next();                            // each constant implements it
        boolean isFinal() { return false; }

        private static final Map<String, Status> BY_CODE = new HashMap<>();
        static { for (Status s : values()) BY_CODE.put(s.code, s); }
        static Status fromCode(String code) {
            Status s = BY_CODE.get(code);
            if (s == null) throw new IllegalArgumentException("unknown status code " + code);
            return s;
        }
    }

    enum Region { NORTH, EAST, SOUTH, WEST }

    public static void main(String[] args) {
        for (Status s = Status.PLACED; ; s = s.next()) {
            System.out.println(s + " ordinal=" + s.ordinal() + " code=" + s.code
                    + " class=" + s.getClass().getName());
            if (s.isFinal()) break;
        }
        System.out.println("fromCode(\"A\") = " + Status.fromCode("A"));
        try {
            Status.valueOf("paid");
        } catch (IllegalArgumentException e) {
            System.out.println(e.getMessage());
        }
        System.out.println("values() is a new array each call: " + (Status.values() != Status.values()));

        EnumSet<Region> south = EnumSet.range(Region.EAST, Region.WEST);
        EnumMap<Region, Integer> orders = new EnumMap<>(Region.class);
        orders.put(Region.WEST, 12);
        orders.put(Region.NORTH, 7);
        System.out.println("range " + south + ", complement " + EnumSet.complementOf(south) + ", map " + orders);

        Status s = Status.PAID;
        String label = switch (s) {                         // exhaustive over the constants
            case PLACED -> "awaiting payment";
            case PAID -> "packing";
            case SHIPPED -> "on its way";
        };
        System.out.println(label + "; PAID compareTo SHIPPED = " + Status.PAID.compareTo(Status.SHIPPED));
    }
}

FactConsequence
A constant with a body is an anonymous subclassgetClass() is Enums$Status$1. Use getDeclaringClass() to get Status.
ordinal() is the declaration positionInsert a constant and every stored ordinal now means something else. Store a stable code or the name.
valueOf matches the exact nameWrong case or an unknown value throws IllegalArgumentException. Map external codes yourself.
values() clones an array per callCache it, or build a lookup map once, as BY_CODE does.
compareTo uses ordinal orderDeclare constants in a meaningful order, or do not rely on it.
Ordinals in the databaseJPA's EnumType.ORDINAL stores 0, 1, 2. Someone adds CANCELLED between PLACED and PAID, and every paid order is now cancelled. Use EnumType.STRING or an AttributeConverter with a code.
EnumSet and EnumMapAn EnumSet is a bit vector: one long for up to 64 constants. An EnumMap is an array indexed by ordinal. Both iterate in declaration order and beat HashSet and HashMap for enum keys.
The safest singletonA single-constant enum cannot be duplicated by reflection or serialization, which breaks the other singleton forms. See singleton, the safe ways.
