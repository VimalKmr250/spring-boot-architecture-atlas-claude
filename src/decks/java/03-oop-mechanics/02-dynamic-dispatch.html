Five invoke instructions, and how a virtual call finds the method it runs

javac compiles every method call into one of five bytecodes. Only invokevirtual and invokeinterface choose the method at run time, from the receiver's class. The JIT then removes most of that cost: a call site that only ever sees one class becomes a direct call, and usually an inlined one.

Dispatch.java · one call of each kind
import java.util.function.LongSupplier;

interface Priced { long price(); }

public class Dispatch {
    static class Item implements Priced {
        public long price() { return 100; }
        private long cost() { return 60; }
        long margin() { return price() - cost(); }
    }
    static class Discounted extends Item {
        @Override public long price() { return super.price() - 10; }
    }
    static long tax(long amount) { return amount / 5; }

    public static void main(String[] args) {
        Item item = new Discounted();
        Priced priced = item;
        long a = item.price();                     // class type: invokevirtual
        long b = priced.price();                   // interface type: invokeinterface
        long c = tax(a);                           // static: invokestatic
        long m = item.margin();
        LongSupplier later = () -> a * 2;          // lambda: invokedynamic
        String line = "price=" + a;                // concatenation: invokedynamic
        System.out.println(a + " " + b + " " + c + " " + m + " " + later.getAsLong() + " " + line);
    }
}

What the JIT does with a virtual call

  • Monomorphic (one class seen): a class check, then the method inlined.
  • Bimorphic (two): two checks, both inlined.
  • Megamorphic (three or more): a real vtable or itable call, and no inlining.
  • If only one implementation is loaded, class hierarchy analysis inlines it with no check, and deoptimises if a subclass loads later. final is not needed for speed.
Where this shows upHot loops over many implementations of one interface, such as serializers, rule engines and visitors, pay for megamorphic calls. Typical service code does not. More on compilation in the JIT compiler.
