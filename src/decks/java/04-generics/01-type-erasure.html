Generics are checked by the compiler and erased from the objects, but not from the declarations

javac checks every type argument, inserts the casts, then compiles List<String> and List<Integer> to the same ArrayList class. That kept Java 5 binary-compatible with older code. At run time an object does not know its type argument. Fields, method signatures and superclass declarations keep theirs in the class file, which is how Jackson and Spring recover them.

Erasure.java · what is erased, and what survives
import java.lang.reflect.*;
import java.util.*;

public class Erasure {
    static List<String> names = new ArrayList<>();               // declarations keep their types

    record Money(long cents) implements Comparable<Money> {
        @Override public int compareTo(Money o) { return Long.compare(cents, o.cents); }
    }

    // A "super type token": a subclass records its type argument in the class file.
    abstract static class TypeRef<T> {
        final Type type = ((ParameterizedType) getClass().getGenericSuperclass()).getActualTypeArguments()[0];
    }

    static <T> T[] newArray(Class<T> type, int n) {               // new T[n] does not compile
        @SuppressWarnings("unchecked")
        T[] array = (T[]) Array.newInstance(type, n);             // so pass the Class in
        return array;
    }

    public static void main(String[] args) throws Exception {
        List<String> strings = new ArrayList<>();
        List<Integer> numbers = new ArrayList<>();
        System.out.println("same class at run time: " + (strings.getClass() == numbers.getClass())
                + " (" + strings.getClass().getName() + ")");

        Field f = Erasure.class.getDeclaredField("names");
        System.out.println("field type " + f.getType().getName() + ", generic type " + f.getGenericType());

        Type t = new TypeRef<Map<String, List<Integer>>>() { }.type;
        System.out.println("captured by the token: " + t);

        for (Method m : Money.class.getDeclaredMethods())
            if (m.getName().equals("compareTo"))
                System.out.println("compareTo(" + m.getParameterTypes()[0].getSimpleName() + ") bridge=" + m.isBridge());

        String[] slots = newArray(String.class, 2);
        System.out.println("array made at run time: " + slots.getClass().getSimpleName() + " length " + slots.length);
    }
}

LineWhy
Same classOne ArrayList class serves every type argument. There is no ArrayList<String>.class.
Generic typeThe field's declaration keeps List<String> as a signature attribute, readable by reflection.
The tokenAn anonymous subclass of TypeRef<…> fixes the argument in its superclass declaration. Jackson's TypeReference and Spring's ParameterizedTypeReference use this trick.
Bridge methodcompareTo(Money) erases differently from Comparable.compareTo(Object), so javac adds a synthetic compareTo(Object) that casts and delegates.
