Pick the collection by the operation you do most, then by the order you need

The interfaces say what a collection promises: List keeps positions, Set rejects duplicates, Queue hands out elements in some order, Map looks up by key. The implementation decides what each operation costs. In practice three classes cover most code: ArrayList, HashMap and ArrayDeque. The others earn their place with one specific property.

How to chooseNeed positions or duplicates: ArrayList. Lookups by key: HashMap, or HashSet for membership. Insertion order on iteration: the Linked variants. Sorted order or range queries: TreeMap, TreeSet. Stack, queue or both ends: ArrayDeque. Smallest or largest first: PriorityQueue. Enum keys: EnumMap, EnumSet.
