ArrayDeque is the stack and the queue; PriorityQueue is a heap that only looks sorted at the top

ArrayDeque is a circular array with O(1) operations at both ends, which makes it the right stack, the right FIFO queue and the right double-ended queue. PriorityQueue is a binary heap stored in an array: the smallest element (by its comparator) is always at the head, while the rest are only partly ordered. Every queue method comes in two forms, one that throws and one that returns a special value.

Queues.java · stacks, FIFO, heaps, top-k, the two method families
import java.util.*;
import java.util.concurrent.ArrayBlockingQueue;

public class Queues {
    record Task(String name, int priority) { }

    public static void main(String[] args) {
        Deque<String> stack = new ArrayDeque<>();
        stack.push("a"); stack.push("b"); stack.push("c");
        Stack<String> legacy = new Stack<>();
        legacy.push("a"); legacy.push("b"); legacy.push("c");
        System.out.println("ArrayDeque as stack " + stack + ", pop " + stack.pop());
        System.out.println("java.util.Stack     " + legacy + ", pop " + legacy.pop() + "  (iterates bottom first)");

        Queue<String> fifo = new ArrayDeque<>(List.of("first", "second", "third"));
        System.out.println("queue poll " + fifo.poll() + ", peek " + fifo.peek() + ", left " + fifo);

        PriorityQueue<Integer> heap = new PriorityQueue<>(List.of(7, 3, 9, 1, 4, 8));
        System.out.print("PriorityQueue toString " + heap + ", poll order");
        while (!heap.isEmpty()) System.out.print(" " + heap.poll());
        System.out.println();

        int k = 3;
        PriorityQueue<Integer> topK = new PriorityQueue<>();       // a min-heap holding the k largest
        for (int n : new int[] {5, 12, 3, 41, 8, 27, 19}) {
            topK.offer(n);
            if (topK.size() > k) topK.poll();                      // drop the smallest
        }
        List<Integer> largest = new ArrayList<>(topK);
        largest.sort(Comparator.reverseOrder());
        System.out.println("top 3 " + largest);

        PriorityQueue<Task> work = new PriorityQueue<>(Comparator.comparingInt(Task::priority).reversed()
                .thenComparing(Task::name));
        work.addAll(List.of(new Task("email", 1), new Task("refund", 5), new Task("invoice", 5), new Task("audit", 3)));
        System.out.print("by priority:");
        while (!work.isEmpty()) System.out.print(" " + work.poll().name());
        System.out.println();

        Queue<String> empty = new ArrayDeque<>();
        System.out.println("empty: poll " + empty.poll() + ", peek " + empty.peek());
        try { empty.remove(); } catch (NoSuchElementException e) { System.out.println("empty: remove -> NoSuchElementException"); }
        try { empty.offer(null); } catch (NullPointerException e) { System.out.println("ArrayDeque.offer(null) -> NullPointerException"); }

        Queue<String> bounded = new ArrayBlockingQueue<>(1);
        bounded.add("x");
        System.out.println("full: offer " + bounded.offer("y"));
        try { bounded.add("y"); } catch (IllegalStateException e) { System.out.println("full: add -> " + e.getMessage()); }
    }
}

java.util.StackIt extends Vector, so every call takes a lock, and it inherits get(i) and add(i, e), which let code reach past the top. It even iterates bottom first, so its toString is the reverse of ArrayDeque's. Use Deque<E> stack = new ArrayDeque<>().
The heap is not sortedtoString printed [1, 3, 8, 7, 4, 9]: the array in heap order, where each parent is no larger than its children. Only repeated poll gives sorted order, at O(log n) each. Iterating a PriorityQueue, or streaming it, gives the heap order.
Top k in O(n log k)Keep a min-heap of size k and evict its smallest whenever it overflows; what remains are the k largest. Interviewers ask for it constantly: heap and top-k in the DSA tab has the problems. ArrayDeque rejects null, because poll uses null to mean empty.
