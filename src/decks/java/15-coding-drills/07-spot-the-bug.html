Drill: five short snippets, each with one bug the compiler accepts

Code-reading rounds hand you a few lines and ask what they print, or what is wrong. Each snippet below is a line or two from real code, with the comment saying what the author meant. Find the bug before reading the answers. Every snippet compiles cleanly with -Xlint:all.

1 · remove the zero quantities
List<Integer> qty = new ArrayList<>(List.of(0, 0, 5, 0, 7));
for (int i = 0; i < qty.size(); i++)
    if (qty.get(i) == 0) qty.remove(i);                    // Bug 1: remove empty lines
2 · a fallback region
Optional<String> configured = Optional.of("eu-west");
String region = configured.orElse(loadDefault());         // Bug 2: a default, if missing
3 · the average order value
int totalCents = 1_000, orders = 3;
double average = totalCents / orders;                       // Bug 3: average order value
4 · build the report in the background
Thread worker = new Thread(() -> System.out.println("4 report built on " + Thread.currentThread().getName()));
worker.run();                                               // Bug 4: build it in the background
5 · the label "A1 band"
char grade = 'A';
String label = grade + 1 + " band";                         // Bug 5: "A1 band"
Output on JDK 25 · SpotTheBug.java · bug, then fix
1 after removing zeros by index: [0, 5, 7]
  removeIf: [5, 7]
2 region eu-west, but loadDefault() ran 1 time(s)
  orElseGet ran it 0 time(s)
3 average 333.0  ->  333.3333333333333
4 report built on main
4 report built on Thread-0
5 label 66 band  ->  A1 band
#The bugThe fix
1Removing at i shifts the next element into i, and i++ skips it, so two zeros in a row leave one behind.removeIf, an Iterator, or loop backwards
2orElse(loadDefault()) evaluates its argument first, every time, even when the value is present. A database call there runs on every request.orElseGet(SpotTheBug::loadDefault), which runs only when empty
3totalCents / orders is integer division; the result is truncated before it is widened to double.Cast one operand: (double) totalCents / orders; for money, BigDecimal
4run() just calls the method on the current thread: the report was built on main, blocking it.start(), or better, submit it to an executor
5grade + 1 is evaluated first, as char plus int: 65 + 1 = 66. Concatenation only starts when a String appears, from the left.Start with a string: "" + grade + 1, or String.valueOf(grade) + 1
