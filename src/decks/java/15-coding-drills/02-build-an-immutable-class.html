Drill: "make this Booking class immutable", and prove that it is

You get a class with a setter, a Date, and a list it shares with its callers. A full answer fixes six things and shows each fix working: the caller's list, the getter's list, the Date, the setter, subclassing, and invalid input. Then it adds value-based equality, because an immutable object is usually a value.

DrillImmutable.java · the given class, the answer, and the attacks
import java.time.*;
import java.util.*;

public class DrillImmutable {
    // The class you are given: "make this immutable".
    static class Booking {
        private String guest;
        private Date checkIn;
        private List<String> rooms;
        Booking(String guest, Date checkIn, List<String> rooms) { this.guest = guest; this.checkIn = checkIn; this.rooms = rooms; }
        String guest() { return guest; }
        Date checkIn() { return checkIn; }
        List<String> rooms() { return rooms; }
        void setGuest(String guest) { this.guest = guest; }
    }

    // The answer.
    static final class ImmutableBooking {                          // 1 final: no mutable subclass
        private final String guest;                                // 2 private final fields
        private final LocalDate checkIn;                           // 3 an immutable type, not Date
        private final List<String> rooms;

        ImmutableBooking(String guest, LocalDate checkIn, List<String> rooms) {
            this.guest = Objects.requireNonNull(guest, "guest");
            this.checkIn = Objects.requireNonNull(checkIn, "checkIn");
            if (rooms.isEmpty()) throw new IllegalArgumentException("at least one room");
            this.rooms = List.copyOf(rooms);                       // 4 copy in; also rejects null rooms
        }
        String guest() { return guest; }
        LocalDate checkIn() { return checkIn; }
        List<String> rooms() { return rooms; }                     // 5 already unmodifiable
        ImmutableBooking withGuest(String newGuest) {              // 6 change = new object
            return new ImmutableBooking(newGuest, checkIn, rooms);
        }
        @Override public boolean equals(Object o) {
            return o instanceof ImmutableBooking b && guest.equals(b.guest) && checkIn.equals(b.checkIn) && rooms.equals(b.rooms);
        }
        @Override public int hashCode() { return Objects.hash(guest, checkIn, rooms); }
        @Override public String toString() { return guest + " " + checkIn + " " + rooms; }
    }

    static String attempt(Runnable attack) {
        try { attack.run(); return "changed it"; }
        catch (UnsupportedOperationException e) { return "blocked"; }
    }

    public static void main(String[] args) {
        List<String> rooms = new ArrayList<>(List.of("101"));
        Date date = new Date(0);
        Booking given = new Booking("Ana", date, rooms);
        rooms.add("102");
        date.setTime(86_400_000L);
        given.rooms().add("103");
        given.setGuest("Bo");
        System.out.println("given class after 4 outside changes: " + given.guest() + " " + given.checkIn().toInstant() + " " + given.rooms());

        List<String> rooms2 = new ArrayList<>(List.of("101"));
        ImmutableBooking b = new ImmutableBooking("Ana", LocalDate.of(2026, 10, 8), rooms2);
        rooms2.add("102");
        System.out.println("caller adds to its list: " + b.rooms());
        System.out.println("getter's list .add():    " + attempt(() -> b.rooms().add("103")));
        ImmutableBooking renamed = b.withGuest("Bo");
        System.out.println("withGuest: " + renamed + ", original still " + b);
        System.out.println("equal by value: " + b.equals(new ImmutableBooking("Ana", LocalDate.of(2026, 10, 8), List.of("101"))));
        for (Runnable bad : List.<Runnable>of(() -> new ImmutableBooking(null, LocalDate.EPOCH, List.of("1")),
                () -> new ImmutableBooking("X", LocalDate.EPOCH, List.of()),
                () -> new ImmutableBooking("X", LocalDate.EPOCH, Arrays.asList("1", null)))) {
            try { bad.run(); } catch (RuntimeException e) { System.out.println("rejected: " + e.getClass().getSimpleName() + " " + e.getMessage()); }
        }
    }
}

The record versionSay it next: record Booking(String guest, LocalDate checkIn, List<String> rooms) with a compact constructor holding the same checks and rooms = List.copyOf(rooms). It gives steps 1, 2 and the equality for free. The interviewer often wants to hear that you know both.
Follow-up: "what if Room were a class?"List.copyOf copies references, not rooms. If Room is mutable, the booking is not immutable either: copy each room, or make Room immutable too. Immutability is only as deep as the types you hold.
Follow-up: "why bother?"Thread safety without locks, safe as map keys, safe to cache and share, and simpler reasoning: nothing changes behind your back. The background is on writing an immutable class.
