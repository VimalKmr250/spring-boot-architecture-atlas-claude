Drill: "implement a HashMap with put, get and remove", in about sixty lines

Interviewers ask for this because it touches everything: generics, equals and hashCode, arrays of a generic type, collisions, resizing and null keys. Aim for separate chaining, a power-of-two table, a stored hash per node and a resize at 75% full. Then prove it, here by running 100,000 random operations against java.util.HashMap and comparing every answer.

MyHashMap.java · the map, and a randomised check against the JDK's
import java.util.*;

// Separate chaining, power-of-two table, resize at 0.75, null key allowed.
public class MyHashMap<K, V> {
    private static final class Node<K, V> {
        final int hash;
        final K key;
        V value;
        Node<K, V> next;
        Node(int hash, K key, V value, Node<K, V> next) { this.hash = hash; this.key = key; this.value = value; this.next = next; }
    }

    private Node<K, V>[] table = newTable(16);
    private int size;

    @SuppressWarnings("unchecked")
    private static <K, V> Node<K, V>[] newTable(int n) { return (Node<K, V>[]) new Node<?, ?>[n]; }

    private static int hash(Object key) {
        if (key == null) return 0;
        int h = key.hashCode();
        return h ^ (h >>> 16);                                   // spread the high bits
    }

    public V get(Object key) {
        int h = hash(key);
        for (Node<K, V> n = table[h & (table.length - 1)]; n != null; n = n.next)
            if (n.hash == h && Objects.equals(n.key, key)) return n.value;
        return null;
    }

    public V put(K key, V value) {
        int h = hash(key), i = h & (table.length - 1);
        for (Node<K, V> n = table[i]; n != null; n = n.next)
            if (n.hash == h && Objects.equals(n.key, key)) { V old = n.value; n.value = value; return old; }
        table[i] = new Node<>(h, key, value, table[i]);           // prepend: O(1)
        if (++size > table.length * 3 / 4) resize();
        return null;
    }

    public V remove(Object key) {
        int h = hash(key), i = h & (table.length - 1);
        for (Node<K, V> n = table[i], prev = null; n != null; prev = n, n = n.next)
            if (n.hash == h && Objects.equals(n.key, key)) {
                if (prev == null) table[i] = n.next; else prev.next = n.next;
                size--;
                return n.value;
            }
        return null;
    }

    public int size() { return size; }

    private void resize() {
        Node<K, V>[] old = table;
        table = newTable(old.length * 2);
        for (Node<K, V> head : old)
            for (Node<K, V> n = head, next; n != null; n = next) {
                next = n.next;
                int i = n.hash & (table.length - 1);             // the stored hash: no hashCode call
                n.next = table[i];
                table[i] = n;
            }
    }

    int capacity() { return table.length; }

    public static void main(String[] args) {
        MyHashMap<String, Integer> mine = new MyHashMap<>();
        Map<String, Integer> real = new HashMap<>();
        Random random = new Random(7);                           // seeded: the same run every time
        int mismatches = 0;
        for (int op = 0; op < 100_000; op++) {
            String key = random.nextInt(20) == 0 ? null : "k" + random.nextInt(5_000);
            int kind = random.nextInt(3), value = random.nextInt();
            Object a, b;
            if (kind == 0) { a = mine.put(key, value); b = real.put(key, value); }
            else if (kind == 1) { a = mine.get(key); b = real.get(key); }
            else { a = mine.remove(key); b = real.remove(key); }
            if (!Objects.equals(a, b) || mine.size() != real.size()) mismatches++;
        }
        System.out.println("100,000 random put/get/remove against java.util.HashMap: " + mismatches
                + " mismatches; size " + mine.size() + ", capacity " + mine.capacity());

        MyHashMap<String, String> collide = new MyHashMap<>();
        collide.put("Aa", "first");
        collide.put("BB", "second");                             // same hashCode: same bucket
        System.out.println("colliding keys: " + collide.get("Aa") + ", " + collide.get("BB") + "; remove(Aa) -> "
                + collide.remove("Aa") + ", get(BB) still " + collide.get("BB"));
    }
}

Power-of-two lengthThe index is hash & (length - 1), no division
h ^ (h >>> 16)The mask uses only low bits; this lets the high bits count
Hash stored in the nodeCheap rejection before equals; resize never calls hashCode

Complexity

get, put and remove are O(1) on average, O(n) if every key collides. A resize is O(n), but doubling makes it O(1) amortised per insert. Memory: the table plus one node per entry.

Follow-ups to expect

"Make the worst case O(log n)": tree bins, as Java 8 did. "Make it thread-safe": one lock is easy, lock striping or per-bin locking is what ConcurrentHashMap does. "Iterate it": walk the table, and track a modification count to fail fast.

Test it the way it was tested hereA randomised comparison against a trusted implementation, with a seeded Random, finds edge cases you would not think to write. Add deliberate collisions ("Aa" and "BB") and the null key. The real one's internals are on HashMap internals.
