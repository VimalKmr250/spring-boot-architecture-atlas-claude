Read the question for its shape, and the Java tool follows

Most core-Java coding prompts are one of about twenty shapes in disguise. Spot the shape in the first minute and the first line of the answer is already decided. This table is the one to revise from the night before.

If the question saysReach forWatch out for
"…an immutable / value object"A record, or a final class with copies in and outMutable components; Date; arrays
"…as a map key" or "…in a set"equals and hashCode from the same immutable fieldsequals(MyType) overloads; mutable fields
"…sorted by X, then Y"Comparator.comparing(…).thenComparing(…)a - b comparators; ties that drop TreeSet elements
"…the k largest / most frequent"A min-heap PriorityQueue of size kSorting everything when n is huge
"…least recently used cache"LinkedHashMap in access order with removeEldestEntryIt is not thread-safe, even for reads
"…nearest price band / slot"TreeMap.floorEntry, ceilingKeyA chain of ifs
"…a stack" or "…a queue"ArrayDequeStack, LinkedList, remove(0) on an ArrayList
"…thread-safe singleton"An enum, or the holder idiomDouble-checked locking without volatile
"…count from many threads"LongAdder, AtomicLong, ConcurrentHashMap.mergevolatile and ++; get then put
"…threads take turns / print in order"Semaphores in a ring, or a lock with one Condition per threadif around wait; a final thread that never wakes the other
"…producer and consumer"A bounded BlockingQueue, with poison pills to stopUnbounded queues; wait/notify by hand
"…at most N at a time"SemaphoreA missing release in finally
"…wait for all N tasks"invokeAll, CompletableFuture.allOf, CountDownLatchStarting each task only after the last finished
"…call services in parallel, with a timeout"CompletableFuture on your own executor, orTimeout, completeOnTimeoutThe common pool; timeouts that do not stop the work
"…run every N seconds"ScheduledExecutorServiceTimer; a task exception that silently ends the schedule
"…rate limiter"A token bucket refilled from System.nanoTimeA timer thread per client
"…parse dates / money"java.time with an explicit zone; BigDecimal from stringsSimpleDateFormat shared; double; YYYY
"…read a big file"Files.lines in try-with-resources, or a BufferedReaderreadAllLines on gigabytes; an unclosed stream
