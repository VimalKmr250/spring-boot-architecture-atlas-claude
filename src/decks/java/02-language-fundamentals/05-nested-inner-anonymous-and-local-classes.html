Four kinds of nested class, and the hidden reference the inner ones carry

A class declared inside another is either static nested, an ordinary class that happens to live in another's namespace, or one of the three inner kinds: member, local and anonymous. Created in an instance context, an inner class gets a hidden field pointing at the outer object. That field is what lets it read outer state, and it is also how an inner class keeps a large object alive by accident.

Nested.java · all four kinds, and a lambda for contrast
import java.lang.reflect.Field;
import java.util.function.Supplier;

public class Nested {
    private int openOrders = 3;

    static class Totals {                          // static nested: no outer instance
        String hello() { return "static nested: needs no Nested instance"; }
    }

    class Inner {                                  // inner: tied to one Nested instance
        String hello() { return "inner reads the outer field: openOrders=" + openOrders; }
    }

    Supplier<String> anonymous() {
        return new Supplier<>() {                  // a class, so 'this' is the anonymous object
            @Override public String get() { return "anonymous: this is " + this.getClass().getName(); }
        };
    }

    Supplier<String> lambda() {
        return () -> "lambda: this is " + this.getClass().getName();   // the enclosing Nested
    }

    public static void main(String[] args) {
        Nested outer = new Nested();
        System.out.println(new Totals().hello());
        Nested.Inner inner = outer.new Inner();
        System.out.println(inner.hello());
        for (Field f : Inner.class.getDeclaredFields())
            System.out.println("hidden field in Inner: " + f);
        System.out.println(outer.anonymous().get());
        System.out.println(outer.lambda().get());

        int base = 10;                             // effectively final, so it can be captured
        record Line(String sku, int qty) { }       // local records are implicitly static
        class Pricer { int total(Line l) { return base + l.qty(); } }
        System.out.println("local class: " + new Pricer().total(new Line("SKU-1", 5)));
    }
}

this$0 is a strong referenceA listener, a cache entry or a task built from an inner class keeps its whole outer object reachable for as long as it lives itself. Since JDK 18, javac leaves the field out when the inner class never uses the outer instance. Declare nested classes static unless they really need it.
this in a lambdaAn anonymous class is a class, so this is the anonymous object (Nested$1). A lambda is not a class you declare: this inside it is the enclosing instance, and it captures that instance only if it uses it.
