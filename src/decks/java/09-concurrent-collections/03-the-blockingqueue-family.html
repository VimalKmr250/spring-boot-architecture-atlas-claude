A BlockingQueue is a hand-off with back-pressure: producers wait when it is full, consumers when it is empty

Every producer-consumer design in Java is a BlockingQueue underneath, including every ThreadPoolExecutor. Its value is in the blocking: put waits for space and take waits for an element, so a fast producer is slowed to the consumers' pace instead of filling the heap. Each method also comes in throwing, non-blocking and timed forms.

BlockingQueues.java · four method forms, the implementations, poison pills
import java.util.*;
import java.util.concurrent.*;

public class BlockingQueues {
    record Reminder(String text, long dueAtMs) implements Delayed {
        @Override public long getDelay(TimeUnit unit) {
            return unit.convert(dueAtMs - System.currentTimeMillis(), TimeUnit.MILLISECONDS);
        }
        @Override public int compareTo(Delayed o) {
            return Long.compare(getDelay(TimeUnit.MILLISECONDS), o.getDelay(TimeUnit.MILLISECONDS));
        }
    }

    static final String POISON = "__STOP__";

    public static void main(String[] args) throws Exception {
        BlockingQueue<String> bounded = new ArrayBlockingQueue<>(2);
        bounded.put("a");
        bounded.put("b");
        System.out.println("full queue: offer -> " + bounded.offer("c")
                + ", offer(50 ms) -> " + bounded.offer("c", 50, TimeUnit.MILLISECONDS));
        Thread taker = new Thread(() -> {
            try { Thread.sleep(100); bounded.take(); } catch (InterruptedException e) { Thread.currentThread().interrupt(); }
        });
        taker.start();
        long t0 = System.nanoTime();
        bounded.put("c");                                      // blocks until the taker makes room
        System.out.printf("put blocked for ~%d ms until a take made room%n", Math.round((System.nanoTime() - t0) / 1e8) * 100);
        taker.join();

        SynchronousQueue<String> handoff = new SynchronousQueue<>();
        System.out.println("SynchronousQueue offer with no taker -> " + handoff.offer("x") + ", size " + handoff.size());

        System.out.println("LinkedBlockingQueue() capacity: " + new LinkedBlockingQueue<String>().remainingCapacity());

        long now = System.currentTimeMillis();
        DelayQueue<Reminder> reminders = new DelayQueue<>(List.of(new Reminder("in 150 ms", now + 150),
                new Reminder("in 50 ms", now + 50), new Reminder("in 100 ms", now + 100)));
        System.out.print("DelayQueue releases:");
        for (int i = 0; i < 3; i++) System.out.print(" [" + reminders.take().text() + "]");
        System.out.println();

        PriorityBlockingQueue<Integer> urgent = new PriorityBlockingQueue<>(List.of(5, 1, 3));
        System.out.println("PriorityBlockingQueue take -> " + urgent.take());

        BlockingQueue<String> work = new LinkedBlockingQueue<>(100);
        List<String> done = Collections.synchronizedList(new ArrayList<>());
        int consumers = 3;
        try (ExecutorService pool = Executors.newFixedThreadPool(consumers)) {
            for (int c = 0; c < consumers; c++)
                pool.submit(() -> {
                    for (String job; !(job = work.take()).equals(POISON); ) done.add(job);
                    return null;                                // a poison pill ends each consumer
                });
            for (int i = 1; i <= 30; i++) work.put("job-" + i);
            for (int c = 0; c < consumers; c++) work.put(POISON);
        }
        System.out.println("poison pills: 3 consumers finished " + done.size() + " jobs and stopped");
    }
}

ImplementationShape
ArrayBlockingQueueBounded array, one lock. The predictable choice; optionally fair.
LinkedBlockingQueueLinked nodes, separate locks for put and take, so more throughput. Unbounded unless you pass a capacity: 2,147,483,647 above.
SynchronousQueueNo capacity: each put waits for a take. The cached thread pool's queue.
PriorityBlockingQueueUnbounded heap: the smallest element first.
DelayQueueUnbounded; an element can be taken only once its delay has expired.
LinkedTransferQueuetransfer waits until a consumer has received the element.
Bound every queueAn unbounded queue turns overload into memory growth and seconds of hidden latency, and the first symptom is an OutOfMemoryError. A bounded one turns it into blocked producers or rejections, which the caller can see and act on.
