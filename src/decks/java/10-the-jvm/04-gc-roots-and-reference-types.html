Garbage is whatever cannot be reached from a GC root, and four kinds of reference decide what counts as reachable

The collector does not count references. It starts from the roots (every thread's locals, static fields, JNI handles and held monitors), marks everything it can reach, and reclaims the rest. That is why a cycle of objects that point at each other is still garbage. The java.lang.ref classes let code hold an object without keeping it alive, which is how caches, canonical maps and native-resource cleanup work.

References.java · weak, soft, cycles, WeakHashMap, Cleaner
// Run with: java -Xmx64m References.java
import java.lang.ref.*;
import java.util.*;

public class References {
    static final class Node {
        Node other;
        final byte[] payload = new byte[1024];
    }

    static void collect() throws InterruptedException {
        System.gc();                                    // a request; G1 runs a full collection here
        Thread.sleep(100);
    }

    public static void main(String[] args) throws Exception {
        Object strongTarget = new Object();
        WeakReference<Object> weak = new WeakReference<>(new Object());
        WeakReference<Object> weakButHeld = new WeakReference<>(strongTarget);
        SoftReference<byte[]> soft = new SoftReference<>(new byte[1024 * 1024]);
        collect();
        System.out.println("after a GC: weak cleared " + (weak.get() == null) + ", weak to a held object cleared "
                + (weakButHeld.get() == null) + ", soft cleared " + (soft.get() == null));

        List<byte[]> pressure = new ArrayList<>();
        try {
            while (true) pressure.add(new byte[1024 * 1024]);
        } catch (OutOfMemoryError e) {
            pressure.clear();
        }
        System.out.println("after memory pressure: soft cleared " + (soft.get() == null) + " (cleared before any OutOfMemoryError)");

        Node a = new Node(), b = new Node();
        a.other = b;
        b.other = a;                                    // a cycle
        WeakReference<Node> cycle = new WeakReference<>(a);
        a = null;
        b = null;
        collect();
        System.out.println("an unreachable cycle was collected: " + (cycle.get() == null));

        Map<Object, String> sessions = new WeakHashMap<>();
        Object key = new Object();
        sessions.put(key, "session data");
        System.out.println("WeakHashMap size with the key held: " + sessions.size());
        key = null;
        collect();
        System.out.println("WeakHashMap size after the key became unreachable: " + sessions.size());

        Cleaner cleaner = Cleaner.create();
        Object resource = new Object();
        cleaner.register(resource, () -> System.out.println("Cleaner action ran: release the native handle"));
        resource = null;
        collect();
        System.out.println("strongTarget kept alive to the end: " + (strongTarget != null));
    }
}

Generations

Most objects die young, so new objects go into a small young generation that is collected often and cheaply, by copying the few survivors. Objects that survive several collections move to the old generation, which is collected rarely. Every collector in the JDK except Epsilon builds on this idea.

The collectors

G1: the default since 9, region-based, with a pause-time goal. ZGC: pauses under a millisecond at any heap size, generational since 21 and only generational since 24. Parallel: throughput for batch work. Serial: small heaps. Choosing and reading one: garbage collection.

System.gc() and finalizeSystem.gc() is a request the JVM may ignore, and -XX:+DisableExplicitGC makes it a no-op; this demo relies on G1 honouring it. finalize() is deprecated for removal (JEP 421, 18): it ran late, or never, and could resurrect objects. Use try-with-resources, then Cleaner as a safety net.
