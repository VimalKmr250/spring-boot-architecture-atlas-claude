CompletableFuture chains async steps without blocking, and the method name says sequence or parallel

A CompletableFuture is a Future you can attach the next step to. thenApply transforms the value, thenCompose starts another async call that depends on it, and thenCombine joins two calls that run at the same time. The timings below show the difference: two dependent 100 ms calls take 200 ms, and five independent 200 ms calls also take 200 ms.

CfCompose.java · four simulated services on a dedicated I/O pool
import java.util.*;
import java.util.concurrent.*;

public class CfCompose {
    static final ExecutorService IO = Executors.newFixedThreadPool(8, Thread.ofPlatform().name("io-", 1).factory());

    static void pause(long ms) {
        try { Thread.sleep(ms); } catch (InterruptedException e) { Thread.currentThread().interrupt(); }
    }
    static CompletableFuture<Long> priceOf(String sku) {
        return CompletableFuture.supplyAsync(() -> { pause(200); return sku.length() * 100L; }, IO);
    }
    static CompletableFuture<Integer> stockOf(String sku) {
        return CompletableFuture.supplyAsync(() -> { pause(200); return sku.equals("tea") ? 0 : 12; }, IO);
    }
    static CompletableFuture<String> customerTier(String id) {
        return CompletableFuture.supplyAsync(() -> { pause(100); return id.startsWith("vip") ? "GOLD" : "BASIC"; }, IO);
    }
    static CompletableFuture<Double> discountFor(String tier) {
        return CompletableFuture.supplyAsync(() -> { pause(100); return tier.equals("GOLD") ? 0.1 : 0.0; }, IO);
    }
    static long ms(long t0) { return Math.round((System.nanoTime() - t0) / 1e8) * 100; }   // to 100 ms

    public static void main(String[] args) {
        priceOf("warm-up").join();                       // start the pool threads, load classes
        long t0 = System.nanoTime();
        String label = priceOf("milk")
                .thenApply(cents -> String.format("%.2f", cents / 100.0))       // transform the value
                .join();
        System.out.println("thenApply   " + label + " after ~" + ms(t0) + " ms");

        t0 = System.nanoTime();
        double discount = customerTier("vip-7")
                .thenCompose(CfCompose::discountFor)                           // the next async call
                .join();
        System.out.println("thenCompose " + discount + " after ~" + ms(t0) + " ms (two calls in sequence)");

        t0 = System.nanoTime();
        String line = priceOf("bread")
                .thenCombine(stockOf("bread"), (p, s) -> p + " cents, " + s + " in stock")   // both at once
                .join();
        System.out.println("thenCombine " + line + " after ~" + ms(t0) + " ms (two calls in parallel)");

        t0 = System.nanoTime();
        List<String> skus = List.of("tea", "milk", "bread", "eggs", "jam");
        List<CompletableFuture<Long>> prices = skus.stream().map(CfCompose::priceOf).toList();
        CompletableFuture.allOf(prices.toArray(CompletableFuture[]::new)).join();   // wait for all
        List<Long> all = prices.stream().map(CompletableFuture::join).toList();      // none block now
        System.out.println("allOf       " + all + " after ~" + ms(t0) + " ms (five calls in parallel)");

        CompletableFuture<String> fast = CompletableFuture.supplyAsync(() -> { pause(50); return "replica-b"; }, IO);
        CompletableFuture<String> slow = CompletableFuture.supplyAsync(() -> { pause(300); return "replica-a"; }, IO);
        System.out.println("anyOf       " + CompletableFuture.anyOf(slow, fast).join());

        priceOf("jam").thenAccept(p -> System.out.println("thenAccept  saw " + p))
                      .thenRun(() -> System.out.println("thenRun     ran after it"))
                      .join();
        IO.shutdown();
    }
}

thenCombine(other, fn)A second future and (T, U) -> VTwo calls at once, joined
allOf(…)Any number of futuresCompletes with Void when all have; then join each
anyOf(…)Any number of futuresThe first to complete, typed as Object
thenAccept, thenRunA consumer, a runnableThe end of a chain: side effects
thenApply with an async functiontier.thenApply(CfCompose::discountFor) compiles, and gives a CompletableFuture<CompletableFuture<Double>>. Whenever the function itself returns a future, the method you want is thenCompose.
Start them, then waitallOf is fast because all five calls were started before anything waited. Calling priceOf(s).join() inside a loop starts each one only after the last has finished, and turns 200 ms into 1,000 ms.
