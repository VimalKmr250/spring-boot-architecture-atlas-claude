A Future is a handle to a result that may not exist yet, and shutting a pool down takes two decisions

submit returns a Future at once; get blocks until the task finishes, and rethrows its failure wrapped in ExecutionException. Two details cause most production surprises: a timed-out get does not stop the task, and an exception in a task whose Future nobody reads disappears without a trace. Shutting down means deciding what happens to queued work, and how long to wait for running work.

FutureShutdown.java · timeouts, cancellation, lost exceptions, shutdownNow
import java.util.List;
import java.util.concurrent.*;

public class FutureShutdown {
    static String slowQuote() throws InterruptedException {
        Thread.sleep(5_000);
        return "quote";
    }

    public static void main(String[] args) throws Exception {
        ExecutorService pool = Executors.newFixedThreadPool(2);

        Future<String> slow = pool.submit(FutureShutdown::slowQuote);
        try {
            slow.get(100, TimeUnit.MILLISECONDS);
        } catch (TimeoutException e) {
            System.out.println("get(100 ms): TimeoutException; the task keeps running: done=" + slow.isDone());
        }
        System.out.println("cancel(true) " + slow.cancel(true) + ", state " + slow.state());

        Future<Integer> failing = pool.submit(() -> Integer.parseInt("12x"));
        try {
            failing.get();
        } catch (ExecutionException e) {
            System.out.println("ExecutionException wraps " + e.getCause());
        }
        System.out.println("exceptionNow(): " + failing.exceptionNow().getClass().getSimpleName());

        Future<?> forgotten = pool.submit(() -> { throw new IllegalStateException("nobody will see this"); });
        while (!forgotten.isDone()) Thread.sleep(1);
        System.out.println("submit() kept the exception inside the Future: state " + forgotten.state());

        Future<Integer> ok = pool.submit(() -> 6 * 7);
        System.out.println("resultNow() " + ok.get() + " / " + ok.resultNow());

        List<Callable<String>> calls = List.of(() -> "price", () -> "stock", () -> "tax");
        System.out.println("invokeAll: " + pool.invokeAll(calls).stream().map(Future::resultNow).toList());

        CountDownLatch busy = new CountDownLatch(1);
        pool.submit(() -> { busy.await(); return null; });
        pool.submit(() -> { busy.await(); return null; });   // both threads now busy
        for (int i = 0; i < 3; i++) pool.submit(() -> "queued");
        List<Runnable> neverStarted = pool.shutdownNow();     // interrupts the running two
        System.out.println("shutdownNow: " + neverStarted.size() + " queued tasks never ran; terminated "
                + pool.awaitTermination(1, TimeUnit.SECONDS));
        try {
            pool.submit(() -> "late");
        } catch (RejectedExecutionException e) {
            System.out.println("submit after shutdown: RejectedExecutionException");
        }

        ThreadFactory withHandler = r -> {
            Thread th = new Thread(r, "worker");
            th.setUncaughtExceptionHandler((x, e) -> System.out.println("uncaught handler got: " + e.getMessage()));
            return th;
        };
        try (ExecutorService single = Executors.newSingleThreadExecutor(withHandler)) {
            single.execute(() -> { throw new IllegalStateException("thrown inside execute()"); });
        }
    }
}

Future methodDoes
get(), get(timeout)Blocks for the result. The timed form throws TimeoutException and leaves the task running.
cancel(true)Stops a queued task from starting, and interrupts a running one, which must honour it.
state(), resultNow(), exceptionNow() 19Inspect a finished future without blocking or catching checked exceptions.
invokeAll, invokeAnyRun a batch and wait for all of them, or for the first success.
The exception nobody sawsubmit catches everything the task throws and stores it in the Future. If nobody calls get, nothing is logged: the forgotten task failed in silence. Use execute for fire-and-forget work, whose exceptions reach the thread's uncaught-exception handler, or catch and log inside the task.
Shutting down properlyshutdown() refuses new work and lets queued tasks finish. shutdownNow() also interrupts running tasks and returns the ones that never started. The usual sequence: shutdown, awaitTermination with a deadline, then shutdownNow. A pool of non-daemon threads that is never shut down keeps the JVM alive after main ends.
