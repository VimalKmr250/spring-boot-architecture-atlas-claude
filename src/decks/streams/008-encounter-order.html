A stream is ordered only if its source is

A stream has an encounter order when its source has one. A List, an array, Stream.of, iterate and IntStream.range are ordered. A HashSet, a HashMap's views and generate are not. Most operations keep whatever order there is; sorted() imposes one, and unordered() drops it. Sequentially this rarely matters. In parallel, it decides what is correct and what is fast.

The same eight ids, four terminal operations, run in parallel
List<Integer> ids = List.of(1, 2, 3, 4, 5, 6, 7, 8);

ids.parallelStream().forEach(System.out::print);
// 65378421, and different on the next run

ids.parallelStream().forEachOrdered(System.out::print);
// 12345678, always

ids.parallelStream().map(i -> i * 10).toList();
// [10, 20, 30, 40, 50, 60, 70, 80]: collecting keeps order

ids.parallelStream().findAny();
// whichever chunk answers first: often not 1
OperationWhat order means to it
findFirst vs findAnyFirst by encounter order, versus any element at all. findAny is cheaper in parallel.
forEach vs forEachOrderedforEach ignores order in parallel, by design.
limit · skipThe first n, or all but the first n, by position.
distinctKeeps the first occurrence of each element when ordered.
sorted(cmp)Stable (ties keep their input order) only when the stream is ordered.
toList · toArray · joiningResults in encounter order, even in parallel.
collect(toSet()) · groupingBy keysThe container decides; a HashMap has no order to keep.
The order that was never thereA test asserts List.of("a", "b") against set.stream().map(…).toList(), where set is a HashSet. It passes for years, then fails after a JDK upgrade or a change in element count, because a hash set's iteration order depends on capacity and hash codes. Assert on a set, sort first, or use a LinkedHashSet on purpose.
unordered() is a performance hintOn a parallel stream, .unordered().distinct() and .unordered().limit(n) can skip the bookkeeping that preserves position. Use it only when any n elements, or any survivor of a duplicate set, is genuinely acceptable. It changes which elements you get, not just the speed.
