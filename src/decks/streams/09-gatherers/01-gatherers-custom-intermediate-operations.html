gather is to intermediate operations what collect is to terminal ones

Java 24 made Stream Gatherers final (JEP 485, after previews in 22 and 23). A Gatherer is an intermediate operation you define yourself. It can keep state, emit any number of elements for each input, stop the stream early, and optionally run in parallel. It is the long-awaited answer to "there is no windowing, distinctBy or running total in the Stream API".

The interface, trimmed (java.util.stream.Gatherer)
public interface Gatherer<T, A, R> {          // T in, A state, R out
    default Supplier<A> initializer();           // fresh state per run      (optional)
    Integrator<A, T, R> integrator();            // called once per element  (required)
    default BinaryOperator<A> combiner();        // merge states: parallel   (optional)
    default BiConsumer<A, Downstream<? super R>> finisher();   // flush at end (optional)
    default <RR> Gatherer<T, ?, RR> andThen(Gatherer<? super R, ?, ? extends RR> that);

    interface Integrator<A, T, R> {
        boolean integrate(A state, T element, Downstream<? super R> downstream);
        // return false to stop: the stream short-circuits
    }
    interface Downstream<T> {
        boolean push(T element);                 // false: downstream wants no more
        default boolean isRejecting();
    }
}
Collector (terminal)Gatherer (intermediate)
supplierinitializer
accumulator: consume one elementintegrator: consume one, push zero or more, or stop
combinercombiner: without one, the stage runs sequentially
finisher: build the resultfinisher: push whatever state is left
Produces one resultProduces a stream, which carries on
Greedy integratorsGatherer.Integrator.ofGreedy(…) marks an integrator that never starts a short-circuit itself: it only passes on the downstream's "stop". Declaring it lets the stream skip some cancellation checks. Integrator.of(…) is the general form. stream.gather(a).gather(b) is equivalent to stream.gather(a.andThen(b)).
When to reach for oneWhen an intermediate step needs memory of earlier elements (windows, running totals, "distinct by key", de-duplicating consecutive repeats), or must stop on a condition that depends on accumulated state. Before Java 24, those needed a loop or a collector followed by a second stream. Primitive streams have no gather, so box first.
