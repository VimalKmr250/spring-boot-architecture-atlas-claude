Strings: word frequency, grouping and reordering

The input is String text = "to be or not to be that is the question", split with String[] words = text.split("\\s+"). The word-frequency drill, sorted by count, is the stream question most often set as live coding.

Drills 37–42
// 37 · Word frequency, most common first, ties alphabetical
Map<String, Long> counts = Arrays.stream(words)
        .collect(groupingBy(Function.identity(), counting()));
counts.entrySet().stream()
      .sorted(Map.Entry.<String, Long>comparingByValue().reversed()
                       .thenComparing(Map.Entry.comparingByKey()))
      .map(e -> e.getKey() + "=" + e.getValue())
      .toList();
// [be=2, to=2, is=1, not=1, or=1, question=1, that=1, the=1]

// 38 · The longest word
Arrays.stream(words).max(Comparator.comparingInt(String::length));   // Optional[question]

// 39 · Words grouped by length
Arrays.stream(words).collect(groupingBy(String::length, TreeMap::new, toList()));
// {2=[to, be, or, to, be, is], 3=[not, the], 4=[that], 8=[question]}

// 40 · The words that repeat
counts.entrySet().stream()
      .filter(e -> e.getValue() > 1)
      .map(Map.Entry::getKey)
      .sorted().toList();                               // [be, to]

// 41 · Distinct words, in order
Arrays.stream(words).distinct().toList();
// [to, be, or, not, that, is, the, question]

// 42 · How many words start with "t"
Arrays.stream(words).filter(w -> w.startsWith("t")).count();          // 4
Drills 43–47
// 43 · Reverse each word, keep the word order
Arrays.stream(words)
      .map(w -> new StringBuilder(w).reverse().toString())
      .collect(joining(" "));
// ot eb ro ton ot eb taht si eht noitseuq

// 44 · Reverse the word order
IntStream.range(0, words.length)
         .mapToObj(i -> words[words.length - 1 - i])
         .collect(joining(" "));
// question the is that be to not or be to
String.join(" ", List.of(words).reversed());         // the same, Java 21

// 45 · Capitalise every word
Arrays.stream(words)
      .map(w -> Character.toUpperCase(w.charAt(0)) + w.substring(1))
      .collect(joining(" "));
// To Be Or Not To Be That Is The Question

// 46 · Group anagrams
List.of("listen", "silent", "enlist", "google", "gogole", "cat", "act").stream()
    .collect(groupingBy(
        w -> w.chars().sorted()
              .collect(StringBuilder::new, StringBuilder::appendCodePoint, StringBuilder::append)
              .toString(),
        LinkedHashMap::new, toList()))
    .values();
// [[listen, silent, enlist], [google, gogole], [cat, act]]

// 47 · Join with a delimiter, prefix and suffix
Arrays.stream(words).distinct().limit(4).collect(joining(", ", "[", "]"));
// [to, be, or, not]
#The follow-up they askWhat to say
37Why the explicit <String, Long>?comparingByValue().reversed() has no target type to infer from, the same trap as comparing(lambda).reversed().
37Now for a 10 GB log file?Files.lines in try-with-resources, flatMap to words, and the same collector: memory grows with the number of distinct words, not the file size.
45What if the text has two spaces in a row?split(" ") produces an empty word, and charAt(0) throws StringIndexOutOfBoundsException. Splitting on "\\s+" avoids it; so does filter(w -> !w.isEmpty()).
46What is the key?The letters in sorted order: every anagram of a word has the same one. The key costs O(L log L) per word.
