How a Collector works, and writing your own

A Collector is four functions and a set of flags. Knowing them explains how collect runs in parallel, what the concurrent collectors change, and how to write the collector the library lacks.

Part of Collector<T, A, R>Role
supplier()A new, empty mutable container A
accumulator()Adds one element T to a container
combiner()Merges two containers. Only used in parallel, and so only tested there
finisher()Turns the container into the result R
IDENTITY_FINISHThe container is the result; the finisher is skipped
UNORDEREDThe result does not depend on encounter order
CONCURRENTOne container can take elements from several threads at once

Parallel collect, in three moves

  1. Each chunk of the split stream gets its own container from supplier(), so no locking is needed.
  2. Each thread runs accumulator() on its chunk.
  3. combiner() merges the containers pairwise, in encounter order, then finisher() runs once.

The concurrent collectors, groupingByConcurrent and toConcurrentMap, are CONCURRENT and UNORDERED. On a parallel stream every thread writes into one ConcurrentHashMap and step 3 disappears. The price is that the elements inside each group lose their encounter order.

A top-N collector: O(n log k) time and O(k) memory
static <T> Collector<T, ?, List<T>> topN(int n, Comparator<? super T> cmp) {
    return Collector.of(
        () -> new PriorityQueue<T>(cmp),                  // a min-heap of the best n
        (heap, t) -> { heap.add(t); if (heap.size() > n) heap.poll(); },
        (a, b) -> { for (T t : b) { a.add(t); if (a.size() > n) a.poll(); } return a; },
        heap -> heap.stream().sorted(cmp.reversed()).toList());   // best first
}

List<Order> top3 = orders.stream()
        .collect(topN(3, Comparator.comparingDouble(Order::total)));
The combiner nobody ranA custom collector whose combiner is (a, b) -> a passes every sequential test, because sequential streams never call it. The first time someone adds .parallel(), every chunk but one is silently thrown away.
