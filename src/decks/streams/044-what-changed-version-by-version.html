What each Java release added to streams

Streams arrived in Java 8 and have grown in small steps since, with one big one: Gatherers in 24. When a codebase is pinned to an older version, this table says which idioms it cannot use. The last three rows were checked against the JDKs' own class files and API lists.

82014 · LTSjava.util.stream: Stream, the three primitive streams, Collector, Collectors (37 methods), StreamSupport. Optional, java.util.function, Collection.stream(), and stream sources across the JDK: Files.lines, BufferedReader.lines, chars(), Random.ints, Pattern.splitAsStream

The version question in interviews"What's new in streams since Java 8?" The strong answer names four things and a date: takeWhile/dropWhile in 9, teeing in 12, toList() and mapMulti in 16, and Gatherers, final in 24, which make custom intermediate operations possible for the first time. Then add that toList() returns an unmodifiable list: that is the follow-up.
