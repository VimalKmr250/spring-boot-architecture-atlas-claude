The whole Stream API, and the failure behind each method

A reference for java.util.stream as it stands in JDK 25. It covers every method on Stream and the primitive streams, all 44 Collectors, the Gatherers that became final in Java 24, and the Optional that the search and reduce operations return. It ends with the stream questions interviewers ask most often, and the coding problems they set, solved.

57

methods on Stream: 40 instance, 9 static and 8 inherited from BaseStream. Every one is in the index on slide 3, linked to the slide that covers it.

44

factory methods on Collectors, from toList to teeing. Slide 4 lists them all, along with the five Gatherers and every Optional method.

25

JDK 25, the current LTS, is the target. JDK 26 ships the identical stream API. Anything added after Java 8 carries a since tag.

How to use it

  • Arrow keys move through slides; C opens contents, where each topic is its own section.
  • since 16 marks an API added after Java 8, with the release that added it. No tag means Java 8.
  • Slide 5 runs a real pipeline one element at a time. Step through it before reading the rest of How a stream runs; the next five slides assume you have.
  • Preparing for an interview? Read Interview questions, then work the Coding drills with the solutions covered. Every answer links back to the slide that goes deeper.
How the API slides are writtenEvery method gets three things: what it does, a real line of code, and the failure it causes when used wrongly. The examples compile on JDK 25; the two listings marked "trimmed" or "simplified" show only the shape of JDK internals. Where a slide quotes an output or an exception message, it is what the JVM actually printed.
