Numbers: the warm-ups

All twelve use List<Integer> nums = List.of(5, 3, 8, 3, 9, 1, 8, 2, 7, 10). Interviewers use these to check fluency. Aim to write each without pausing, then say the edge case.

Drills 1–6
// 1 · Split into even and odd
nums.stream().collect(partitioningBy(n -> n % 2 == 0));
// {false=[5, 3, 3, 9, 1, 7], true=[8, 8, 2, 10]}

// 2 · Sum, average, min and max in one pass
nums.stream().mapToInt(Integer::intValue).summaryStatistics();
// IntSummaryStatistics{count=10, sum=56, min=1, average=5.600000, max=10}

// 3 · Square each, keep the squares above 20
nums.stream().map(n -> n * n).filter(sq -> sq > 20).toList();
// [25, 64, 81, 64, 49, 100]

// 4 · Sort ascending, then descending
nums.stream().sorted().toList();                             // [1, 2, 3, 3, 5, 7, 8, 8, 9, 10]
nums.stream().sorted(Comparator.reverseOrder()).toList();    // [10, 9, 8, 8, 7, 5, 3, 3, 2, 1]

// 5 · Remove duplicates, keeping the first occurrence
nums.stream().distinct().toList();                           // [5, 3, 8, 9, 1, 2, 7, 10]

// 6 · Find the duplicates
nums.stream()
    .collect(groupingBy(Function.identity(), LinkedHashMap::new, counting()))
    .entrySet().stream()
    .filter(e -> e.getValue() > 1)
    .map(Map.Entry::getKey)
    .toList();                                               // [3, 8]
Drills 7–12
// 7 · Frequency of each number, in key order
nums.stream().collect(groupingBy(Function.identity(), TreeMap::new, counting()));
// {1=1, 2=1, 3=2, 5=1, 7=1, 8=2, 9=1, 10=1}

// 8 · How many are greater than 5
nums.stream().filter(n -> n > 5).count();                   // 5

// 9 · Product of all of them, safely
nums.stream().mapToLong(Integer::longValue).reduce(1, (a, b) -> a * b);
// 3628800

// 10 · All positive? Any negative?
nums.stream().allMatch(n -> n > 0);                         // true
nums.stream().anyMatch(n -> n < 0);                         // false

// 11 · The first number greater than 7
nums.stream().filter(n -> n > 7).findFirst();               // Optional[8]

// 12 · List<Integer> to int[]
int[] arr = nums.stream().mapToInt(Integer::intValue).toArray();
#The follow-up they askWhat to say
2Why not four separate streams?Four passes over the data; summaryStatistics is one pass, and it stays correct for a stream that can be read only once.
6Can you do it with a Set?filter(n -> !seen.add(n)) gives the same [3, 8], but the lambda mutates a shared HashSet: correct sequentially, broken in parallel. The grouping version is safe either way.
9Why mapToLong, and why identity 1?Products overflow int fast. And 1 is the true identity of multiplication, where 0 would zero everything.
10What does allMatch return on an empty list?true. There is no counterexample. anyMatch returns false.
