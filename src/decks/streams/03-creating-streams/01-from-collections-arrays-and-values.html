Most streams start from something you already hold

A collection, an array, a handful of values, a map's entries. Each has one idiomatic factory. Each factory also has a trap that looks fine until the shape of the data changes.

One line per factory
Stream<Order> fromList   = orders.stream();                  // ordered, like the list
IntStream     fromInts   = Arrays.stream(new int[]{3, 1, 4});  // primitive: no boxing
Stream<String> middle    = Arrays.stream(skus, 1, 3);         // indices 1 and 2
Stream<String> literals  = Stream.of("NEW", "PAID", "SHIPPED");
Stream<Map.Entry<String, Integer>> stock = stockBySku.entrySet().stream();

Stream<Integer> maybe = Stream.ofNullable(stockBySku.get("X-9"));   // empty when null (9)
Stream<String> none  = Stream.empty();
Stream<String> built = Stream.<String>builder().add("a").add("b").build();
Stream<Order>  both  = Stream.concat(open.stream(), archived.stream());
FactoryWatch for
collection.stream()Ordered only if the collection is. A HashSet gives no order to keep.
parallelStream()A request, not a promise. See the parallel section before reaching for it.
map.entrySet().stream()There is no Map.stream(). Stream the entries, keys or values.
Arrays.stream(a, from, to)Half-open: to is excluded, like substring.
Stream.ofNullable(x) 9Zero or one element. Pairs well with flatMap over a nullable field.
Stream.builder()One use: add after build() throws IllegalStateException.
Stream.concat(a, b)Parallel if either input is. Closing it closes both inputs.
Stream.of(int[]) is not an IntStreamStream.of(new int[]{1, 2, 3}).count() returns 1. Varargs cannot take an int[] as T..., because T must be a reference type, so the whole array becomes one element of a Stream<int[]>. Use Arrays.stream(int[]) or IntStream.of(1, 2, 3). Arrays.asList(int[]) has the same trap.
Concatenating in a loopEach concat wraps the previous stream, so reading the first element walks down the whole chain. On JDK 25, 100,000 nested concat calls threw StackOverflowError on the first element read. To join many streams, stream the collection of sources and flatMap: sources.stream().flatMap(List::stream).
