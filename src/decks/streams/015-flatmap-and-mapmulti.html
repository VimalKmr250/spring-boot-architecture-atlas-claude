One element in, any number out

map is one-to-one. When each element expands into zero, one or many results — an order into its lines, a sentence into words, an optional value into zero or one — use flatMap. Since Java 16, mapMulti does the same job imperatively.

flatMap, flatMapToInt and flattening Optionals
List<String> skus = orders.stream()
        .flatMap(o -> o.lines().stream())   // Stream<Line>
        .map(Line::sku)
        .distinct()
        .toList();

int totalUnits = orders.stream()
        .flatMapToInt(o -> o.lines().stream().mapToInt(Line::qty))
        .sum();

List<String> emails = customers.stream()
        .map(directory::findEmail)          // Stream<Optional<String>>
        .flatMap(Optional::stream)          // drop the empties (9)
        .toList();
mapMulti: push results instead of building streams (16)
List<Line> bulkLines = orders.stream()
        .<Line>mapMulti((order, sink) -> {
            for (Line l : order.lines())
                if (l.qty() >= 10) sink.accept(l);
        })
        .toList();

// Zero or one per element, with a type test
List<Refund> refunds = events.stream()
        .<Refund>mapMulti((e, sink) -> {
            if (e instanceof Refund r) sink.accept(r);
        })
        .toList();
