Collections and maps: flatten, invert, sort by value, batch

The utility questions. Several have a Java 24 answer, using Gatherers, alongside the classic one. Know both, and say which version of Java the codebase is on.

Drills 70–75
// 70 · Flatten a list of lists
List.of(List.of(1, 2), List.of(3), List.of(4, 5, 6)).stream()
    .flatMap(List::stream).toList();                  // [1, 2, 3, 4, 5, 6]

// 71 · List to map when keys repeat: merge the values
employees.stream().collect(toMap(Employee::dept, Employee::name,
                                 (a, b) -> a + ", " + b, TreeMap::new));
// {Engineering=Asha, Bruno, Chen, Finance=Goran, Hana, ...}

// 72 · Sort a map by value, highest first, into an ordered map
headcount.entrySet().stream()
         .sorted(Map.Entry.<String, Long>comparingByValue().reversed()
                          .thenComparing(Map.Entry.comparingByKey()))
         .collect(toMap(Map.Entry::getKey, Map.Entry::getValue,
                        (a, b) -> a, LinkedHashMap::new));
// {Sales=4, Engineering=3, Finance=2, Support=2}

// 73 · Invert a map whose values repeat
Map.of("Asha", "Pune", "Chen", "Pune", "Hana", "Prague").entrySet().stream()
   .collect(groupingBy(Map.Entry::getValue, TreeMap::new,
                       mapping(Map.Entry::getKey, toCollection(TreeSet::new))));
// {Prague=[Hana], Pune=[Asha, Chen]}

// 74 · The key with the largest value
headcount.entrySet().stream().max(Map.Entry.comparingByValue())
         .map(Map.Entry::getKey);                     // Optional[Sales]

// 75 · Merge two maps, adding values for shared keys
Stream.of(Map.of("apples", 3, "pears", 2), Map.of("apples", 5, "plums", 1))
      .flatMap(m -> m.entrySet().stream())
      .collect(toMap(Map.Entry::getKey, Map.Entry::getValue, Integer::sum, TreeMap::new));
// {apples=8, pears=2, plums=1}
Drills 76–81
// 76 · Zip two lists
List<String> names = List.of("Asha", "Bruno", "Chen");
List<String> cities = List.of("Pune", "Lisbon", "Pune", "Dublin");
IntStream.range(0, Math.min(names.size(), cities.size()))
         .mapToObj(i -> names.get(i) + "@" + cities.get(i))
         .toList();                                   // [Asha@Pune, Bruno@Lisbon, Chen@Pune]

// 77 · Batches of three: Java 24, then the classic way
List<Integer> seven = List.of(1, 2, 3, 4, 5, 6, 7);
seven.stream().gather(Gatherers.windowFixed(3)).toList();
IntStream.range(0, (seven.size() + 2) / 3)
         .mapToObj(i -> seven.subList(i * 3, Math.min(seven.size(), (i + 1) * 3)))
         .toList();                                   // both [[1, 2, 3], [4, 5, 6], [7]]

// 78 · Three-point moving average
List.of(10.0, 11.0, 12.0, 13.0, 20.0).stream()
    .gather(Gatherers.windowSliding(3))
    .map(w -> w.stream().mapToDouble(Double::doubleValue).average().orElseThrow())
    .toList();                                        // [11.0, 12.0, 15.0]

// 79 · Word count across the lines of a file
try (Stream<String> lines = Files.lines(path)) {
    lines.flatMap(l -> Arrays.stream(l.toLowerCase().split("\\W+")))
         .filter(w -> !w.isBlank())
         .collect(groupingBy(Function.identity(), TreeMap::new, counting()));
}   // "The cat sat." / "The cat ran!" gives {cat=2, ran=1, sat=1, the=2}

// 80 · Arrays to lists and back
Arrays.stream(new int[]{3, 1, 2}).boxed().toList();        // [3, 1, 2]
List.of(3, 1, 2).stream().mapToInt(Integer::intValue).toArray();
List.of("a", "b").toArray(String[]::new);                  // no stream needed (11)

// 81 · Index of the first element above 7
IntStream.range(0, nums.size()).filter(i -> nums.get(i) > 7).findFirst();   // OptionalInt[2]
#The follow-up they askWhat to say
72Why LinkedHashMap::new and the merge function?A HashMap would throw away the order you just sorted into. The four-argument toMap is the only one that takes a map factory, so the merge function comes with it, even though keys from a map cannot collide.
73Why not toMap(getValue, getKey)?Two people live in Pune: a duplicate key, so IllegalStateException. When values can repeat, inverting is a grouping.
77Which would you ship?On Java 24 or later, windowFixed: it works on any stream, including one read once from a file. The subList version needs a random-access list, and its batches are views of it.
81Why not list.indexOf?indexOf finds an equal element, not one matching a condition. IntStream.range over indexes is the stream idiom whenever the answer is a position.
