Strings: character counting, without the traps

The input is String s = "programming". Nearly every character question is a frequency map in disguise, so build that first. Remember that chars() yields ints, not chars.

Drills 26–31
// 26 · Frequency of each character, in order of first appearance
Map<Character, Long> freq = s.chars()
        .mapToObj(c -> (char) c)
        .collect(groupingBy(Function.identity(), LinkedHashMap::new, counting()));
// {p=1, r=2, o=1, g=2, a=1, m=2, i=1, n=1}

// 27 · First non-repeated character
freq.entrySet().stream()
    .filter(e -> e.getValue() == 1)
    .map(Map.Entry::getKey)
    .findFirst();                                   // Optional[p]

// 28 · Every character that repeats
freq.entrySet().stream()
    .filter(e -> e.getValue() > 1)
    .map(Map.Entry::getKey)
    .toList();                                      // [r, g, m]

// 29 · First character seen for the second time
Set<Character> seen = new HashSet<>();
s.chars().mapToObj(c -> (char) c)
 .filter(c -> !seen.add(c))
 .findFirst();                                      // Optional[r]  (sequential only)

// 30 · The most frequent character
freq.entrySet().stream().max(Map.Entry.comparingByValue());   // Optional[r=2]

// 31 · Count the vowels
s.chars().filter(c -> "aeiou".indexOf(c) >= 0).count();     // 3
Drills 32–36
// 32 · Reverse the string
new StringBuilder(s).reverse().toString();          // gnimmargorp
IntStream.range(0, s.length())
         .mapToObj(i -> String.valueOf(s.charAt(s.length() - 1 - i)))
         .collect(joining());                       // gnimmargorp, the stream way

// 33 · Is it a palindrome?
String r = "racecar";
IntStream.range(0, r.length() / 2)
         .allMatch(i -> r.charAt(i) == r.charAt(r.length() - 1 - i));   // true

// 34 · Are two words anagrams?
Arrays.equals("listen".chars().sorted().toArray(),
              "silent".chars().sorted().toArray());                    // true

// 35 · Remove duplicate characters, keeping order
s.chars().distinct()
 .mapToObj(c -> String.valueOf((char) c))
 .collect(joining());                               // progamin

// 36 · Count upper case, lower case and digits in "Java25Streams!"
String t = "Java25Streams!";
t.chars().filter(Character::isUpperCase).count();   // 2
t.chars().filter(Character::isLowerCase).count();   // 9
t.chars().filter(Character::isDigit).count();       // 2
#The follow-up they askWhat to say
26Why LinkedHashMap::new?Drill 27 needs the first non-repeated character. A plain groupingBy uses a HashMap, which forgets the order of appearance.
29What is wrong with the Set version?The filter lambda mutates shared state. It works sequentially and is wrong in parallel. For "first repeated", a plain loop with early exit is honest and O(n).
30r, g and m all appear twice. Why r?max keeps the first of equal elements it meets, and the map is in appearance order. If ties matter, say what the rule should be.
32Should you use a stream to reverse a string?No. StringBuilder.reverse() is the answer; the stream version shows you know IntStream.range. Reversing with reduce("", (a, c) -> c + a) is O(n²).
—What about emoji?chars() splits characters outside the Basic Multilingual Plane into two surrogate code units. Use codePoints() and Character.toString(int).
