filter keeps or drops; map replaces

The two operations in almost every pipeline. filter keeps the elements a predicate accepts. map replaces each element with a function of it. Its primitive variants, mapToInt, mapToLong and mapToDouble, avoid boxing when the result is a number.

The running example
double paidRevenue = orders.stream()
        .filter(o -> "PAID".equals(o.status()))    // constant first: null-safe
        .mapToDouble(Order::total)                 // DoubleStream: no boxing
        .sum();

List<String> customers = orders.stream()
        .map(Order::customer)                      // Stream<Order> → Stream<String>
        .toList();

List<String> labels = IntStream.range(0, 3)
        .mapToObj(i -> "#" + i)                    // IntStream → Stream<String>
        .toList();                                 // [#0, #1, #2]

Predicate<Order> paid = o -> "PAID".equals(o.status());
Predicate<Order> large = o -> o.total() > 500;
orders.stream().filter(paid.and(large.negate()));  // composed predicates
