Employees: grouping and aggregating

Using the employees list from the first drill slide. Every answer here is a single groupingBy with the right downstream collector, and a TreeMap::new so that the printed output is in a stable order.

Drills 48–53
// 48 · Names grouped by department
employees.stream().collect(groupingBy(Employee::dept, TreeMap::new,
                                      mapping(Employee::name, toList())));
// {Engineering=[Asha, Bruno, Chen], Finance=[Goran, Hana],
//  Sales=[Dara, Emeka, Farah, Kofi], Support=[Ivo, Jia]}

// 49 · Headcount per department
Map<String, Long> headcount = employees.stream()
        .collect(groupingBy(Employee::dept, TreeMap::new, counting()));
// {Engineering=3, Finance=2, Sales=4, Support=2}

// 50 · Average salary per department
employees.stream().collect(groupingBy(Employee::dept, TreeMap::new,
                                      averagingDouble(Employee::salary)));
// {Engineering=113666.66666666667, Finance=91500.0, Sales=75750.0, Support=57500.0}

// 51 · The department with the most employees
headcount.entrySet().stream()
         .max(Map.Entry.comparingByValue())
         .map(Map.Entry::getKey);                     // Optional[Sales]

// 52 · Average age by gender
employees.stream().collect(groupingBy(Employee::gender, TreeMap::new,
                                      averagingInt(Employee::age)));
// {F=31.0, M=33.666666666666664}

// 53 · Split by age above 30
employees.stream().collect(partitioningBy(e -> e.age() > 30,
                                          mapping(Employee::name, toList())));
// {false=[Chen, Dara, Hana, Ivo, Kofi],
//  true=[Asha, Bruno, Emeka, Farah, Goran, Jia]}
Drills 54–58
// 54 · Total salary bill
employees.stream().mapToDouble(Employee::salary).sum();      // 942000.0

// 55 · Names per department as one string
employees.stream().collect(groupingBy(Employee::dept, TreeMap::new,
                                      mapping(Employee::name, joining(", "))));
// {Engineering=Asha, Bruno, Chen, Finance=Goran, Hana, ...}

// 56 · Headcount per city
employees.stream().collect(groupingBy(Employee::city, TreeMap::new, counting()));
// {Dublin=2, Lagos=2, Lisbon=2, Prague=1, Pune=3, Zagreb=1}

// 57 · Employees earning over 80,000, per department, keeping every department
employees.stream().collect(groupingBy(Employee::dept, TreeMap::new,
                                      filtering(e -> e.salary() > 80_000, counting())));
// {Engineering=3, Finance=2, Sales=2, Support=0}

// 58 · Salary statistics for one department
employees.stream()
         .collect(groupingBy(Employee::dept, summarizingDouble(Employee::salary)))
         .get("Sales");
// DoubleSummaryStatistics{count=4, sum=303000.000000, min=69000.000000,
//                         average=75750.000000, max=81000.000000}
#The follow-up they askWhat to say
49Why is the value Long?counting() returns Long. For Integer counts, use summingInt(e -> 1).
51What if two departments tie?max returns one of them. State the rule: "all of them" means finding the max count first, then filtering the entries equal to it.
57Why filtering and not filter first?Filtering before grouping drops Support entirely. filtering (Java 9) keeps it, with a count of 0.
50The client wants two decimal places.Format at the edge: keep the double in the map and format when printing. For money, prefer long cents or BigDecimal throughout.
