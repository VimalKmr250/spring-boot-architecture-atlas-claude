Design Dropbox: keep every device's folder identical, without re-sending what hasn't changed

Users drop files into a folder, and the same folder appears on their other devices and on their collaborators' machines, with version history and offline edits. The estimate points at the key idea. Split files into content-addressed blocks so an edit re-sends only the changed block, and keep the small, transactional metadata completely separate from the enormous, immutable bytes.

Functional

  • Upload, download, and sync changes to all of a user's devices automatically.
  • Shared folders across users; version history and restore.
  • Work offline; sync when back online.

Non-functional

  • Never lose or corrupt data: eleven nines of durability, with every block verified by hash.
  • Every device converges to the same state; changes propagate within seconds.
  • Frugal with bandwidth, battery and server storage.

Clarify

  • Largest file size? (Tens of GB.) Mobile clients as well as desktop?
  • Real-time co-editing? No: that's a different design (OT or CRDTs).
  • How are conflicts handled: last writer wins, or keep both copies?
