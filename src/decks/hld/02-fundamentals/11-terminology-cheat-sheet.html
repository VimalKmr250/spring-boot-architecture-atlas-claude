The vocabulary, one line each

Use these words precisely. Interviewers notice when "consistent" or "partition" is used loosely, and each one below has a slide later in the deck.

Load and performance

QPS / RPS
Queries or requests per second. Always state average and peak (peak is usually 2–10× average).
DAU / MAU
Daily and monthly active users, the input to most estimates.
p50 / p99
Median and 99th-percentile latency. p99 is what your heaviest users feel.
Tail latency
The slow end of the distribution, which fan-out amplifies.
Throughput
Work completed per unit time, in requests, rows or bytes per second.
Hot spot / hot key
One partition or key getting a disproportionate share of traffic.
Fan-out
One request or event turning into many downstream calls or writes.
Back pressure
A slow consumer signalling upstream to slow down instead of drowning.
Thundering herd
Many clients hitting the same resource at once, e.g. after a cache expiry or a restart.
Head-of-line blocking
One slow item delaying everything queued behind it.

Data and distribution

Replication
The same data copied to several nodes, for availability and read scale.
Partitioning / sharding
Different data on different nodes, for write scale and size.
Network partition
Nodes that are up but can't reach each other. Not the same thing as a data partition.
Quorum
A majority, or R + W > N, needed for an operation to count.
Linearizable
Behaves as if there were one copy. The precise meaning of "strongly consistent".
Eventual consistency
Replicas converge if writes stop; reads may be stale until then.
Idempotent
Doing it twice has the same effect as doing it once, which is what makes retries safe.
SPOF
Single point of failure: one component whose loss takes the system down.
Split brain
Two nodes both acting as the leader after a partition.
RPO / RTO
How much data you can lose, and how long you can be down.
