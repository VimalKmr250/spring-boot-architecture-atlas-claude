Three messaging shapes: work queue, fan-out topic, replayable log

"Put it on a queue" hides a real decision. A work queue hands each message to exactly one worker and then forgets it. Pub/sub copies each message to every subscriber. A log keeps messages in order for days and lets any number of consumer groups read, and re-read, at their own positions.
