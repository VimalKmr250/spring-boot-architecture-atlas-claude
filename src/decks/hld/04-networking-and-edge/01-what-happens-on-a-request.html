Follow one request from the browser to the database and back

Nearly every design shares the same front half: name resolution, an edge that caches, a balancer that spreads load, a gateway that enforces policy, and a stateless service in front of a cache and a database. Know that path cold. Then each interview design is mostly a question of what changes behind the service.
