Four ways a cache sends a flood to the database

Once the database is sized for a 95% hit ratio, the cache is load-bearing. Anything that suddenly drops the hit ratio becomes a database outage. These four failures have names, and interviewers expect you to name them, together with their fixes.

Say this in the deep dive"The database is sized for about 5% of reads. If the cache goes cold, we'll be at 20× that for a few minutes. So: jittered TTLs, single-flight loading on hot keys, a replicated Redis with warm-up before traffic returns, and a concurrency limit on database-bound queries, so a cold cache degrades latency instead of taking the database down."
