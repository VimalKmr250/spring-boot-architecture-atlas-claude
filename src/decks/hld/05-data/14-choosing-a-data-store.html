Every store trades query flexibility against scale

Stores that answer any question (relational, OLAP) are harder to scale for writes. Stores that scale almost without limit (wide-column, KV, object storage) answer only the questions you designed for. Place the requirement on this map, and name what you give up.

RequirementReach forBecause
Money, orders, inventory, bookingsPostgreSQL / MySQL (or Spanner at global scale)Transactions, constraints, strong consistency

Chat messages, feeds, IoT, event historyCassandra / ScyllaDB / DynamoDBWrite-heavy, partitioned by entity, time-ordered
Images, video, backups, logs archiveObject storage + CDNCheap, durable, unlimited; metadata in a DB
Product search, typo tolerance, facetsOpenSearch / ElasticsearchInverted index, relevance ranking
