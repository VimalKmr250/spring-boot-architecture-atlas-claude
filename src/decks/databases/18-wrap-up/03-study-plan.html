A three-week plan from first query to interview-ready, on real engines

Reading about isolation levels is not the same as watching a session block. Run the three engines locally, all free for development, load a small shop schema, and repeat the experiments in this tab yourself. By the end you will have numbers you measured, queries you wrote from the question alone, and an answer to every question in this tab.

Further reading

  • Use The Index, Luke: indexing and plans for developers, with Oracle and SQL Server examples
  • Oracle Database documentation: the SQL Language Reference and the Concepts guide's chapter on data concurrency
  • Transact-SQL reference, and the guide to transaction locking and row versioning
  • MongoDB data modelling and the aggregation chapters of the manual
  • Spring Data MongoDB reference and Testcontainers
  • Martin Kleppmann, Designing Data-Intensive Applications: chapters on storage, replication, partitioning and transactions
The engines used hereOracle AI Database 26ai Free (container-registry.oracle.com/database/free), SQL Server 2025 Developer (mcr.microsoft.com/mssql/server:2025-latest, which requires accepting the licence with ACCEPT_EULA=Y) and MongoDB (mongo:8, started as a one-node replica set so transactions and change streams work). With the example data loaded, the three together used about 4 GB of memory here.
