If the question saysReach forWatch out for
"…find documents where"find or $match first in the pipeline{ f: null } also matches a missing f; use $exists to tell them apart
"…an array element that has both A and B"$elemMatchTwo separate conditions may match two different elements
"…total / count / average per X"$group with $sum, $avg, $count$sum of a missing field is 0; doubles for money
"…per line item / per tag"$unwind, then $groupEmpty or missing arrays vanish unless preserveNullAndEmptyArrays
"…the top N in each group"$topN in $group; $denseRank for ties$push then $slice holds whole groups in memory
"…with the customer / product details"$lookup, late in the pipeline, after $limitNo index on foreignField: a scan per input document
"…that have no / never"$lookup with $limit: 1, then $size: 0; or distinct and $ninLarge distinct results hit the 16 MB limit
"…per 5 minutes / per day"$dateTrunc with binSize and timezoneDays in UTC when the business means local days
"…including the periods with no data"$densify, then $fillA plain $group skips the gaps silently
"…running total / previous value"$setWindowFields with $sum or $shiftMissing partitionBy mixes series
"…several summaries in one query"$facetAll facets come back in one document, so together they must fit in 16 MB
"…duplicates"$group on the normalised key, $push the ids, $match count > 1A unique index needs a collation to be case-insensitive
"…save the result for later"$merge into a summary collection$out replaces the whole target collection
"…page through / next 20"Range on the sort key: { ts: { $lt: lastTs } } plus a tie-breakerskip reads and discards every skipped document
"…update if present, insert if not"updateOne with upsert: true on a unique keyWithout a unique index, two upserts can both insert
"…the whole subtree / all reports"$graphLookupThe 100 MB memory limit on the stage
