"Schemaless" means the database will store the wrong type without complaint, unless you ask it to check

MongoDB accepts any document in any collection by default, so type mistakes surface later, as queries that quietly miss data. A date stored as a string compares as text: '2026-3-9' sorts after '2026-10-01', and no date range will ever match it. A price stored as a double carries binary rounding into every total. A $jsonSchema validator on the collection makes the server check types, required fields and allowed values on every insert and update. It can reject a bad document (validationAction: 'error') or only log it ('warn').

types.js · MongoDB 8.3, mongosh
db.events.drop();
// 1  dates stored as strings compare as text, not as time
db.events.insertMany([
  { _id: 1, kind: 'string', at: '2026-3-9 10:00' },
  { _id: 2, kind: 'string', at: '2026-10-01 10:00' },
  { _id: 3, kind: 'date',   at: ISODate('2026-03-09T10:00:00Z') },
  { _id: 4, kind: 'date',   at: ISODate('2026-10-01T10:00:00Z') }
]);
print('strings after "2026-06":', db.events.countDocuments({ at: { $gt: '2026-06' } }));
print('dates after 2026-06-01:', db.events.countDocuments({ at: { $gt: ISODate('2026-06-01') } }));
show(db.events.find({}, { _id: 1, kind: 1 }).sort({ at: 1 }));   // mixed types sort by type first

// 2  money: a line total, price x quantity, as double and as Decimal128
show(db.aggregate([
  { $documents: [{ price: 1.10, priceDec: Decimal128('1.10'), qty: 3 }] },
  { $project: { double: { $multiply: ['$price', '$qty'] }, decimal: { $multiply: ['$priceDec', '$qty'] } } }
]));

// 3  a validator in warn mode accepts a bad document and only logs it; error mode rejects it
db.events.drop();
db.createCollection('events', { validationAction: 'warn', validator: { $jsonSchema: {
  required: ['kind', 'at'], properties: { at: { bsonType: 'date' } } } } });
db.events.insertOne({ kind: 'login', at: '2026-04-01' });
print('stored in warn mode:', db.events.countDocuments());
db.runCommand({ collMod: 'events', validationAction: 'error' });
try { db.events.insertOne({ kind: 'login', at: '2026-04-02' }); } catch (e) { print(e.message); }
db.events.drop();

Mixed types sort by typeThe sort put both strings before both dates, regardless of value, because BSON compares values of different types by type first. A field that is sometimes a string and sometimes a date breaks sorting, ranges and indexes at once. That is usually the trace of an old application version or a careless import.
1.10 × 3As doubles the line total came out as 3.3000000000000003; as Decimal128 it is exactly 3.30. Store money as Decimal128, or as whole cents in a long, and map it to BigDecimal in Java. MongoDB's $sum compensates for rounding when it adds doubles, but multiplication, division and application code do not.
Say it in the interview"I add a $jsonSchema validator to every collection that matters: required fields, BSON types, enums. During a migration I run it in warn mode, then switch it to error.
