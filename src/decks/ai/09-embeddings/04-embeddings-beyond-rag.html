Embeddings solve problems without calling a chat model at all

Many useful features need only vectors and arithmetic: no prompt, no generation, no hallucination, and a cost of fractions of a cent per thousand items. Before reaching for a chat model, ask whether "find similar", "group similar" or "which known category is this nearest to" answers the question.

TicketDeduplicator.java
package com.acme.ai.embeddings;

import java.util.ArrayList;
import java.util.List;
import org.springframework.ai.embedding.EmbeddingModel;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Service;

@Service
class TicketDeduplicator {

    record Ticket(String id, String text) {}

    record Duplicate(String ticketId, String duplicateOf, double score) {}

    private final EmbeddingModel embeddingModel;
    private final double threshold;

    TicketDeduplicator(EmbeddingModel embeddingModel,
                       @Value("${acme.dedup.threshold:0.92}") double threshold) {
        this.embeddingModel = embeddingModel;
        this.threshold = threshold;   // tuned on labelled pairs, per model
    }

    /** Pairwise within one batch: fine for an hourly batch of a few thousand tickets. */
    List<Duplicate> findDuplicates(List<Ticket> tickets) {
        List<float[]> vectors = embeddingModel.embed(tickets.stream().map(Ticket::text).toList());
        List<Duplicate> duplicates = new ArrayList<>();
        for (int i = 0; i < tickets.size(); i++) {
            for (int j = 0; j < i; j++) {
                double score = SimilarityService.cosine(vectors.get(i), vectors.get(j));
                if (score >= threshold) {
                    duplicates.add(new Duplicate(tickets.get(i).id(), tickets.get(j).id(), score));
                    break;                     // link to the earliest match only
                }
            }
        }
        return duplicates;
    }
}

Say it in the interview"Not every AI feature needs generation. For deduplication, routing to known categories or 'more like this', embeddings plus a threshold are cheaper, faster, deterministic for a given model, and easy to evaluate. I bring in a chat model when I need language out, not just a decision."
