The request path: identity in, filter built, cited answer out

The service is small because the hard work sits in ingestion and permissions. On each question it builds an access filter from the employee's authenticated groups, passes it to the RAG advisor for this request only, and returns the answer with the documents that were actually used. Every question, source list and rating is logged for analytics and audit.

KnowledgeAssistantController.java
package com.acme.ai.usecases.knowledge;

import jakarta.validation.Valid;
import jakarta.validation.constraints.NotBlank;
import jakarta.validation.constraints.Size;
import java.util.List;
import org.springframework.ai.chat.client.ChatClient;
import org.springframework.ai.chat.client.ChatClientResponse;
import org.springframework.ai.document.Document;
import org.springframework.ai.rag.advisor.RetrievalAugmentationAdvisor;
import org.springframework.ai.rag.generation.augmentation.ContextualQueryAugmenter;
import org.springframework.ai.rag.retrieval.search.VectorStoreDocumentRetriever;
import org.springframework.ai.vectorstore.VectorStore;
import org.springframework.ai.vectorstore.filter.Filter;
import org.springframework.ai.vectorstore.filter.FilterExpressionBuilder;
import org.springframework.security.core.Authentication;
import org.springframework.security.core.GrantedAuthority;
import org.springframework.web.bind.annotation.*;

@RestController
@RequestMapping("/api/knowledge")
class KnowledgeAssistantController {

    record Question(@NotBlank @Size(max = 1_000) String text) {}

    record Source(String title, String url, String lastModified) {}

    record Answer(String text, List<Source> sources) {}

    interface QuestionLog {
        void record(String employee, String question, List<Source> sources);
    }

    private final ChatClient chatClient;
    private final QuestionLog questionLog;

    KnowledgeAssistantController(ChatClient.Builder builder, VectorStore vectorStore,
                                 QuestionLog questionLog) {
        var rag = RetrievalAugmentationAdvisor.builder()
                .documentRetriever(VectorStoreDocumentRetriever.builder()
                        .vectorStore(vectorStore)
                        .topK(6)
                        .similarityThreshold(0.45)
                        .build())
                .queryAugmenter(ContextualQueryAugmenter.builder().allowEmptyContext(false).build())
                .build();
        this.chatClient = builder
                .defaultSystem("""
                        You are Acme's internal knowledge assistant for employees.
                        Be concise. Name the document each fact comes from.""")
                .defaultAdvisors(rag)
                .build();
        this.questionLog = questionLog;
    }

    @PostMapping("/ask")
    Answer ask(@Valid @RequestBody Question question, Authentication employee) {
        ChatClientResponse response = chatClient.prompt()
                .user(question.text())
                .advisors(a -> a.param(VectorStoreDocumentRetriever.FILTER_EXPRESSION,
                        accessFilter(employee)))
                .call()
                .chatClientResponse();

        @SuppressWarnings("unchecked")
        List<Document> used = (List<Document>) response.context()
                .getOrDefault(RetrievalAugmentationAdvisor.DOCUMENT_CONTEXT, List.of());
        List<Source> sources = used.stream()
                .map(d -> new Source(String.valueOf(d.getMetadata().get("title")),
                        String.valueOf(d.getMetadata().get("url")),
                        String.valueOf(d.getMetadata().get("lastModified"))))
                .distinct()
                .toList();

        questionLog.record(employee.getName(), question.text(), sources);
        return new Answer(response.chatResponse().getResult().getOutput().getText(), sources);
    }

    /** Readable by everyone, or shared with one of the employee's groups. */
    static Filter.Expression accessFilter(Authentication employee) {
        List<Object> groups = employee.getAuthorities().stream()
                .map(GrantedAuthority::getAuthority)
                .filter(a -> a.startsWith("GROUP_"))
                .map(a -> (Object) a)
                .toList();
        var f = new FilterExpressionBuilder();
        return groups.isEmpty()
                ? f.eq("aclGroup", "EVERYONE").build()
                : f.or(f.eq("aclGroup", "EVERYONE"), f.in("aclGroup", groups)).build();
    }
}

PieceWhere it lives
Groups in the tokenSpring Security OAuth2 resource server, authorities mapped from the IdP's group claim
Per-request filterVectorStoreDocumentRetriever.FILTER_EXPRESSION: a Filter.Expression or a string
Used documentsRetrievalAugmentationAdvisor.DOCUMENT_CONTEXT in the response context
AnalyticsQuestionLog: questions with no sources become content tickets
Groups can be largeEmployees in hundreds of groups produce huge IN filters and slow searches. Map fine-grained source permissions to a manageable set of access groups at ingestion, and cache each employee's set for the token's lifetime.
