Candidates from the vector store, a short re-rank by the model, SKUs checked in code

VectorStore searches by text, so the "taste query" is built from the names of the products the customer engaged with most recently; its embedding lands near similar products. Filters exclude what they already own. The model then picks and explains a few items from that shortlist, and any SKU it returns that was not a candidate is discarded.

RecommendationService.java
package com.acme.ai.usecases.recommend;

import java.util.List;
import java.util.Map;
import java.util.function.Function;
import java.util.stream.Collectors;
import org.springframework.ai.chat.client.ChatClient;
import org.springframework.ai.document.Document;
import org.springframework.ai.vectorstore.SearchRequest;
import org.springframework.ai.vectorstore.VectorStore;
import org.springframework.ai.vectorstore.filter.FilterExpressionBuilder;
import org.springframework.stereotype.Service;

@Service
class RecommendationService {

    record Interaction(String sku, String productName, String kind) {}     // VIEWED, BOUGHT

    record Pick(String sku, String reason) {}

    record Picks(List<Pick> picks) {}

    record Recommendation(String sku, String name, String reason) {}

    interface History {
        List<Interaction> recent(String customerId, int limit);
    }

    private final VectorStore products;
    private final History history;
    private final ChatClient chatClient;

    RecommendationService(VectorStore products, History history, ChatClient.Builder builder) {
        this.products = products;
        this.history = history;
        this.chatClient = builder
                .defaultSystem("""
                        You are a home-furnishing stylist for Acme Retail. Choose items from the
                        candidate list only. Each reason must refer to the customer's history.""")
                .build();
    }

    List<Recommendation> recommend(String customerId, int howMany) {
        List<Interaction> recent = history.recent(customerId, 10);
        if (recent.isEmpty()) {
            return List.of();                                  // cold start: popular items instead
        }
        String tasteQuery = recent.stream().map(Interaction::productName)
                .collect(Collectors.joining(", "));
        List<Object> owned = recent.stream().filter(i -> i.kind().equals("BOUGHT"))
                .map(i -> (Object) i.sku()).toList();

        var f = new FilterExpressionBuilder();
        var filter = owned.isEmpty() ? f.eq("inStock", true)
                : f.and(f.eq("inStock", true), f.nin("sku", owned));
        List<Document> candidates = products.similaritySearch(SearchRequest.builder()
                .query(tasteQuery).topK(20).filterExpression(filter.build()).build());
        Map<String, Document> bySku = candidates.stream().collect(Collectors.toMap(
                d -> (String) d.getMetadata().get("sku"), Function.identity(), (a, b) -> a));

        String list = candidates.stream()
                .map(d -> d.getMetadata().get("sku") + " | " + d.getText().lines().findFirst().orElse(""))
                .collect(Collectors.joining("\n"));
        String past = recent.stream().map(i -> i.kind() + ": " + i.productName())
                .collect(Collectors.joining("\n"));

        Picks picks = chatClient.prompt()
                .user(u -> u.text("""
                        Customer history:
                        {past}

                        Candidates (SKU | name):
                        {list}

                        Pick the {n} best candidates for this customer.""")
                        .param("past", past).param("list", list).param("n", howMany))
                .call()
                .entity(Picks.class);

        return picks.picks().stream()
                .filter(p -> bySku.containsKey(p.sku()))           // drop invented SKUs
                .limit(howMany)
                .map(p -> new Recommendation(p.sku(),
                        bySku.get(p.sku()).getText().lines().findFirst().orElse(""), p.reason()))
                .toList();
    }
}

Keep the LLM off the hot pathCompute recommendations asynchronously (on a new purchase, or nightly for active customers), cache them, and serve from the cache. The page never waits for a model, and the cost is per customer per day, not per page view.
