Compliance checking: compare each clause with the rules, quote the evidence, let a person decide

Legal and procurement teams check supplier contracts against internal policy: liability caps, payment terms, data-protection clauses, termination rights. An LLM pipeline can pre-review a 40-page contract in minutes, but only if every finding is traceable: which clause, which policy rule, the exact quote that triggered it, and a reviewer's decision recorded against it.

Code first, model second

"Payment within 60 days" and "liability cap at least 1× contract value" are numeric rules: extract the numbers with structured output and compare in code. Use the model for judgement rules such as "data processing terms equivalent to our DPA".

Evidence or it did not happen

Every finding carries a verbatim quote. Code checks the quote exists in the clause; a finding with a paraphrased or invented quote is downgraded to "needs review". Reviewers jump straight to the evidence.

Measure against lawyers

Run past contracts with known outcomes. Track recall of real issues above all (a missed unlimited-liability clause is the costly error), then precision, so reviewers are not buried in false alarms.
