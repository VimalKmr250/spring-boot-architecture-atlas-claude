Images and documents go into the prompt as media

Most current chat models read images, and many read PDFs. That turns a whole class of enterprise chores into one call: read a delivery photo, a scanned invoice, a screenshot of an error, a hand-filled form. In Spring AI an image is a Media attached to the user message; combine it with structured output and you get typed data from a picture.

DamageClaimController.java
package com.acme.ai.vision;

import java.util.List;
import org.springframework.ai.chat.client.ChatClient;
import org.springframework.core.io.Resource;
import org.springframework.util.MimeType;
import org.springframework.util.MimeTypeUtils;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.RestController;
import org.springframework.web.multipart.MultipartFile;

@RestController
class DamageClaimController {

    enum Severity { NONE, COSMETIC, FUNCTIONAL, DESTROYED }

    record DamageReport(boolean packagingDamaged, Severity productDamage,
                        List<String> visibleIssues, boolean needsHumanReview) {}

    private static final List<String> ALLOWED = List.of("image/jpeg", "image/png");

    private final ChatClient chatClient;

    DamageClaimController(ChatClient.Builder builder) {
        this.chatClient = builder
                .defaultSystem("""
                        You assess photos of delivered parcels for damage claims.
                        Describe only what is visible. If the photo is unclear or
                        does not show a parcel, set needsHumanReview to true.""")
                .build();
    }

    @PostMapping("/api/claims/photo")
    DamageReport assess(@RequestParam("photo") MultipartFile photo) {
        if (!ALLOWED.contains(photo.getContentType()) || photo.getSize() > 5_000_000) {
            throw new IllegalArgumentException("JPEG or PNG up to 5 MB");
        }
        MimeType type = MimeTypeUtils.parseMimeType(photo.getContentType());
        Resource image = photo.getResource();
        return chatClient.prompt()
                .user(u -> u.text("Assess this delivery photo.").media(type, image))
                .call()
                .entity(DamageReport.class);
    }
}

InputGood fitWatch out for
PhotosDamage claims, shelf audits, returns triageImages cost hundreds to thousands of tokens each; resize first
Scans and PDFsInvoices, delivery notes, formsCheck provider support and page limits; for large archives, extract text once and use RAG
ScreenshotsSupport tickets ("what does this error mean?")They may contain personal data; redact or keep them in your region
Validate before you payCheck type and size before calling the model, as above. A 40 MB phone photo is expensive, slow, and may be rejected by the provider after the upload. Text visible inside an image is also untrusted input: a photo can carry an injection as easily as a document can.
