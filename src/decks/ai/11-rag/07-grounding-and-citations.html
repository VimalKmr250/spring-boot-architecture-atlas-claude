Number the sources, ask for citations, and check them in code

A grounded answer is one a reader can verify. Label every retrieved chunk with a number, ask the model to cite the numbers it used and to say when the context does not contain the answer, return the answer as a record, then check in code that every cited number was actually retrieved. Show the user the source titles and links. An answer with no valid citation is treated as "not found".

CitedAnswerService.java
package com.acme.ai.rag;

import java.util.List;
import java.util.stream.IntStream;
import org.springframework.ai.chat.client.ChatClient;
import org.springframework.ai.chat.client.ResponseEntity;
import org.springframework.ai.chat.model.ChatResponse;
import org.springframework.ai.document.Document;
import org.springframework.ai.rag.Query;
import org.springframework.ai.rag.retrieval.search.DocumentRetriever;
import org.springframework.ai.rag.retrieval.search.VectorStoreDocumentRetriever;
import org.springframework.ai.vectorstore.VectorStore;
import org.springframework.stereotype.Service;

@Service
class CitedAnswerService {

    record ModelAnswer(boolean answered, String answer, List<Integer> citations) {}

    record Source(int number, String title, String url) {}

    record CitedAnswer(String text, List<Source> sources) {}

    private static final String GROUNDED = """
            Answer the question using only the numbered sources below.
            After each claim, cite the source numbers you used, like [2].
            If the sources do not contain the answer, set answered to false.

            Sources:
            {sources}

            Question: {question}""";

    private final ChatClient chatClient;
    private final DocumentRetriever retriever;

    CitedAnswerService(ChatClient.Builder builder, VectorStore vectorStore) {
        this.chatClient = builder.build();
        this.retriever = VectorStoreDocumentRetriever.builder()
                .vectorStore(vectorStore).topK(5).similarityThreshold(0.5).build();
    }

    CitedAnswer ask(String question) {
        List<Document> docs = retriever.retrieve(new Query(question));
        if (docs.isEmpty()) {
            return new CitedAnswer("I couldn't find that in our policies.", List.of());
        }
        String numbered = IntStream.range(0, docs.size())
                .mapToObj(i -> "[" + (i + 1) + "] " + docs.get(i).getText())
                .reduce("", (a, b) -> a + b + "\n\n");

        ResponseEntity<ChatResponse, ModelAnswer> result = chatClient.prompt()
                .user(u -> u.text(GROUNDED)
                        .param("sources", numbered)
                        .param("question", question))
                .call()
                .responseEntity(ModelAnswer.class);
        ModelAnswer a = result.entity();

        List<Integer> valid = a.citations() == null ? List.of() : a.citations().stream()
                .filter(n -> n >= 1 && n <= docs.size()).distinct().toList();
        if (!a.answered() || valid.isEmpty()) {          // no evidence, no answer
            return new CitedAnswer("I couldn't find that in our policies.", List.of());
        }
        return new CitedAnswer(a.answer(), valid.stream().map(n -> new Source(n,
                String.valueOf(docs.get(n - 1).getMetadata().get("title")),
                String.valueOf(docs.get(n - 1).getMetadata().get("url")))).toList());
    }
}

Why retrieve outside the advisor hereThe advisor is convenient, but this use case needs the exact list of chunks and their numbering to validate citations, so the service retrieves with the same DocumentRetriever the advisor would use and builds the prompt itself. With the advisor you can read the retrieved list from the response context (RetrievalAugmentationAdvisor.DOCUMENT_CONTEXT).
Citations can be wrong tooA model can cite [2] for a claim that is not in source 2. Valid numbers prove the source was retrieved, not that it supports the claim. Measure support offline with a fact-checking evaluator (next slide), and show sources so users can check.
Say it in the interview"Grounding is a contract: answer only from numbered context, cite it, and decline when it is missing. I enforce the contract in code with structured output and citation checks, and I measure faithfulness offline."
