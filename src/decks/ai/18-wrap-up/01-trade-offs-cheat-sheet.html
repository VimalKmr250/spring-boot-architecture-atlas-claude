The trade-offs you will be asked to defend, on one page

Nearly every design question in this area is one of these choices. Name the option you would start with, the evidence that would make you switch, and the cost of switching. That structure answers most follow-ups before they are asked.

The meta-answer"I start with the simplest option that can work, define how I would measure 'good enough', and switch only when the measurement says so. Spring AI's abstractions make most switches configuration or a local refactor; the expensive switches are the ones that change stored data: embedding models, chunking and vector stores."
