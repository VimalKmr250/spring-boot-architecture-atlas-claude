A three-week plan from first prompt to interview-ready

Reading is not enough; build one small application that grows through the plan. Run it with the ollama profile so experiments cost nothing, and switch to a hosted model when you want to compare quality. By the end you will have code to talk about, numbers you measured yourself, and answers to every question in this tab.

What to bring to an interviewOne system you built, its numbers (latency, cost per request, evaluation score), one thing that went wrong and how you found it, and the controls you would add next. That story answers more questions than any definition.
