Spring AI 1.x → 2.0: what breaks, and what to change

Many production codebases still run Spring AI 1.0 or 1.1 on Spring Boot 3.x. Spring AI 2.0 requires Spring Boot 4 (Framework 7) and Jackson 3, so the upgrade usually follows the Boot 4 migration. This is the list to work through, taken from the official upgrade notes and checked against the 2.0.1 jars.

Order of work

Boot 4 and Jackson 3 first; then dependencies and module names; then compile errors (options, tools, MCP packages); then behaviour changes (memory ids, tool attachment, retries); then the JDBC schema migration.

Behaviour, not just compilation

Code that compiles can still behave differently: tools no longer run from ChatModel, unattached tools are not found, retries and timeouts come from a different layer. The stub-model unit tests and the evaluation set are what prove equivalence.
