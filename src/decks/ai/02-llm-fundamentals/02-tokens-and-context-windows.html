Tokens are the unit of cost, latency and limits

A model never sees characters or words. A tokenizer splits text into sub-word pieces from a fixed vocabulary, and everything is counted in those pieces: what you pay, how long you wait, and how much fits in one call. Being able to estimate tokens quickly is a skill interviewers test.

Rule of thumb (English)Tokens
1 token≈ 4 characters ≈ ¾ of a word
A one-paragraph question≈ 100
A page of prose≈ 600–800
A 20-page contract≈ 15,000
A 300-page manual≈ 200,000
Code, JSON, other languages1.5–3× more per word

The context window

The maximum number of tokens in one call, input plus output together: system prompt, history, retrieved documents, tool definitions and the answer. Current models offer from about 128k to over a million tokens. A bigger window is not free: you pay for every token you send, latency grows, and models recall facts from the middle of a long context less reliably than from the start or end.

Estimate a bill before you build

A support assistant: 20,000 conversations a day, 5 turns each. Each turn sends a 1,500-token system prompt and retrieved context, plus the growing history (about 2,500 tokens on average), and gets a 250-token answer.

Back-of-envelope · illustrative prices
turns/day   = 20,000 × 5                 = 100,000
input/day   = 100,000 × 4,000 tokens     = 400 M tokens
output/day  = 100,000 × 250 tokens       =  25 M tokens

at $0.25 per M input, $2.00 per M output (a small model):
  400 × 0.25 + 25 × 2.00 = $100 + $50   = $150 / day ≈ $4.5k / month
the same traffic on a model priced 12× higher ≈ $54k / month

Input dominates the bill, and most of the input is the part you resend every turn. That is why trimming history, retrieving fewer but better chunks, and prompt caching matter more than shortening the answer.

Output costs moreOutput tokens are usually priced several times higher than input tokens (often 4–8×), and they are generated one at a time. Cap them with maxTokens and ask for compact formats.

Measure, do not guess

Every Spring AI response carries the real counts in ChatResponse.getMetadata().getUsage(), and Micrometer publishes them as metrics. See token usage.

Budget the window

Decide up front how the window is split: for example 2k system and tools, 6k retrieved context, 4k history, 1k answer. Then enforce each budget in code instead of hoping it fits.

Different models, different tokenizers

The same text is a different number of tokens on different model families. Re-measure when you switch providers; prices per token are not directly comparable.
