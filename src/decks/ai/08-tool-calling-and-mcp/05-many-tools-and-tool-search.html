Past a dozen tools, stop sending them all: let the model search for them

Every attached tool's name, description and schema is sent on every model call. Ten tools cost a few hundred tokens; two hundred tools from a handful of MCP servers cost tens of thousands, slow every call, and make the model pick the wrong tool more often. ToolSearchToolCallingAdvisor replaces the full list with one search tool: the model describes what it needs, the advisor finds matching tools in an index, and only those are disclosed.

application.yml · with spring-ai-starter-tool-search-advisor
spring:
  ai:
    chat:
      client:
        tool-search-advisor:
          enabled: true
          tool-index-type: lucene   # regex (default), lucene or vector
          max-results: 5
    tools:
      limits:
        max-total-tool-calls: 20
Tools attachedApproach
1–10Attach them all; write precise descriptions
10–30Split by use case: separate clients with separate tool sets
30+ or from MCP serversTool search, or route first with a classifier and attach that route's tools
Search does not replace authorisationTool search changes what the model sees, not what it may do. Only index tools the current user is allowed to use, and keep the permission checks inside each tool.
