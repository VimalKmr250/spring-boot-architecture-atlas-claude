MCP lets one team publish tools that any AI application can use

The Model Context Protocol (MCP) standardises how an AI application discovers and calls tools, reads resources and fetches prompt templates from a separate server. Instead of every assistant re-implementing "check stock", the inventory team runs an MCP server once; Spring AI apps, IDE assistants and desktop chat clients all connect to it. Spring AI 2.0 ships MCP Java SDK 2.0, with Streamable HTTP as the default transport.

InventoryMcpTools.java · server, with spring-ai-starter-mcp-server-webmvc
package com.acme.ai.mcp.server;

import org.springframework.ai.mcp.annotation.McpTool;
import org.springframework.ai.mcp.annotation.McpToolParam;
import org.springframework.stereotype.Component;

@Component
public class InventoryMcpTools {

    public record StockLevel(String sku, int available) {}

    public interface Inventory {
        StockLevel level(String sku);
    }

    private final Inventory inventory;

    public InventoryMcpTools(Inventory inventory) {
        this.inventory = inventory;
    }

    @McpTool(name = "stock_level", description = "Current available stock of one Acme product")
    public StockLevel stockLevel(
            @McpToolParam(description = "Product SKU, for example LMP-01", required = true) String sku) {
        return inventory.level(sku);
    }
}
application.yml · server
spring:
  ai:
    mcp:
      server:
        name: acme-inventory
        version: 1.4.0

StockAssistant.java · client, with spring-ai-starter-mcp-client
package com.acme.ai.mcp.client;

import org.springframework.ai.chat.client.ChatClient;
import org.springframework.ai.mcp.SyncMcpToolCallbackProvider;
import org.springframework.stereotype.Service;

@Service
class StockAssistant {

    private final ChatClient chatClient;

    StockAssistant(ChatClient.Builder builder, SyncMcpToolCallbackProvider mcpTools) {
        this.chatClient = builder
                .defaultSystem("You answer Acme staff questions about stock.")
                .defaultTools(mcpTools)             // every tool the connected servers offer
                .build();
    }

    String ask(String question) {
        return chatClient.prompt().user(question).call().content();
    }
}
application.yml · client
spring:
  ai:
    mcp:
      client:
        request-timeout: 10s
        streamable-http:
          connections:
            inventory:
              url: https://inventory-mcp.internal.acme.example
An MCP server is a trust decisionIts tool descriptions go into your prompt and its results go into your context: a malicious or compromised server can inject instructions. Connect only to servers you operate or vet, secure them with OAuth 2.0 or API keys, filter which tools you expose with an McpToolFilter bean, and apply the same least-privilege rules as local tools.
