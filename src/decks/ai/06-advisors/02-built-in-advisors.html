The built-in advisors, what each adds, and where it sits

You will rarely write the plumbing these advisors provide. Learn what each one does to the request and response, its default order, and which module it lives in, because several sit outside the core spring-ai-client-chat jar.

AdvisorDoesDefault orderModule
MessageChatMemoryAdvisorAdds stored history as messages; saves the new turnHIGHEST+200spring-ai-client-chat
VectorStoreChatMemoryAdvisorRetrieves only relevant past turns from a vector storeHIGHEST+200spring-ai-vector-store-advisor
ToolCallingAdvisorRuns the tool-call loop; auto-registered by ChatClientHIGHEST+300spring-ai-client-chat
ToolSearchToolCallingAdvisorExposes only the tools relevant to the request, found by searchconfigurablespring-ai-tool-search-advisor
QuestionAnswerAdvisorSimple RAG: similarity search, then context added to the user message0spring-ai-vector-store-advisor
RetrievalAugmentationAdvisorModular RAG: query transform, expand, retrieve, join, augment0spring-ai-rag
SafeGuardAdvisorBlocks requests that contain listed words; returns a fixed reply0spring-ai-client-chat
SimpleLoggerAdvisorLogs request and response at DEBUG0spring-ai-client-chat
StructuredOutputValidationAdvisorValidates JSON against the schema; re-asks with the errorsLOWEST−2000spring-ai-client-chat
Defaults on the client, extras per request (excerpt)
ChatClient support = builder
        .defaultAdvisors(
                SafeGuardAdvisor.builder()
                        .sensitiveWords(List.of("internal use only"))
                        .order(Ordered.HIGHEST_PRECEDENCE)        // before memory
                        .build(),
                MessageChatMemoryAdvisor.builder(chatMemory).build(),
                QuestionAnswerAdvisor.builder(vectorStore).build(),
                new SimpleLoggerAdvisor())
        .build();

String answer = support.prompt()
        .user(question)
        .advisors(a -> a.param(ChatMemory.CONVERSATION_ID, conversationId))
        .call()
        .content();
Logging prompts is a data decisionSimpleLoggerAdvisor logs full prompts and answers, which may contain personal data and retrieved confidential documents. Enable its DEBUG logger only where your log retention allows it, or write a logger advisor that records sizes and ids instead of content.
1.x renames and removalsToolCallAdvisor became ToolCallingAdvisor; PromptChatMemoryAdvisor was removed in favour of MessageChatMemoryAdvisor; the vector store advisor module was renamed from spring-ai-advisors-vector-store to spring-ai-vector-store-advisor.
