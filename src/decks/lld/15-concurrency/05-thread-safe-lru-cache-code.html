LRU cache: the hand-written version, one lock, and a check that the structure survives contention

Every public method takes the lock, does its O(1) work on the map and the list together, and releases it in finally. The demo first shows the eviction order, then runs 20,000 random operations from virtual threads. Which keys survive varies from run to run, so it checks the invariants instead: the map and the list agree, and the size never exceeds capacity.

LruCacheDemo.java · the cache and its demo
import java.util.*;
import java.util.concurrent.Executors;
import java.util.concurrent.atomic.AtomicInteger;
import java.util.concurrent.locks.ReentrantLock;

final class LruCache<K, V> {
    private static final class Node<K, V> {
        final K key;
        V value;
        Node<K, V> prev, next;
        Node(K key, V value) { this.key = key; this.value = value; }
    }

    private final int capacity;
    private final Map<K, Node<K, V>> index = new HashMap<>();
    private final Node<K, V> head = new Node<>(null, null);  // sentinels
    private final Node<K, V> tail = new Node<>(null, null);
    private final ReentrantLock lock = new ReentrantLock();
    private long hits, misses, evictions;

    LruCache(int capacity) {
        if (capacity < 1) throw new IllegalArgumentException("capacity");
        this.capacity = capacity;
        head.next = tail;
        tail.prev = head;
    }

    Optional<V> get(K key) {
        lock.lock();
        try {
            Node<K, V> n = index.get(key);
            if (n == null) { misses++; return Optional.empty(); }
            hits++;
            moveToFront(n);                      // a read is a write
            return Optional.of(n.value);
        } finally { lock.unlock(); }
    }

    void put(K key, V value) {
        lock.lock();
        try {
            Node<K, V> n = index.get(key);
            if (n != null) { n.value = value; moveToFront(n); return; }
            if (index.size() == capacity) {
                Node<K, V> lru = tail.prev;
                unlink(lru);
                index.remove(lru.key);
                evictions++;
            }
            n = new Node<>(key, value);
            index.put(key, n);
            addFront(n);
        } finally { lock.unlock(); }
    }

    List<K> keysByRecency() {
        lock.lock();
        try {
            List<K> keys = new ArrayList<>();
            for (Node<K, V> n = head.next; n != tail; n = n.next) keys.add(n.key);
            return keys;
        } finally { lock.unlock(); }
    }

    boolean consistent() {                       // for tests
        List<K> keys = keysByRecency();
        lock.lock();
        try {
            return keys.size() == index.size() && keys.size() <= capacity
                && index.keySet().containsAll(keys);
        } finally { lock.unlock(); }
    }

    long lookups() {
        lock.lock();
        try { return hits + misses; } finally { lock.unlock(); }
    }

    private void unlink(Node<K, V> n) { n.prev.next = n.next; n.next.prev = n.prev; }
    private void addFront(Node<K, V> n) {
        n.next = head.next; n.prev = head;
        head.next.prev = n; head.next = n;
    }
    private void moveToFront(Node<K, V> n) { unlink(n); addFront(n); }
}

public class LruCacheDemo {
    public static void main(String[] args) {
        var cache = new LruCache<String, Integer>(3);
        cache.put("a", 1); cache.put("b", 2); cache.put("c", 3);
        cache.get("a");                           // a becomes most recent
        cache.put("d", 4);                        // evicts b, the least recent
        System.out.println("recency: " + cache.keysByRecency());
        System.out.println("get b: " + cache.get("b") + ", get c: " + cache.get("c"));
        System.out.println("recency: " + cache.keysByRecency());

        var shared = new LruCache<Integer, Integer>(100);
        var gets = new AtomicInteger();
        try (var pool = Executors.newVirtualThreadPerTaskExecutor()) {
            for (int t = 0; t < 20; t++) {
                long seed = t;
                pool.submit(() -> {
                    var random = new Random(seed);
                    for (int i = 0; i < 1_000; i++) {
                        int key = random.nextInt(300);
                        if (random.nextBoolean()) shared.put(key, i);
                        else { shared.get(key); gets.incrementAndGet(); }
                    }
                });
            }
        }
        System.out.println("after 20,000 concurrent ops: consistent " + shared.consistent()
                + ", size " + shared.keysByRecency().size()
                + ", lookups counted " + (shared.lookups() == gets.get()));
    }
}

Why ReentrantLock and not synchronizedEither is correct here. ReentrantLock leaves room for tryLock with a timeout, and on JDK 21 it does not pin a virtual thread's carrier if a loader is later called inside the lock. The try/finally is mandatory: an exception between lock() and unlock() would otherwise leave the cache locked forever.
Why test invariants, not contentsUnder concurrency the final contents depend on scheduling, but the invariants must hold after every run. Tests that assert invariants catch torn updates reliably; tests that assert exact contents are flaky. The same approach applies to the booking race.
The follow-up: a loading cache"On a miss, load from the database, but only once per key even if a hundred threads miss together." Do not load while holding the cache lock. Keep a ConcurrentHashMap<K, CompletableFuture<V>> of in-flight loads: the first thread starts one with computeIfAbsent, and the rest wait on the same future.
