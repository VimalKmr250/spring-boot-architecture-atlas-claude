The 23 Gang of Four patterns, and the ones LLD rounds actually use

The 1994 Design Patterns book named 23 recurring solutions in three families: creational (how objects get made), structural (how objects are put together) and behavioural (how objects share work). About ten of them come up in almost every LLD round. The core ones are worth knowing well enough to write from memory.

CreationalIntent
SingletonOne instance, one global access point. Mostly an anti-pattern now.
Factory method coreLet a method decide which class to instantiate.
Abstract factoryCreate families of related objects that must match.
Builder coreBuild a complex object step by step, validated once.
PrototypeCreate by copying a configured instance.
StructuralIntent
Adapter coreMake an existing interface fit the one you need.
BridgeVary an abstraction and its implementation independently.
CompositeTreat a tree of objects and a single object alike.
Decorator coreAdd behaviour by wrapping, without subclassing.
FacadeOne simple entry point to a subsystem.
FlyweightShare immutable state across many small objects.
ProxyA stand-in that controls access: lazy, cached, remote, guarded.
BehaviouralIntent
Chain of resp.Pass a request along handlers until one deals with it.
Command coreA request as an object: queue it, log it, undo it.
InterpreterA grammar as a class per rule. Rare in LLD rounds.
IteratorWalk a collection without exposing its structure.
MediatorObjects talk through a hub, not to each other.
MementoSave and restore state without exposing it.
Observer coreNotify subscribers when something changes.
State coreBehaviour that changes with internal state.
Strategy coreSwap an algorithm behind an interface.
Template methodA fixed algorithm with steps subclasses fill in.
VisitorAdd operations to a closed type hierarchy.
How each pattern slide is laid outThe problem it solves, a complete program that compiles and runs, what it printed, and when not to use it. Patterns cost classes. Use one when it removes a conditional that would otherwise be repeated, or isolates a change you expect.
