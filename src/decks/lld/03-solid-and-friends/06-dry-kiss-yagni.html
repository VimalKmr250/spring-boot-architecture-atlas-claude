DRY, KISS and YAGNI keep SOLID from turning into over-engineering

SOLID pushes you towards more interfaces and more classes. These three push back. In an interview the right amount of design is whatever the stated requirements, plus the one change you can see coming, need. Anything beyond that is time you did not spend on the working code.

DRY · Don't repeat yourself

Every piece of knowledge should have one authoritative home. The late-fee rule lives in one place, not in the checkout screen and in the nightly job.

Misread as "never write similar code twice". Two methods that look alike today but change for different reasons are not duplication. Merging them creates the wrong abstraction, which is worse than the copy.

KISS · Keep it simple

Choose the simplest structure that meets the requirement. If vehicle types differ only in a size, an enum with a field beats a class hierarchy. If there is one pricing rule, a method beats a strategy interface.

Misread as "no design". Simple means few concepts, not one giant method.

YAGNI · You aren't gonna need it

Do not build for requirements you imagined. Multi-currency, plug-in loading and a rules engine are rarely asked for in an hour.

Misread as "no seams". Leaving an interface where the prompt hints at change ("pricing may vary") is not speculation; it is reading the requirements.

KISS · when behaviour is only data, use an enum
enum VehicleType {
    MOTORBIKE(SpotSize.SMALL, 20),
    CAR(SpotSize.MEDIUM, 40),
    TRUCK(SpotSize.LARGE, 90);

    final SpotSize needs;
    final int hourlyRate;
    VehicleType(SpotSize needs, int hourlyRate) {
        this.needs = needs;
        this.hourlyRate = hourlyRate;
    }
}
// Promote to classes only when the types start to
// behave differently, not just carry different numbers.
What to say out loud"I'll keep vehicle types as an enum, because right now they differ only in size and rate. If you tell me trucks need a permit check, I'll turn it into a sealed interface. That's a ten-minute change, because nothing outside VehicleType switches on it." That one sentence shows KISS, YAGNI and an awareness of OCP together, and interviewers notice it.
