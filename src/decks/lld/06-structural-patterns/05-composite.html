Composite: treat one item and a whole tree of items the same way

A directory's size is the sum of its children's sizes, and a child can be a file or another directory. A composite gives leaves and containers one interface, so size(), print() or find() work on any node, and the recursion is in the data structure rather than in every caller. It is the standard answer to "design a file system".

CompositeDemo.java · a file tree with a sealed node type
import java.util.*;

sealed interface Node permits FileNode, Dir {
    String name();
    long size();
}

record FileNode(String name, long size) implements Node {}

final class Dir implements Node {
    private final String name;
    private final List<Node> children = new ArrayList<>();
    Dir(String name) { this.name = name; }
    Dir add(Node child) { children.add(child); return this; }
    public String name() { return name; }
    public long size() {                          // recursion lives here
        return children.stream().mapToLong(Node::size).sum();
    }
    List<Node> children() { return Collections.unmodifiableList(children); }
}

public class CompositeDemo {
    static void print(Node n, String indent) {
        switch (n) {                              // pattern switch, sealed
            case FileNode f -> System.out.printf("%s%s (%d)%n", indent, f.name(), f.size());
            case Dir d -> {
                System.out.printf("%s%s/ (%d)%n", indent, d.name(), d.size());
                d.children().forEach(c -> print(c, indent + "  "));
            }
        }
    }

    static Optional<Node> find(Node n, String name) {
        if (n.name().equals(name)) return Optional.of(n);
        if (n instanceof Dir d)
            for (Node c : d.children()) {
                Optional<Node> hit = find(c, name);
                if (hit.isPresent()) return hit;
            }
        return Optional.empty();
    }

    public static void main(String[] args) {
        Dir root = new Dir("root")
            .add(new FileNode("notes.txt", 120))
            .add(new Dir("src")
                .add(new FileNode("Main.java", 2_400))
                .add(new Dir("util").add(new FileNode("Ids.java", 800))))
            .add(new Dir("empty"));
        print(root, "");
        System.out.println("src size: " + find(root, "src").map(Node::size).orElse(-1L));
        System.out.println("missing:  " + find(root, "nope").isPresent());
    }
}

Where the add method goesThe classic GoF version puts add on the shared interface, so a file has an add that throws. That breaks ISP. Putting add only on Dir, as here, is the safer choice; callers who build trees know they are holding a directory.
