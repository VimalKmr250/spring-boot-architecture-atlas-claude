It is the round closest to the job you will actually do

Most engineering time goes into adding a feature to code someone else designed. An LLD round shows, in an hour, whether your code will make that easy or hard for the next person. Many product companies run a machine-coding round for mid-level hires, and senior loops often use an object-oriented design question alongside system design.

Modelling

Can you find the right nouns, and put state and behaviour together? A candidate who makes ParkingSpot decide whether a vehicle fits has modelled. One who writes a ParkingManager that asks every object for its fields has not.

Handling change

Every interviewer has a second requirement ready: a new vehicle type, a weekend price, a new split rule. They are watching whether the change touches one class or ten.

Code quality under time pressure

Names, small methods, immutability, validation at the boundary, no duplicated logic. Nobody expects perfect code in an hour, but the habits show.

Communication

Asking the right questions before designing, saying why you chose an interface over an enum, and saying what you would do with more time. A silent correct answer scores lower than a spoken, slightly incomplete one.

LevelWhat a pass usually looks like
JuniorA sensible set of classes, correct code for the main use case, and clear names. Patterns are optional.
Mid-levelClean responsibilities, interfaces at the points of variation, edge cases handled, and a working demo. Can name the patterns they used and why.
SeniorAll of that, plus concurrency, failure modes and extensibility, raised without prompting. Explains what they deliberately left out.
