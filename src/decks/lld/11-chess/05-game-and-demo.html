Chess: the shortest checkmate, a pin, a promotion, and undo

The first game plays fool's mate, the fastest possible checkmate, with two illegal attempts along the way. The second starts from a position written as text. It shows a pinned bishop, a promotion, and a black rook that cannot capture because moving it would expose its own king to the new queen.

ChessDemo.java · 3 of 3 · the demo
public class ChessDemo {
    static void play(Game g, String from, String to) {
        try {
            Move m = g.move(from, to);
            System.out.printf("  %-9s %s to move, %s%n", m, g.turn(), g.status());
        } catch (IllegalArgumentException | IllegalStateException e) {
            System.out.printf("  %s-%s     refused: %s%n", from, to, e.getMessage());
        }
    }

    public static void main(String[] args) {
        System.out.println("Fool's mate");
        var g = new Game(Board.standard());
        play(g, "e7", "e5");                    // black cannot start
        play(g, "e2", "e5");                    // pawns do not jump
        play(g, "f2", "f3");
        play(g, "e7", "e5");
        play(g, "g2", "g4");
        play(g, "d8", "h4");                    // checkmate
        play(g, "a2", "a3");
        g.undo();
        System.out.println("  undo      " + g.turn() + " to move, " + g.status());

        System.out.println("Pin and promotion");
        var p = new Game(Board.fromRows(
                "....r..k",
                "P.......",
                "........",
                "........",
                "........",
                "........",
                "....B...",
                "....K..."));
        play(p, "e2", "d3");                    // bishop is pinned
        play(p, "a7", "a8");                    // promotes to a queen
        play(p, "e8", "e2");                    // would uncover h8
        play(p, "h8", "h7");
        play(p, "a8", "e8");
        System.out.println(p.render());
    }
}

Positions as text are a test toolBoard.fromRows costs ten lines and makes every rule testable in isolation: a pin, a stalemate, a promotion. In a machine-coding round, write it early. It is also how you answer "how would you test this?"
What undo restoresAfter undoing the mating move, it is black's turn again and the status is recomputed from the board, not remembered. Deriving status from the position means undo can never leave a stale "checkmate" behind.
