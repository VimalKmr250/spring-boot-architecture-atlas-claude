Prototype: copy a configured object, and copy it deeply enough

Create new objects by copying one that is already set up: a board in its opening position, a document template, a default configuration. The pattern is simple. The hard part is the copy: a shallow copy shares its mutable insides, so changing the copy changes the original. Chess engines hit this when they copy the board to try a move.

PrototypeDemo.java · a shallow copy leaks, a deep copy does not
import java.util.*;

final class Board {
    private final char[][] cells;
    private Board(char[][] cells) { this.cells = cells; }

    static Board parse(String... rows) {
        char[][] c = new char[rows.length][];
        for (int i = 0; i < rows.length; i++) c[i] = rows[i].toCharArray();
        return new Board(c);
    }

    Board shallowCopy() {                  // new Board, same arrays
        return new Board(cells.clone());   // clone() on 2-D copies row refs
    }

    Board deepCopy() {                     // copy constructor semantics
        char[][] c = new char[cells.length][];
        for (int i = 0; i < cells.length; i++) c[i] = cells[i].clone();
        return new Board(c);
    }

    void move(int r1, int c1, int r2, int c2) {
        cells[r2][c2] = cells[r1][c1];
        cells[r1][c1] = '.';
    }

    String row(int r) { return new String(cells[r]); }
}

public class PrototypeDemo {
    public static void main(String[] args) {
        Map<String, Board> prototypes = new LinkedHashMap<>();   // registry
        prototypes.put("mini", Board.parse("rnbk", "pppp", "....", "PPPP", "RNBK"));

        Board original = prototypes.get("mini");
        Board shallow = original.shallowCopy();
        shallow.move(3, 0, 2, 0);          // try a pawn move on the copy
        System.out.println("after shallow try, original row 3: " + original.row(3));

        Board fresh = Board.parse("rnbk", "pppp", "....", "PPPP", "RNBK");
        Board deep = fresh.deepCopy();
        deep.move(3, 0, 2, 0);
        System.out.println("after deep try,    original row 3: " + fresh.row(3));
        System.out.println("                   copy row 3:     " + deep.row(3));
    }
}

                   copy row 3:     .PPP
Ways to copyVerdict
Cloneable + clone()Avoid. Shallow by default, bypasses constructors, clashes with final fields, and throws a checked exception.
Copy constructor or copy() methodPreferred. You decide what is deep, and it can keep fields final.
Immutable objectsBest of all: nothing to copy. A new board per move, sharing the unchanged rows, is how persistent data structures work.
