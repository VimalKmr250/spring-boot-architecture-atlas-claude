Parking lot: four classes with state, two enums, one strategy

The lot coordinates, each floor manages its own free spots, and a spot guards its own occupancy. The fee rule sits behind an interface because the requirements say it changes. Everything else is concrete, because nothing else was said to vary.

Free lists, not a scanEach floor keeps a queue of free spots per size, so finding a spot is a few queue polls rather than a loop over every spot. With 2,000 spots per floor and a busy morning, that is the difference the interviewer asks about when they say "can it be faster?"
No singletonThere is one lot, but it is created in main and passed in, so a test can build a lot with three spots. See Singleton: how it breaks.
